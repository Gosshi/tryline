# Codex 委譲プロンプト作成

仕様書完成後、Owner が Codex に貼るプロンプトを作る。

## 手順

1. **テンプレートを使う**: `docs/codex-prompts.md` に公式テンプレートがある（仕様書実装 / 小さな個別変更 / バグ修正）。これをベースにする。
2. **保存場所**: `docs/codex-prompts/<spec名と同名>.md` に保存する（既存例多数あり。命名を揃える）。
3. **原則**:
   - 仕様書ファイルをパスで参照し、内容をインラインで繰り返さない
   - 入出力の具体例を 1〜2 個示す
   - Codex が処理すべきエッジケースを列挙する
   - 「完了」の定義を明確にする（テスト、変更されるファイル、実行コマンド）
   - 参考にすべき既存コードのパターンをファイルパスで指す（`lib/llm/stages/`、`lib/db/queries/` など）

## プロンプトに必ず含める定型

- `CLAUDE.md` の規約に従う
- 曖昧な箇所は推測せず末尾に質問として列挙する
- スコープ対象外は実装しない
- 受け入れ条件に対するテストを書く（`tests/` 配下の既存構成に倣う）

## 完了後

Owner に「このプロンプトを Codex に貼ってください」と伝え、実装が返ってきたら `codex-review` スキルでレビューする流れを案内する。
