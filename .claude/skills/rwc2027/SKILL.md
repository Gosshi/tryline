# RWC2027 資産構築プログラム

RWC2027（2027年10〜11月・オーストラリア）はプロダクトの最終目標（有料購読者数）であり、SEO 上も **GSC で実需要が確認できた唯一の大型キーワード群**。大手メディアが本気を出す2027年夏より前にドメイン評価を作る（空白期は残り約15ヶ月）。

## 根拠（2026-07 実測）

- 「ラグビーワールドカップ 日程」「ラグビーワールドカップ 2027 日程」等の実クエリが GSC に存在。`/c/rwc` `/c/rwc/2027` にインプレッション発生、順位29〜58位・クリック0（＝ページを強化すれば取れる位置）
- 詳細: `docs/marketing-strategy-2026-07-06.md` §4・§6.2、`docs/growth-audit-2026-07-01.md` §2.2

## 施策バックログ（優先順）

1. **ハブ強化 spec（最優先）**: `/c/rwc/2027` に日程・日本時間・出場24カ国・開催都市・視聴方法・FAQ 構造化データ → `spec-writing` で起票
2. **note 連載「RWC2027への道」**（月1本、執筆規約は `note-weekly` に従う）:
   - #1 出場24カ国はどう決まったか
   - #2 開催地オーストラリアの都市と時差事情
   - #3 前回大会からの勢力図の変化
   - #4 日本代表が入りうるプールのシナリオ
   - 以降は抽選・組み合わせ・強化試合の進行に合わせて追加
3. プール別ページ（抽選確定後に spec 化）
4. 過去大会 recap 資産の整理（RWC2023 データの有無を要確認 → `prod-investigation`）

## 月次チェック（月初、/today から委譲される）

1. GSC で RWC 系クエリ（「ラグビーワールドカップ」「RWC」を含むクエリ）の順位・インプレッションを確認（取得手順は `growth-analysis`）
2. ハブ強化 spec / note 連載の進捗確認（前月分が出ているか）
3. 大会の確定情報（抽選・チケット販売・日本での放送権）を WebSearch で確認し、変化があればハブ更新の spec 候補として Owner に提示

## KPI

- RWC 系クエリ平均順位: 29〜58位 → **20位以内（2026-08末）** → 10位以内（2026年内）→ 大会年は主要クエリで1ページ目
- note 連載: 月1本の継続（落とした月は翌月2本にしない。ペース維持が優先）

## 制約

- 実装は Codex（spec 経由）。このスキル自体は調査・進捗管理・ドラフトまで
- 日程・出場国・チケット等の事実は一次ソース（World Rugby / 大会公式）で裏取り。未確定情報は「未確定」と明記（捏造ゲートの思想と同じ）
