# X reply 運用（下書き支援）

Owner の毎日10分 reply 運用（growth-playbook X2）を支援する。**投稿するのは Owner。Claude Code は候補選定と下書きまで。**

## 権威ドキュメント

- ターゲットリスト・原則: `docs/x-reply-strategy.md`（Tier 1/2 アカウント、reply の切り口）
- 運用ルール（10分/日版）: `docs/growth-playbook-2026-06.md` の「追記（2026-07-02）」節

## 手順

1. **対象スレッドの把握**: Owner から対象ポストの内容（コピペ or スクショ）をもらう。こちらから X をクロールしない（robots/レート制限の観点。X API スクリプトは `scripts/x-find-reply-targets.ts` があるが実行は Owner 判断）
2. **データで裏付ける**: reply の武器は Tryline の実データ。`prod-investigation` スキルの読み取り専用ルールで Supabase から取る:
   - 直近5試合の平均得点・失点、連勝/連敗（`match` / `competition_standings`）
   - H2H 過去対戦（`/h2h` ページのデータ）
   - 該当試合の得点経過（`match_events`）
3. **下書きは2〜3案**: トーン違い（データ補足型 / 質問回答型 / 予習情報型）で出し、Owner が選ぶ
4. **文字数**: 140字以内を基本。数字は1 reply に1〜2個まで（詰め込みすぎない）

## reply の質（2026-07-13 追加）

- **祝辞・感想だけの reply（「素晴らしい勝利でした🎉」等）は書かない**。07-13 の実測分析で、この型は 129 インプレッションに達してもフォロー・プロフィール訪問に一切繋がらなかった
- 必ず「事実＋自分の見方」を1セット入れる。型: 「同感です。特に重要だったのは○○。前半の△△以降、試合の流れが変わりました。次戦では□□に注目です」
- 相手に質問を投げる場合は選択式（①②③）にして答えやすくする

## URL ルール（厳守）

- 「詳しくは→URL」だけの reply は絶対に書かない
- URL を添えるのは「そのリンクで何が分かるか」を一言添えられるときだけ
- URL 付き reply は1日1〜2件まで。@wowow_rugby には週1回まで
- 最初の接点3件は URL なしで信頼を作る（新規アカウント相手）

## 週次ペース配分

平日1〜2件で存在維持、週末（試合日）に3〜5件へ増やす。10分で終わらない量は提案しない。

## こちらからのフォロー（2026-07-13 追加）

reply の対象を眺める中で、好意的な反応をしている個人アカウントを見つけたら候補として提示する。詳細ルールは `docs/x-reply-strategy.md`「こちらからのフォロー運用」節。1日5人上限、bot・相互フォロー狙いアカウントは除外。**実行（フォローボタンを押す）は Owner。**

## 実況タイムラインへの参加（2026-07-13 追加）

試合日（土日）は通常の Tier 1/2 reply に加え、中継中の実況ハッシュタグタイムラインでの reply も候補に含める。ハッシュタグは放送ごとに変わるため Owner が配信画面等で確認したものを使う（推測で固定タグを使わない）。詳細は `docs/x-reply-strategy.md`「実況タイムラインへの参加」節。中継中は反応速度優先のため下書きは1案で出す。

## やらないこと

- X への自動投稿（`fix-disable-x-auto-post.md` で停止済み。復活提案もしない）
- 実データにない統計の創作（成功率%・ポゼッション等。[[project_content_fabrication]] のルール）
- 他人のポストの全文引用（15語超の引用禁止）
