# サイト内コンテンツ企画

Tryline 本体に載せるコンテンツ（growth-playbook S7 系）の企画。note 記事は `note-weekly`、X は `x-post` が担当。このスキルは**検索需要に応えるサイト内の資産**を作る企画。

## 企画の型（需要ファースト）

1. **需要の証拠から始める**: GSC の実クエリ（`growth-analysis` で取得）に、応えられていない検索意図があるか。実証例: 「ラグビーワールドカップ 2027 日程」の需要発見 → `/c/rwc/2027` 強化（fix-rwc2027-hub-page-gate）
2. **既存データで応えられるか確認**: Tryline の強みは試合データ・順位・H2H・日程が既に DB にあること。**新規データ収集が要る企画はコストが跳ねる**ので、既存データの見せ方を変えるだけで応えられる企画を優先
3. **競合の空き地か確認**: `competitor-watch` で日本語圏に同等コンテンツがないか
4. **spec 化**: 企画が固まったら `spec-writing` で Codex に渡す

## 既存のコンテンツ資産（重複企画を避ける）

- 大会ガイド（`competitions` テーブルの guide、`feat-competition-guides.md`）— 全大会に概要・見どころ・視聴方法あり
- 週次カレンダー（`/calendar`）、H2H ページ（200件）、チームページ（90件）
- エバーグリーン構想の過去 spec: `feat-evergreen-competition-guides.md`、`feat-competition-guides.md`、`p3-rwc-2027-prep.md`

## 有望な企画領域（2026-07 時点の状況から）

- **RWC2027 関連**: 唯一実需要が確認済みの成長クエリ群。観戦ガイド・出場国紹介・過去大会アーカイブ活用
- **「視聴方法」系**: 「◯◯ 放送 日本」系クエリは常設需要。大会ガイドの視聴方法節の独立ページ化・鮮度維持
- **入門・用語解説**: ターゲット（日本語で海外ラグビーを追いたいファン全般）の入口。ドメイン権威が乗れば効く

## 判断基準

- 各企画に「狙うクエリ / 応える既存データ / 実装コスト（I×E）」を必ず添える
- 検索需要の証拠がない思いつき企画は「仮説」と明示し、優先度を上げない
- MVP 機能膨張（CLAUDE.md アンチパターン）に該当しないか自問する
