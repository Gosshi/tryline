# note 記事ドラフト

note（@tryline_rugbyjp）の記事ドラフトを作る。**公開するのは Owner（月曜午前が基本）。**

## 権威ドキュメント

- 運用 playbook: `docs/note-owned-media-playbook.md`（テンプレ・SEO 設定・チェックリストの原本）
- 過去記事の例: `docs/note-weekly-roundup-2026-06-08.md`、`docs/notes/` 配下

## 記事の型（2種）

1. **週次まとめ**（毎週・月曜午前公開）: playbook §2 のテンプレを埋める。大会ごとに結果＋一言
2. **エバーグリーン**（月1〜2）: 入門・解説記事。playbook §3 の候補リストから

## 手順（週次まとめ）

1. 週末の試合結果を取得: `prod-investigation` スキルで DB から、またはサイトの `/calendar`・各大会ページから転記
2. playbook §2 テンプレに流し込む。一言コメントは各試合の recap「この試合の核心」を**要約・言い換え**（コピペしない）
3. 送客導線を必ず3点入れる: ①primary サンプル recap へのリンク（現在の primary は `lib/sample-matches.ts` を確認）②X プロフィールへの一言 ③関連試合の Tryline ページへの内部リンク
4. タイトルは「海外ラグビー週末まとめ（YYYY年M月D日週）｜大会名」形式
5. ドラフトは `docs/notes/YYYY-MM-DD-weekly.md` に保存（既存の命名に合わせる）

## 絶対ルール

- **recap 全文を転載しない**（要約＋送客のみ。重複コンテンツで両方沈む）
- 数値は**得点経過ベースのみ**。成功率%・テリトリー%等の捏造統計を書かない
- 直接引用は最小限・言い換え原則
- 公開前チェックリスト（playbook §8）を必ず通す

## 公開後

X での単独告知より、関連する既存スレッドへの reply で「補足」として使う（`x-reply` スキル参照）。
