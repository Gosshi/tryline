# note 記事ドラフト

note（@tryline_rugbyjp）の記事ドラフトを作る。**公開するのは Owner（月曜午前が基本）。**

## 権威ドキュメント

- 運用 playbook: `docs/note-owned-media-playbook.md`（テンプレ・SEO 設定・チェックリストの原本）
- 過去記事の例: `docs/note-weekly-roundup-2026-06-08.md`、`docs/notes/` 配下

## 記事の型（2種）

1. **週次まとめ**（毎週・月曜午前公開）: playbook §2 のテンプレを埋める。大会ごとに結果＋一言
2. **エバーグリーン**（月1〜2）: 入門・解説記事。playbook §3 の候補リストから

## 手順（週次まとめ）

1. 週末の試合結果を取得: `prod-investigation` スキルで DB から、またはサイトの `/calendar`・各大会ページから転記
2. 各試合の一言は `match_content`（`content_type='preview'`）の予想と recap「この試合の核心」を**対比**させて書く（例:「プレビューでは○○が優勢と見られていたが、実際は××が逆転」「プレビュー通り接戦に」）。プレビューは平均得点・勝率・直接対戦成績などの**具体的な数字を1つ以上引用**して対比を厚くする（`/matches/[id]` ページはプレビュー・レビューとも試合後もそのまま公開され続けるため、note 側で数字を要約引用しても情報の重複にはならない。2026-07-06 Owner確認済み）。プレビュー本文・recap 本文は**要約・言い換え**し、コピペしない。**各試合1行だけの一言は情報量不足**（2026-07-06、拡充前は閲覧が伸びず反省点として判明）。最低でも3〜4文の段落にする
3. 送客導線を必ず3点入れる: ①primary サンプル recap へのリンク（現在の primary は `lib/sample-matches.ts` を確認）②X プロフィールへの一言 ③各試合の Tryline `/matches/[id]` ページへの内部リンク（プレビュー・レビュー両方読める旨がわかるリンク文言にする、例:「試合ページ(プレビュー・レビュー日本語)」）
4. タイトルは「海外ラグビー週末まとめ（YYYY年M月D日週）｜大会名」形式
5. **ハッシュタグを生成**（playbook §5 の2〜4個は最低ライン。複数試合を扱う週次まとめは同ルールの通り増やしてよい）: 固定枠 `#海外ラグビー` `#ラグビー` ＋ その週の目玉大会名（例:`#ネーションズチャンピオンシップ` `#プレミアシップ`）＋ 日本代表が絡む週は `#日本代表` ＋ **登場チームのうち有名な愛称を持つチームのタグを追加**（例:ニュージーランド→`#オールブラックス`、南アフリカ→`#スプリングボクス`、オーストラリア→`#ワラビーズ`、アルゼンチン→`#ロス・プーマス`）。愛称の無いチーム（イングランド・アイルランド・ウェールズ・スコットランド・イタリア・フィジー等）は無理に作らず割愛。本文とは別に「推奨ハッシュタグ」として本文末尾に明記し、note投稿画面のタグ欄に設定する旨を書く（本文中には含めない）
6. **見出し画像プロンプトを生成**: `image-gen` スキルを使い、その週の目玉（大会名・注目カード等）を反映した英語プロンプトを1本作る。`image-gen` の必須末尾制約・失敗パターン対策句を必ず反映する。特定の選手・チームの勝敗を画像内容で示唆しない（普遍的なムード表現に留める）
7. ドラフトは `docs/notes/YYYY-MM-DD-weekly.md` に保存（既存の命名に合わせる）。本文末尾に「推奨ハッシュタグ」「見出し画像プロンプト」の2セクションを追記する（どちらも note 本文には含めず、投稿画面の別欄に設定する運用メモとして残す）

## 絶対ルール

- **recap 全文を転載しない**（要約＋送客のみ。重複コンテンツで両方沈む）
- 数値は**得点経過ベースのみ**。成功率%・テリトリー%等の捏造統計を書かない（プレビューに実際にある数値の言い換え引用は可）
- 直接引用は最小限・言い換え原則
- 各試合は最低3〜4文（プレビューの予想との対比を含む）。1行のみの一言は避ける
- 公開前チェックリスト（playbook §8）を必ず通す

## 公開後

X での単独告知より、関連する既存スレッドへの reply で「補足」として使う（`x-reply` スキル参照）。
