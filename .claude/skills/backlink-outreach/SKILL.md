# 被リンク獲得（S3）支援

新規ドメインの権威ゼロが SEO の最大ボトルネック（`docs/growth-playbook-2026-06.md` S3、目標: 参照ドメイン 0→10+）。**登録・送信・投稿の実行は Owner**。Claude Code は候補整理・文面ドラフト・効果確認まで。

## 打ち手の優先順位（コスト低い順）

1. **自前チャネルからのリンク**: note 記事→Tryline の内部リンク（既に機能中。`note-weekly` スキルの送客3点セット）、X bio・note プロフィールの URL 確認
2. **リンク集・ディレクトリ登録**: 国内のラグビー系リンク集、スポーツサイトディレクトリ、個人ブログの相互リンク。WebSearch で「ラグビー リンク集」「ラグビー ブログ」等を調査し、登録可否・申請方法を一覧化
3. **言及依頼（アウトリーチ）**: ラグビー系ブロガー・note 書き手・サイト運営者へ「データ引用元としての紹介」を打診。`docs/x-reply-strategy.md` の Tier 2（@New_Lenny5959 = Lenny's Rugby 等）はコラボ候補
4. **Wikipedia 出典提案**: 試合結果・順位の出典として妥当な範囲のみ。**宣伝的な追加はしない**（コミュニティガイドライン違反はドメイン評価を毀損する。判断に迷う場合はやらない）

## 打診文ドラフトの作法

- 相手のコンテンツを読んでから書く（テンプレ一斉送信の文面は作らない）
- 提供価値を先に: 「全大会横断の JST カレンダー」「日本語の試合レビュー」「H2H データ」等、相手の読者に役立つものを具体的に
- 見返り要求を条件にしない（「リンクしてくれたら〜」は書かない）
- 各ドラフトに送信先・送信方法（問い合わせフォーム/DM/メール）を添えて Owner に渡す

## 進捗トラッキング

- 申請・打診の記録は `docs/backlink-outreach-log.md` に表形式で（日付 / 相手 / 手段 / 状態 / 結果 URL）。無ければ初回に作成
- 効果確認: GSC の「リンク」レポート（Owner が GSC UI で確認）、Ahrefs 等は未契約なので `growth-analysis` の実測でオーガニック変化を見る

## 制約

- 有料リンク・リンクファーム・相互リンク大量交換は提案しない（ペナルティリスク）
- 外部サイトへのフォーム送信・投稿は Owner が行う（Claude Code は下書きまで）
