# X 投稿ドラフト

@tryline_rugbyjp の自発ポストの下書きを作る。**投稿するのは Owner。自動投稿は停止済み**（`specs/fix-disable-x-auto-post.md`）で復活させない。

## 投稿の型（この4種のみ）

1. **試合結果**: スコア＋一言（レビューの「この試合の核心」から要約。全文コピペしない）
2. **週末プレビュー**: 「今週末の海外ラグビー」— カレンダーページのデータから注目3〜5試合を JST 付きで
3. **note 連動**: note 記事公開の告知。ただし単独告知より既存スレッドへの reply 転用を優先（`docs/x-reply-strategy.md` の note 連動節）
4. **試合日ライブ**: キックオフ前後の速報・寸評（playbook X4。週末の注目試合に集中）

## ルール

- **1日1〜3投稿まで**。連続大量投稿はしない（2026-05-23 の教訓）
- **ネイティブ投稿優先**: 外部リンクは reach を下げる。URL は本文でなく 1st reply に置くか省略。リンク付き投稿は1日1回まで（playbook X3）
- 数字は実データのみ（Supabase / サイト表示から転記。捏造統計禁止）
- ハッシュタグは `#海外ラグビー` ＋大会タグ（`#URC` 等）を1〜2個まで
- 画像を添える場合は `image-gen` スキルの制約（実在ロゴ・選手・ユニフォーム禁止）に従った生成画像か、サイトのスクリーンショット

## データ取得

- 今週の試合: `https://www.trylinerugby.com/calendar` または `prod-investigation` スキルで DB から
- 試合結果・レビュー要約: 該当 `/matches/[id]` ページの「この試合の核心」

## 出力

各投稿につき2案（真面目トーン / 熱量トーン）。文字数を明記し、URL の有無と配置（本文 or 1st reply）を指定して Owner に渡す。
