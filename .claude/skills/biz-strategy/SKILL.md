# 事業戦略の壁打ち

Owner の戦略判断を支援する。**方向性を決めるのは Owner**。Claude Code は選択肢・トレードオフ・過去の判断との整合を示す。

## 前提（North Star と制約）

- **主要成功指標**: RWC 2027（2027年10〜11月）までの有料購読者数。¥980/月 Premium + 無料層（CLAUDE.md）
- **コスト構造**: 月 $25〜30。有料数人で黒字化（メモリ `project_growth_strategy`）
- **現状**: 実ユーザーほぼゼロ（GA4 約4〜5セッション/日）。ボトルネックは製品ではなく**発見（distribution）**
- **ファネル診断**: 認知→お試し→納得→課金のうち「認知」が最初の壁（Gemini レポート 2026-05-20）

## 壁打ちの手順

1. **過去の判断を先に確認**: `docs/decisions.md`（D001〜）、メモリの方針系（英語ニッチ・AI ラベリング・集客チャネル B+X 等）。**既に決まったことを蒸し返さない**。覆す提案をするなら「何が変わったから再検討に値するか」を明示
2. **直近の診断を土台に**: `docs/pmf-audit-2026-06-10.md`（PMF監査）、`docs/growth-audit-2026-07-01.md`、`docs/design-ui-growth-review-2026-07-03.md`
3. **評価軸は I×E マトリクス**（growth-playbook Part 3 の型）: インパクト(1-5) × 実装コスト(1-5) で Quick Win / Big Bet / Fill-in / Thankless に分類
4. **機能追加の提案には常に問う**: それは RWC2027 までの購読者数に効くか？ Phase 1 spec に無い機能膨張ではないか？（CLAUDE.md アンチパターン）

## 議論でよく使う分解

- **レバー種別**: Codex で解ける（技術）/ Owner の手動運用（X reply・被リンク・note）/ 待ち（インデックス自然増・シーズン開幕）
- **時間軸**: 今すぐ（〜2週）/ 短期（1ヶ月）/ RWC2027 に向けた中期
- **投資対効果の実測主義**: 「note 8セッション > X 3セッション」のように、実測が出ているチャネルを基準に配分を語る

## 出力

- 結論は「推奨＋理由＋捨てた選択肢」の形（網羅的な選択肢羅列で終わらない）
- 実行が Codex 向けなら spec 化候補として挙げる（起票は Owner 判断）
- 決定に至ったら `docs/decisions.md` への追記文案（D0XX 形式）を出す
