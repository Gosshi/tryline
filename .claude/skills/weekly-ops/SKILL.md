# 週次運用ルーティン

`docs/x-reply-strategy.md` の週次オペレーション（週5時間以内）を回すための司令塔スキル。各作業は専用スキルに委譲する。

## 週次チェックリスト（月曜起点）

### 1. note 週次まとめ（月曜午前公開）→ `note-weekly` スキル
- [ ] 週末の試合結果から記事ドラフト作成
- [ ] primary サンプル（`lib/sample-matches.ts`）が最新の好試合か確認。古ければ差し替えを Owner に提案

### 2. X 運用の週次計画 → `x-reply` / `x-post` スキル
- [ ] 今週の試合カレンダーから「reply が盛り上がりそうな試合日」を特定（週末に比重）
- [ ] note 公開後の reply 転用先スレッド候補を1〜2件

### 3. 数字のクイックチェック（5分版）→ 深掘りは `growth-analysis` スキル
- [ ] GA4 で先週のセッション数・チャネル内訳（前週比）
- [ ] X プロフィールアクセス・フォロワー（Owner が X アナリティクスで確認）
- [ ] note PV（Owner が note ダッシュボードで確認）
- 数字の異変（急増・急減）があれば `growth-analysis` で深掘り

### 4. リンク・導線の保守（月1回程度でよい）
- [ ] X bio・note プロフィールの URL が生きているか
- [ ] pricing・サンプルへの導線が壊れていないか（`funnel-audit` スキル）

## 記録

週次の実施記録は `docs/notes/YYYY-MM-DD-weekly.md`（note ドラフトと同居でよい）に残す。数値は「実測値＋期間」を明記（`growth-analysis` の出力規約と同じ）。

## 原則

- **10分/日・週5時間の枠を超える提案をしない**（中途半端な運用が最もコスパが悪い。growth-playbook X2 の教訓）
- 実行（投稿・公開・送信）はすべて Owner。Claude Code はドラフト・チェック・数字取得まで
- 目標値は growth-playbook「追記（2026-07-02）」の下方修正版を正とする（1ヶ月: 反応が週次で発生 / 3ヶ月: フォロワー30〜50・X経由セッション月10+）
