# 競合・市場ウォッチ

Tryline の競合・代替手段を調査し、差別化と「真似るべき点」を整理する。

## 競合の分類

| 層 | 例 | Tryline との関係 |
|----|-----|-----------------|
| 英語グローバル | RugbyPass、ESPN Rugby、BBC Sport、Planet Rugby | データ量・速報性で勝てない。「日本語・JST・深掘り」で差別化 |
| 日本語メディア | rugby-rp.com（ラグビー共和国）、J SPORTS コラム、Yahoo!ニュース個人 | 海外リーグの試合単位カバレッジが薄い領域が Tryline の空き地 |
| 個人発信 | note のラグビー書き手、X の観戦勢、YouTube 解説 | 競合であり被リンク・コラボ候補でもある（`backlink-outreach` と接続） |
| 代替行動 | 「英語のまま公式を読む」「ハイライトだけ見る」「何も追わない」 | 最大の競合は無関心。入門コンテンツの意義 |

## 比較軸（毎回この表で揃える）

対象ごとに: カバー大会 / 日本語対応 / 試合単位の深掘り有無 / データ（スタッツ・H2H）/ 料金 / 更新頻度 / SEO 強度（検索での露出感）

## 調査の作法

- WebFetch で対象サイトの公開ページを見る（ログイン・課金が必要な領域は Owner に確認）
- 機能スクショの転載はしない。文章で記述
- 「彼らがやっていて Tryline に無いもの」を見つけたら、即座に機能追加提案にしない。**RWC2027 までの購読者数に効くか**（`biz-strategy` の問い）を通してから spec 候補に

## 出力

- 比較表＋「差別化の再確認」＋「真似る価値のある UI/コンテンツパターン」の3点セット
- 発見が戦略に関わるなら `biz-strategy`、デザイン系なら `site-audit` のレポートに接続
