# note オウンドメディア運用 playbook — 2026-06

> note を「週次で回す発見エンジン」にするための手順書。
> 今 X はシャドウバン回復中で reach がほぼ0。**note は無傷で動く唯一の能動チャネル**であり、SEO・被リンク・X プロフィールへの送客を同時に担う。

## 0. note の役割（なぜやるか）
- **SEO**: note 記事自体が検索に乗る（ドメインが強い）。新規ドメインの Tryline より早く拾われる。
- **送客**: 記事から Tryline（全文 recap）と X プロフィールへ流す。
- **被リンク源**: note→Tryline のリンクが参照ドメインを増やす（[[project_growth_strategy]] の被リンク目標に寄与）。
- **X 回復中の代替導線**: 記事から **@tryline_rugbyjp** のプロフィールへ送れば、タイムラインが沈んでいても**プロフィール直アクセスの28% はクリックする**（実測）。note が X 成長の入口になる。

## 1. 絶対ルール（重複コンテンツ回避）
- **recap 全文を note に転載しない**。note は **要約＋送客**のみ。全文は Tryline 側（でないと Google が重複判定し両方沈む）。
- 数値は**データにある得点経過のみ**。成功率%・テリトリー%等の捏造統計は書かない（[[project_content_fabrication]] のルール）。
- 直接引用は最小限・言い換え原則（著作権配慮）。

## 2. 週次の型 ―「週末まとめ」（毎週・月曜午前公開）
**狙い**: 週末に終わった海外ラグビーを日本語でざっと把握したい層を捕まえる。検索需要が立つ月曜朝に出す。

### テンプレ（毎週これを埋めるだけ）
```
タイトル: 海外ラグビー週末まとめ（YYYY年M月D日週）｜Premiership・Super Rugby ほか

【リード】
今週末の海外ラグビーの主要な試合を、日本語でざっと振り返ります。

## Premiership（イングランド）
- {ホーム} {スコア} {アウェイ}：{一言・得点経過ベース}

## Super Rugby Pacific（南半球）
- {ホーム} {スコア} {アウェイ}：{一言}

## URC / Six Nations 等（開催中の大会）
- ...

【送客】
各試合の「得点経過・流れ・見どころ」は Tryline で日本語の詳しいレビューにしています。1本、全文を無料で置いておきます👇
→ {primary サンプルの試合名} 全文レビュー
{primary サンプルURL}

Tryline では8大会・週10試合以上をこの形で。X（@tryline_rugbyjp）でも毎週末お届けします。
```

### 運用
- **公開: 月曜 午前**（週末試合の検索需要に間に合わせる）。
- 試合・スコアは Tryline の管理画面/サイトから転記（実データ）。
- **送客リンクは primary サンプル**（現状 Northampton 36-32 Gloucester＝全文無料）＋ X プロフィール。

## 3. エバーグリーン記事（月1〜2・検索の土台）
週次まとめと別に、**陳腐化しない入門/解説**を不定期で。検索需要が安定し、長く効く。
- 「海外ラグビーの見方・どこで観られる？（DAZN/J SPORTS/WOWOW 早見表）」
- 「Six Nations とは？／Super Rugby Pacific とは？ 日本人向け入門」
- 「ラグビーの基本用語（ラインアウト・ブレイクダウン等）をやさしく」
- 各記事の末尾に Tryline サンプル＋X 送客。

## 4. 送客導線（全記事に必ず）
1. **Tryline サンプル recap**（全文無料）へのリンク1本。
2. **X @tryline_rugbyjp** への一言（「Xでも毎週末お届け」）。
3. （任意）記事中で関連試合の Tryline ページへ内部リンク（被リンク効果）。

## 5. SEO 設定（note 側）
- タイトルに**キーワード＋日付/大会名**（「海外ラグビー 週末まとめ 6月1日週」等）。
- ハッシュタグ: #ラグビー #海外ラグビー #Premiership 等を2〜4個。
- 1記事 1テーマ・見出し（##）で構造化。
