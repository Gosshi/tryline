# 【今週のラグビーまとめ】リーグワン決勝、コベルコ神戸が初制覇。海外もトライ祭りの週末（2026.6.1–6.7）

国内外で見どころの多い週末となった。最大のトピックは、ジャパンラグビー リーグワンの決勝――コベルコ神戸スティーラーズの初戴冠だ。海を渡れば、プレミアシップ、URC、スーパーラグビー・パシフィックも大詰めを迎え、各地でトライが乱れ飛んだ。今週の主な結果をまとめて振り返る。

## ジャパンラグビー リーグワン（最終週）

### 決勝（6/7・国立競技場）｜コベルコ神戸スティーラーズ 22-13 クボタスピアーズ船橋・東京ベイ

神戸がリーグワン初制覇を果たした。

立ち上がりはクボタのペース。16分にバーナード・フォーリーのペナルティゴールで先制すると、22分にもフォーリーが3点を加え、25分には為房慶次朗がトライ。コンバージョンも決まり、クボタが13点を先行した。

しかし神戸も崩れない。19分の李承信のペナルティゴールで食らいつくと、29分にイノケ・ブルアがトライ。李のコンバージョンで10-13と迫り、40分の李のペナルティゴールで **13-13** に追いついて前半を終えた。

勝負を決めたのは後半の神戸の10番だった。43分、李承信のペナルティゴールで16-13と勝ち越すと、52分、80分にもペナルティゴールを重ね、後半はこの李のキックだけでスコアを伸ばした。守ってはクボタを後半無得点に封じ、**22-13** で逃げ切り。

この日のMOMはブロディ・レタリック。ラインアウトと接点で優位を握り、後半の完封を支えた。スコア面では李承信が5本のペナルティゴールと1本のコンバージョンで計17点をマークし、神戸の全得点に絡んだ。前線を牽引したレタリックと、確実に得点へ変えた李――両輪の噛み合った、王者にふさわしい勝ち方だった。

### 3位決定戦（6/6・秩父宮）｜埼玉パナソニックワイルドナイツ 26-19 東京サントリーサンゴリアス

3位を争った一戦は、東京サントリーが18分の松島幸太朗のトライ（ケイレブ・トラスクのコンバージョン）で先制し、7-0とリードして試合を進めた。

流れが変わったのは後半開始直後。41分の小山大輝のトライと楢本幹志朗のコンバージョンで埼玉が同点に追いつくと、トラスクのシンビン（一時退場）で数的優位に立った埼玉が、島根一磨、楢本、モーリス・マークスと立て続けにトライを奪い、一気に突き放した。東京サントリーも尾崎泰雅の2トライで意地を見せたが、及ばず。埼玉が **26-19** で逆転勝ちし、3位を確保した。

なお、東京サントリーでは流大、中村亮土が現役最後の試合に出場。両ベテランの花道となる一戦でもあった。

## 海外リーグ 週末の主な結果

ヨーロッパも南半球もシーズン終盤。攻撃ラグビーが映える好ゲームが並んだ。

### プレミアシップ（イングランド）｜バース 24-22 レスター・タイガース

合計7トライの撃ち合いを、バースがわずか2点差で振り切った。主役はバースのドゥトイ。一人でハットトリックを達成し、勝利の立役者となった。バースはこのほかジョー・コカナシガもトライを記録。レスターもベイリー、ピアソン、そして スクラムハーフのファンポルトフリートがトライを返し、最後まで食い下がったが、わずかに届かなかった。1トライ＝勝敗を分けかねない緊張感が、最後まで続いた一戦だった。

### URC｜準決勝（アイルランド・南ア・スコットランド・ウェールズ・イタリア）

URCは準決勝の2試合。

**グラスゴー・ウォリアーズ 21-22 ブルズ**
ホームのグラスゴーとブルズが1点差で並ぶ大接戦を、南アの強豪ブルズが守り切り、決勝進出を決めた。

**レンスター 20-11 ストーマーズ**
欧州屈指の強豪レンスターが地力を発揮。ストーマーズを9点差で下し、決勝へ駒を進めた。

### スーパーラグビー・パシフィック（NZ・豪・太平洋）｜トライ量産の南半球

NZ勢が軒並み大量得点で快勝し、攻撃力の高さを見せつけた。

**ハリケーンズ 66-12 ブランビーズ**
週末屈指の大勝。ハリケーンズが9トライを奪い、ブランビーズを圧倒した。プニヴァイがハットトリック、オールブラックスのスクラムハーフ、カム・ロイガードが2トライ。さらに **日本代表のウォーナー・ディアンズ** もこの試合で2トライを挙げる活躍を見せた。ブランビーズはコーリー・トゥール、テイン・エドメドの2トライにとどまった。

**クルセイダーズ 52-31 ブルーズ**
両者合わせて13トライという壮絶な撃ち合いを、王者クルセイダーズが制した。ジョニー・マクニコルがハットトリックを達成し、セブ・リース、デイビッド・ハヴィリらも続いた。ブルーズもケイレブ・クラークらが5トライを返して食い下がったが、地力の差が出た。

**チーフス 46-24 クイーンズランド・レッズ**
チーフスはダミアン・マッケンジーとカイレン・タウモエフォラウがそろって2トライずつをマーク。サミソニ・タウケイアホらも加わり、計6トライで快勝した。レッズも3トライを返したが、終始チーフスがゲームを支配した。

## 来週へ

リーグワンは神戸の初戴冠でシーズンが幕を閉じた。一方、海外の各リーグはこれからが佳境。優勝の行方、そして日本代表のウォーナー・ディアンズら、日本にゆかりの選手たちの活躍からも目が離せない。来週も熱い週末になりそうだ。
