## 0. ブリーフの事実への訂正を1点だけ先に

ブリーフは「課金関連テーブルは存在しない」としたが、本番実測では**決済レールは実装済み**である。

- `/api/stripe/checkout` `/api/stripe/webhook` `/api/stripe/portal` が存在
- `user_profiles` に `stripe_customer_id` / `stripe_subscription_id` / `subscription_status` / `premium_until` を保持
- 本番実データ: 3プロファイル中 premium 2件（いずれも `premium_source='manual'` = Owner 手動付与）、free 1件。**Stripe を通過した有料転換は 0 件**

したがって正しい問題設定は「課金の仕組みを作る」ではなく、ブリーフの中心的な問いそのもの——**「レジは開いているのに誰も店に来ない」**——である。本ロードマップはこの前提で組む。

## 2. なぜ誰も来ないのか（実測に基づく診断）

ブリーフの中心的な問いに、8月実測で答える。

### 2.1 「順位が取れていない」のではない。「需要の谷」+「Google の権威不足」の複合である

- GSC 実測（7/10〜8/6）: 大会ハブは既に **6〜12位**（シックスネーションズ順位系 8.4位、プレミアシップ 10.3位、Top 14 6.4位）。順位はあるのにクリックが出ないのは、**閑散期でクエリ需要自体が月数十インプレしかない**から
- 一方 RWC 系は実需要（「出場国」9.0位は取れているが「日程」23.1位、`/c/rwc` 34.7位）で**上位を取り切れていない**。ここは唯一「順位側」に伸び代がある
- **結論: SEO 実装・コンテンツ品質の問題ではない。8月に流入がないのは構造的。検証は需要が返る11月と2027年2月にしかできない**

### 2.2 Bing が Google の2.7倍という歪み = Google の権威だけが未解放

直近28日の検索流入: **Bing 119 セッション vs Google 44**。IndexNow（Bing 即時反映）は機能しており、コンテンツは検索需要を満たせている。Google だけが新規ドメインへの権威評価を留保している。被リンク獲得は枯渇確認済み（再提案しない）ので、**Google の権威は「指名検索・再訪・ピークシーズンのエンゲージメント」で作るしかない**。裏返せば、Google が開けば検索流入は現状の数倍になる余地が実測で示されている。

### 2.3 チャネルの地図が3ヶ月で塗り替わった

- **X 46 セッション/28日 > note ≈0**。2026-07-01 時点の「note(8) > X(3)」は逆転した。reply-first 転換（D012）は referral として機能し始めている
- blogmura（ブログ村）経由 11 セッション——ディレクトリ登録が小さく機能している
- 8/8 日本×豪州の投稿でインプレッション60（4週間目標50を達成）。X の4週間 KPI は順調

### 2.4 転換ファネルは「未検証」ですらなく「未通電」

`/pricing` の閲覧は **4 PV/28日**。訪問→登録→有料のどこが折れているかを議論できる標本すらない。**転換率の議論はトラフィックが先**であり、ペイウォール・価格の再設計をこの段階でやるのは順序が逆（既存 spec 群で実装済みの装置をそのまま使う）。

### 2.5 リテンション装置がゼロ = 来た人が一度きりで消えている

- `push_subscriptions` **0件**、メール捕捉フォーム未設置、LINE なし
- 11月遠征で仮に 1,000人来ても、再訪の仕組みがなければ全員消える。**ピーク前に「掴む装置」を用意することが、トラフィック増施策と同じ優先度**

### 2.6 供給側に1つだけ穴がある

本番 DB 実測: 2026-08-09 以降の登録試合は Greatest Rivalry(7)・Lipovitan(3)・Nations Cup(2)・NC 2026(18)・Six Nations 2027(15) のみで、**2026-27 欧州クラブシーズン（Premiership / URC / Top 14、9月末〜10月開幕）が未登録**。GSC でプレミアシップ順位系クエリが10位に表示されている（=需要はある）のに、新シーズンが始まると順位表・日程が空になる。934本の資産を無視した「コンテンツ増産」提案はしないが、**これは増産ではなく既存カバレッジの継続**であり、放置すると2.1で確認した「取れている順位」を失う。

## 3. 収益化方針

### 3.1 維持するもの（再設計しない）

- **Freemium + ¥980/月**（D005）。変更を正当化する転換データが存在しない
- **Web Stripe 決済**（実装済み・§0）+ ペイウォール/価格ページ（既存 spec 群で完成済み）
- **note は収益化しない**（D013）。収益は Tryline 本体に一本化

### 3.2 追加するもの

1. **iOS IAP（RevenueCat）** — App Store 審査は Guideline 3.1.1 で却下済み、RevenueCat 実装は決定済み（`specs/feat-ios-in-app-purchase.md` 起票済み）。**9月中の再審査・公開が Phase 0 の最重要マイルストーン**（D014: スパイク前に App Store 評価を貯める逆算）
2. **年額プラン（新提案）** — RWC 2027 は10〜11月の6週間。月額のみだと「RWC の2ヶ月だけ課金して解約」が合理的行動になる。RWC 前（2027年前半）に年額 ¥9,800（2ヶ月分割引）を投入し、スパイクを年間契約に変換する。Stripe の Price 追加 + pricing ページ改修で済み、実装コストは小さい。**投入は Six Nations 2027 で転換の初実績が出てから**（転換ゼロの段階で価格体系を増やしても標本が割れるだけ）
3. **Vercel Pro 移行** — 課金者が発生した時点で Hobby の商用利用制限に抵触するため、**最初の有料転換の前に** Pro（$20/月）へ移行する。§1 のコスト計算に織り込み済み

### 3.3 やらないもの

- 広告モデル（トラフィック規模が3〜4桁足りない）
- note 有料記事・メンバーシップ（D013）
- 価格改定・ペイウォール位置の再設計（転換標本ゼロでは判断材料がない。Six Nations 2027 で標本が出てから）
