## 1. 結論

**Tryline の問題は「サイトの出来」ではなく「発見（distribution）」である。これは 06-01 の診断から変わっていないが、7月時点で技術 SEO の衛生修正はほぼ完了しており、残る変数は3つに絞られた。**

1. **RWC2027 と大会ハブへの SEO 集中** — GSC で実需要が確認できた数少ない領域（PNC 2026 で順位10位・クリック発生、RWC クエリでインプレッション発生中）。ここに常設ページと内部リンクを集中させる。
2. **X の reply 運用＋データ画像投稿の継続実行** — 決定済み（07-02）だが、数字に出るまで90日は判断を変えない。フォロワー100が最初のマイルストーン。
3. **note → サイトの送客導線強化** — 現時点で note(8) > X(3) セッション/28日。既に機能している唯一の referral チャネルを太くする。

**やらないことも同じくらい重要**: ニュース速報の量産（ラグリパと同じ土俵）、Instagram/YouTube の新規立ち上げ、広告出稿（転換実績ゼロの段階では捨て金）、海外リーグの英語展開。

短期（90日）は「PNC/NC/Rugby Championship の進行中大会×検索とX」、中長期（〜2027年11月）は「RWC2027 SEO 資産の複利」に賭ける。

### 2.3 X アカウント診断

- 06-01 時点フォロワー0・インプレ7〜8/ツイート。自動リンク投稿が主因で reach 死亡 → 停止済み
- 07-02 に reply ファースト運用（毎日10分）を決定、データ画像投稿（スコアボード画像、週2〜3本）を追加済み
- **弱い理由は明確**: (a) 網（フォロー関係）ゼロ、(b) リンク投稿中心だった過去、(c) 会話の起点になる投稿形式がなかった

**07-13 実測（Owner が X アナリティクス CSV を提供、42投稿・約4週間分。同日に Codex 集計と突合して数値確定。初回集計の「フォロー2件・プロフィールアクセス1件」は列の読み違いで誤りだった）**:

| 指標 | 値 |
|---|---|
| フォロワー | 3（06-01 の0から +3） |
| 総インプレッション | 1,038（平均24.7/投稿、中央値17） |
| エンゲージメント | 65。うち詳細クリック37＋URLクリック17で約83%がクリック系。いいねは42件中1件のみ |
| エンゲージメント0の投稿 | 23/42件 |
| プロフィールへのアクセス | 4件 |
| 新規フォロー | 1件（7/1 南ア×イングランド開幕プレビュー投稿から） |

**わかったこと**:
1. Tier 0 公式アカウントへの reply（@JRFUMedia 129imp、@jsports_rugby 64imp）は単発リーチ最大化に効くが、フォロー転換ゼロ。内容が祝辞型（「素晴らしい勝利でした」）でフォロー理由を作れていなかった。「visibility大きいので慎重に」の既存警戒は実データで裏付け
2. 唯一の新規フォロー1件は、断定的な数字を冒頭に置いた単独試合プレビュー（インプレッションわずか7の投稿）から発生。露出が小さくても内容の型次第で転換は起きる（ただし N=1）
3. エンゲージメントの83%が記事クリック系＝読む意欲はあるが、いいね・reply・リポストの会話が発生しておらず、拡散の複利がゼロ
4. 同型フォーマットの連投（7/1 プレビュー6連投: 各4〜11imp、7/13 結果まとめ連投: 6〜24imp）はインプレッション最低帯。日付・大会名始まりの定型文が原因とみられる（新設大会の認知不足も7/1の低調には重なった可能性）

**判断（07-13 確定、X運用方針v2）**: チャネルへの投資継続という90日コミットは維持したまま、投稿フォーマットを実測に基づき修正する——1投稿=1メッセージ（冒頭に最も驚く事実）、分割連投廃止（強い1本＋スレッド）、引用リポスト解禁（海外ニュース＋日本語の付加価値必須）、タイムライン配分 50%独自分析/30%ニュース引用/20%会話、重心は日本代表＋その週の主要国際試合。立ち位置は「ニュースが日本語で分かり、次の試合への影響まで分かる」（速報の速さでは勝負しない）。詳細は `.claude/skills/x-post/SKILL.md`・`.claude/skills/x-reply/SKILL.md`・`docs/x-reply-strategy.md`（4週間プロセスKPI含む）。

### Tryline の差別化領域（競合が構造的に取れない場所）

1. **海外リーグの試合単位の日本語レビュー/プレビュー** — ラグリパも Just RUGBY も試合単位では書かない（物量的に不可能）。Tryline は LLM パイプラインで 904 件持っている。これは日本語圏で唯一。
2. **大会横断×日本時間の日程・順位ハブ** — J SPORTS は自局分のみ、公式は各大会単独。横断は空白。
3. **RWC2027 の日本語常設情報** — 大会1年前から積み上げれば、大手が本気を出す2027年夏より先にドメインへの評価を作れる。
4. **リーグワン⇔海外の接続コンテンツ** — 「リーグワンで見たあの選手が海外でどうプレーしているか」は両方を追う Tryline にしか書けない。

**試合ページ** — 現状で技術的にほぼ完成。追加は (a) 同大会ハブへのパンくず強化、(b) 「この試合を見た人向けの次の試合」導線、(c) H2H ページへのリンク。

**視聴方法ページ** — 大会別に「放送局・配信・料金・日本時間帯」の表1枚。年1回更新のエバーグリーン。※放送権は変動するため「{年}{月}時点」の明記と四半期見直しをルール化。

**初心者向け** — サイト内に単独ページは作らず、note「海外ラグビー観戦のはじめ方」→大会ガイドへ誘導（ビッグワード回避の側面戦）。

**週次観戦ガイド** — サイト（カレンダーページ）＋note（まとめ記事）＋X（データ画像）＋メール（digest）の4面に同じ編集素材を展開する「1素材4配信」を毎週のルーティンにする。

### 6.2 RWC2027 長期資産（いま仕込む理由: 大手参入前の15ヶ月）

- `/c/rwc/2027` ハブ（日程・日本時間・開催都市・チケット情報へのリンク）
- プール別ページ（抽選確定後）／出場国×チームページ接続
- 「RWC2027 への道」note シリーズ（月1、各国の予選・強化試合を追う）——大会前に「ずっと追ってきたサイト」という信頼を作る
- 過去大会 recap 資産があれば「前回大会の記録」として整理【要確認: RWC2023 データの有無】

### 6.3 SNS 向けコンテンツの型

- **保存されやすい**: 日本時間の週末観戦スケジュール画像／大会順位表画像／「この秋の海外ラグビー全日程」1枚もの
- **拡散されやすい**: 試合直後のスコアボード画像＋一言寸評（速報性×画像）／「リーグワンの◯◯、母国での成績がこれ」型の意外性データ／週末の結果総まとめ画像
- **会話が生まれる**: 「今週末どの試合見る？」アンケート／プレビューでの勝敗予想（note の予想×結果対比と連動）
