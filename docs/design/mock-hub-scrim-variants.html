判断のポイント

すべて「構造」ではなく「配合」の違いで、案B2 のレイアウトはそのまま。実装は app/c/[competition]/[season]/page.tsx:646 の background 値の差し替え（案A / 案C は要素を1つ追加）だけ。

判断は「写真をどれだけ見せたいか」対「色で大会をどれだけ識別させたいか」のトレードオフです。写真優先なら案A、識別優先なら案B、中間が案C。

なお現行がシックスネイションズで成立して見えるのは、あの大会の色がたまたま明るい青で、写真にも青い照明が入っているためです。他大会に一般化できません。
