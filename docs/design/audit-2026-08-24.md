## サマリ

1. **`design.md` と現行実装が別のデザインシステムになっている。** 権威文書は緑アクセント、セリフ見出し、カード半径 0.75rem を定義する一方、実装は赤 `#c93a40`、Zen Maru Gothic、カード系 `--radius-md: 1.375rem` を採用している（`design.md:90-100,102-109,123-136`、`app/globals.css:20-55`、`app/layout.tsx:14-25`）。個別違反を直す前に、Owner が「文書へ戻す／現行ブランドを文書化する」のどちらかを決めないと監査基準が安定しない。

- 確信度: 確実

- 根拠: `components/match-header.tsx:133-165,290-325`、`components/calendar/week-schedule.tsx:131-195`、`components/team-stats-panel.tsx:168-200`、global clip `app/globals.css:62-76`
- design.md の該当箇所: Layout
- 検索コマンド: `rg -n "min-w-\[[^\]]+\]|whitespace-nowrap|grid-cols-\[[^\]]+\]|overflow-x-auto" app components`
- 実測:
  - MatchHeader score: `min-w-[5.5rem] sm:min-w-[10rem]`。両側は `minmax(0,1fr)`、team name は mobile `break-words`（`components/match-header.tsx:133-165,304-320`）。
  - Calendar state: `min-w-[72px]`。mobile は親が `flex-col` なので同一行幅を奪わない（`components/calendar/week-schedule.tsx:131-195`）。
  - Team stats table: `min-w-[28rem]` だが `overflow-x-auto` 内（`components/team-stats-panel.tsx:168-200`）。
  - `html` と `body` は `overflow-x: clip`（`app/globals.css:62-76`）。
- 影響: 上記 3 箇所は静的構造上は対策がある。ただし global clip は新たな overflow を発見しにくくするため、将来の fixed width 追加時に「横スクロールしない」のではなく「内容が切れる」回帰を隠す可能性がある。
