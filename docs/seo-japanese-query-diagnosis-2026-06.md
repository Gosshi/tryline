# SEO 日本語クエリゼロ問題の診断（2026-06-10）

> `docs/growth-playbook-2026-06.md` の SEO 診断を補完する。  
> playbook は「ドメイン権威ゼロ」を主因としたが、本診断で **それと並ぶ構造的根因＝海外チーム/大会名が英語表記のまま** を新たに特定した。

## 症状（GSC・引き継ぎより）
- GSC 28日: 238 impressions / 5 clicks / 平均順位 32.8
- **検索クエリがほぼ全て「英語の選手名」。日本語クエリがほぼゼロ。**
- 日本語コンテンツ（recap 929件）が潤沢にあるのに、日本語検索に当たっていない。

## 根因（Supabase 実データで検証）

### 根因1: 海外チーム名が英語のまま（最重要・新発見）
`teams` テーブル 90件のうち:
- **英語名のみ（カタカナなし）: 78件**（＝海外チーム全部）
- 日本語名あり: 12件（リーグワンの日本チームのみ）
- `english_name` カラムは存在するが海外チームでは未使用（`name` に英語が入っている）

例: Chiefs / Crusaders / Hurricanes / Blues はすべて `name="Chiefs"` 等、`english_name=null`。

### 根因2: 大会名も全て英語
`competitions` 30件すべて英語表記（"Six Nations 2026" "Super Rugby Pacific 2026" "Premiership 2025-26" "URC 2025-26" 等）。
`formatCompetitionTitle`（`lib/format/competition.ts`）が日本語化するのは **リーグワンのみ**。海外大会は素の英語。

### 根因3: 試合ページのタイトル/メタが英語
`app/matches/[id]/page.tsx:81` のタイトル生成:
```
`${match.homeTeam.name} vs ${match.awayTeam.name} — ${competitionTitle}`
→ 例: "Chiefs vs Crusaders — Super Rugby Pacific 2026"
```
日本語ページ（`/matches/[id]`）でも **タイトル・h1・構造化データのチーム/大会名が英語**。
meta description は地の文だけ日本語（「…の試合結果・日本語レビュー」）でチーム名は英語。

### 根因4: recap 本文すらほぼ英語表記
`match_content`（content_type=recap, language=ja）929件のうち、有名カタカナ8チーム名
（チーフス/クルセイダーズ/ハリケーンズ/ブルーズ/スプリングボクス/オールブラックス/ハイランダーズ/ブランビーズ）を含むのは **33件（3.6%）のみ**。
→ ナラティブ生成 LLM も team 名を英語で書いている。**タイトルも本文もカタカナがない。**

## なぜ「英語の選手名」だけがヒットするのか
選手名は recap 本文に登場し（一部）、かつ英語選手名は世界共通表記。一方チーム/大会名は英語のまま競合（公式・大手メディア）と同じ土俵で戦い、権威ゼロのため上位に出ない。結果、たまに拾えるのが英語選手名のロングテールだけ、という GSC の症状と完全に一致する。

## 結論
日本のラグビーファンは **カタカナで検索する**（「チーフス」「スーパーラグビー 順位」「シックスネイションズ 2026 結果」）。
Tryline の日本語コンテンツは **データ層・タイトル層・本文層のすべてで海外名が英語** のため、この検索意図に物理的に当たらない。

権威ゼロ（playbook）は「上位表示されない」問題、**カタカナ欠如は「そもそも候補に入らない」問題** で、後者の方が先に効く。被リンクより前に、まずカタカナ表記でインデックスの土俵に乗る必要がある。

## 打ち手（優先順）
1. **【最優先・spec 化】海外チーム/大会の日本語（カタカナ）表示名を整備し、日本語ページのタイトル/h1/メタ/構造化データに使う** → `specs/feat-japanese-team-competition-names.md`
2. ナラティブ/プレビュー生成プロンプトにカタカナ用語集を渡し、**新規 recap からカタカナを使う**（プロンプト変更のみ＝低コスト）
3. （Owner 判断）既存 929 recap のカタカナ backfill（LLM 再生成＝コスト発生、段階実施可）
4. カタカナ名を使った **エバーグリーン日本語ページ**（順位表・日程・結果ハブ）＝ playbook S4/S7 と連動
