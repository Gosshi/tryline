# X reply 戦略

## 背景

@tryline_rugbyjp は 174件のポストで2フォロワー（2026-06-08調査）。投稿量に対してフォロワーが全くついていない。根本原因は「自分からポストするだけ」の運用で、コミュニティへの参加がゼロ。

**方針: reply-first に切り替える。**  
自分のタイムラインを育てるより先に、すでにエンゲージメントのあるスレッドに価値を加える返信を継続する。

## reply の原則

### やること

- 事実・数字・背景で補足する（「◯◯はこのシーズン×試合に出場していますね」）
- 質問に丁寧に答える
- 試合前の予習情報をさりげなく置く
- URL は「これ読むと詳しいですよ」の文脈が自然なときだけ添付
- URL を貼る場合も「全文はこちら」だけでなく、試合の流れ・勝負どころ・注目選手など、そのリンクで何が分かるかを一言添える

### やらないこと

- 「詳しくは→URL」だけの reply（スパム扱い）
- 自分のコンテンツ宣伝を前面に出す
- 同じアカウントに連日 URL を貼る
- Tier 1 の公式アカウント（@wowow_rugby）に週2回以上 URL を貼る

## note 連動

note は全文転載ではなく「要約＋送客」に徹する。記事末尾は毎回以下のどれかに寄せる。

- 「この試合のレビュー全文・得点経過・AI チャットは Tryline で」
- 「今週末の海外ラグビー予定は Tryline のカレンダーで」
- 「無料サンプルでレビュー品質を確認できます」

note 公開後は X で単独告知するより、関連する既存スレッドへの reply で補足として使う。URL 付き reply は1日1〜2件まで。

## ターゲット更新

`scripts/x-find-reply-targets.ts` を定期実行してリストを更新する。

```bash
export $(grep -v '^#' .env.production.local | xargs) && pnpm tsx scripts/x-find-reply-targets.ts
```

シーズン開幕時（9月・2月）に再実行すると新規アクティブアカウントが取れる。
