# X reply 戦略

## 背景

@tryline_rugbyjp は 174件のポストで2フォロワー（2026-06-08調査）。投稿量に対してフォロワーが全くついていない。根本原因は「自分からポストするだけ」の運用で、コミュニティへの参加がゼロ。

**方針: reply-first に切り替える。**  
自分のタイムラインを育てるより先に、すでにエンゲージメントのあるスレッドに価値を加える返信を継続する。

## reply の原則

### やること

- 事実・数字・背景で補足する（「◯◯はこのシーズン×試合に出場していますね」）
- 質問に丁寧に答える
- 試合前の予習情報をさりげなく置く
- URL は「これ読むと詳しいですよ」の文脈が自然なときだけ添付
- URL を貼る場合も「全文はこちら」だけでなく、試合の流れ・勝負どころ・注目選手など、そのリンクで何が分かるかを一言添える

### やらないこと

- 「詳しくは→URL」だけの reply（スパム扱い）
- 自分のコンテンツ宣伝を前面に出す
- 同じアカウントに連日 URL を貼る
- Tier 0 の公式アカウント（@JRFUMedia, @rugbyworldcupjp, @jsports_rugby, @LeagueOne_JP, @ntv_rugby, @wowow_rugby）に週2回以上 URL を貼る

## note 連動（2026-07-13 更新、D013）

note は「要約＋送客」原則を維持しつつ、告知は自分のスレッドへの連動型にする。**責務分離: 親投稿の下書きは `x-post`、note URL を載せる返信は `x-reply` の扱い**（URL 付き reply 1日1〜2件ルールの枠内）。

1. **記事タイプ別の親投稿**を先に立てる（`x-post` skill の投稿の原則に従う）:
   - A（試合翌朝の深掘り）→ 試合直後の親投稿（強い1本＋スレッド）
   - B（テーマ型週次）→ 対応する週末ガイド・結果分析の親投稿
   - C（エバーグリーン・企画）→ 記事の最も強い結論を **URL なしの親投稿**として先に出す
   - 適切な親投稿がない場合も C 方式で親投稿を立てる。**単独の URL 告知投稿には戻さない**
2. note 公開直後、その親投稿への**返信**で「記事で新たに分かったこと＋URL」を投稿する
3. 6〜12時間後、新しい図・別の論点がある場合のみ引用RT
4. 翌日に選択式質問投稿（①②③形式）で会話枠へ接続
5. 記録タイミングは `note-weekly` スキル「計測と KPI」の通り（全記事24h/72h、A・B は7日、C は7日＋30日）

note 側の CTA・公開チェックリストは `note-weekly` スキルが正。

## プロフィール最適化（2026-07-13 追加）

reply でインプレッションが増えても、飛んできたプロフィールで「フォローする理由」が示せていなければフォローに変換されない。bio・固定ポスト・ヘッダーは reply 運用と対をなす転換装置として扱う。

### 確定文案（2026-07-13、Codex 分析を踏まえ確定）

**アカウント名**: Tryline｜海外ラグビー日本語分析

**bio**:

> 海外ラグビーを日本語で深掘り🏉
> 試合前：JST日程と注目ポイント
> 試合後：勝敗を分けたデータを3分で解説
> 日本代表／Six Nations／SRPほか

**固定ポスト（初期版）**:

> 海外ラグビーの英語情報を追いきれない人へ。
> Trylineでは毎週、
> ・週末の注目試合とJST開始時刻
> ・勝敗を分けた1つのデータ
> ・試合後の短いレビュー
> を日本語で届けます。
>
> まずは今週の試合まとめ👇

プロフィールリンクは pricing でなくカレンダーページ（無料で見える場所）に。適用は Owner が実施。

### 固定ポストの運用

初期は上記の自己紹介ポスト（今週の試合まとめへの誘導付き）を固定。以降、反応（いいね・reply）が明確に良い投稿が出てきたら、四半期に1回を目安に best-performing 投稿への差し替えを検討する。

### ヘッダー画像

新規デザイン工数をかけず、`x-post` skill のデータ画像テンプレ（`app/globals.css` の CSS 変数を使うスコアボード風デザイン）を横長に流用。追加コストほぼゼロ。

**実施は Owner。** Claude Code は文案・画像素材のドラフトまで。X プロフィール設定変更は Owner が行う。

## こちらからのフォロー運用（2026-07-13 追加）

フォロワー0〜100の初動では、reply の露出だけでなく、こちらからのフォローが最短のブースターになる。小規模アカウント同士はフォローバック率が高く、reply への初動いいねの供給源にもなる。

- **対象**: Tier 1/2 アカウント（本ドキュメント上記表）の reply 欄で好意的な反応をしている個人アカウント。bio に海外ラグビー関連の記載があり、直近1ヶ月以内に投稿があるアクティブなアカウントに限る
- **上限**: 1日5人まで。フォロー爆撃に見えるペースは避ける（10分運用の枠内で完結する量）
- **除外**: 明らかな bot・スパムアカウント、フォロー数がフォロワー数の10倍を超えるような相互フォロー狙いのアカウント
- **記録**: 週次で「今週フォローした人数・フォローバック率」だけ簡易メモ（数字疲れを避けるため詳細トラッキングはしない）

## 実況タイムラインへの参加（2026-07-13 追加）

J SPORTS / WOWOW 中継中は、セカンドスクリーンで実況ハッシュタグを検索する視聴者が最も濃い時間帯。土日のライブ運用（`x-post` skill の型4）を自分のポストだけでなく、中継中の実況タイムラインでの reply・いいねにも振る。

- 該当する実況ハッシュタグは放送ごとに変わりうるため、**都度、配信画面や公式アカウントの告知で確認**する（固定タグを推測で使わない）
- 既存の `#海外ラグビー` `#URC` `#スーパーラグビー` 等の大会タグと合わせて検索し、試合中に投稿しているアカウントへ reply
- 切り口は通常の reply 原則と同じ（データで補足、URL は控えめ）。中継中は反応速度が価値なので、下書きは1案で素早く出す

## 4週間プロセス KPI（2026-07-13 設定）

フォロワー数は遅行指標のため、先行するプロセス指標で週次確認する。ベースライン（07-13 実測、42投稿）: インプレッション中央値17・プロフィールアクセス率0.39%・エンゲージメント0が23/42投稿・新規フォロー1件。

| 指標 | ベースライン | 4週間目標 |
|---|---|---|
| 投稿インプレッション中央値 | 17 | **50以上** |
| プロフィールアクセス率 | 0.39% | **1%以上** |
| 新規フォロー | 〜0.25件/週 | **週2件以上** |
| いいね・返信・RTのいずれか獲得 | ほぼゼロ | **4投稿に1投稿** |
| 同型投稿の連投 | あり（7/1・7/13） | **ゼロ**（強い1本＋スレッドに統一） |

広告はこの段階では使わない。自然投稿で反応の良い型が2〜3個見つかってから、その型だけを少額で広げる方が効率的（Codex 分析 2026-07-13）。

## ターゲット更新

**2026-07-05時点の方針: 手動運用がデフォルト。** X APIは従量課金（読み取り$0.005/件）でコストが発生し、視聴者数がまだ少ない現状ではコストに見合わないと判断（Owner判断）。

- 通常運用: Ownerが気になったポスト（対象スレッド）をコピペ or スクショで渡し、そこから下書きする（`x-reply` skillの手順1どおり）
- `scripts/x-find-reply-targets.ts` は温存するが、**実行はシーズン開幕時など狙いを定めた低頻度のみ**（新規アクティブアカウント発掘用）。ルーティンでは回さない

export $(grep -v '^#' .env.production.local | xargs) && pnpm tsx scripts/x-find-reply-targets.ts
