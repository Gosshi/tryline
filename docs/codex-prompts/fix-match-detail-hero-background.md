前回の修正（1回目）は「4層目を`color-mix(in srgb, ${homeColor} 88%, transparent)`で透過させる」だけだったが、これだけでは**まだ不十分**だった:
- Owner側の実機確認で、ニュージーランド×イタリア（濃紺〜青系）の組み合わせで再度確認したところ、画像のピッチラインがほぼ視認できなかった
- 原因: `public/visuals/match-detail-bg.jpg` 自体が「極めて低コントラストな近黒画像」であり、88%不透明の色付きグラデーション越しに単純なアルファブレンドしても、暗い画像は暗い背景にほぼ埋もれてしまう

**今回追加で必要な修正**: `backgroundBlendMode: "normal, normal, normal, screen, normal"` を4層目に適用する（`screen`ブレンドモード）。実測で、これにより画像の明るい部分（ピッチライン・隅のアイコン）が濃色チームカラーの上でも選択的に浮き出て視認できることを確認済み。transparent化と screen blend の**両方**が必要。

修正内容（specの「UIサーフェス」節に完全なdiffを記載済み）:
- 4層目: `linear-gradient(135deg, color-mix(in srgb, ${homeColor} 88%, transparent), color-mix(in srgb, ${awayColor} 88%, transparent))`（前回分、変更なし）
- 追加: `backgroundBlendMode: "normal, normal, normal, screen, normal"`（今回の修正、5層に対応する5値、4番目のみ`screen`）
