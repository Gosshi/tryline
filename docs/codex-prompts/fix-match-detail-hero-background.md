見つかった不具合:
- 実装後にVercelプレビュー（`/matches/[id]`）で確認したところ、追加したはずの `public/visuals/match-detail-bg.jpg` が**画面上に一切見えない**（`getComputedStyle`で`background-image`には含まれているが、視覚的に完全に不可視）
- 原因: `components/match-header.tsx` の4層目 `linear-gradient(135deg, ${homeColor}, ${awayColor})` が完全不透明（アルファなし）のため、CSSの複数背景レイヤー仕様上、手前に描画されるこの層が5層目の画像を100%覆い隠している

修正内容:
- 4層目を `linear-gradient(135deg, color-mix(in srgb, ${homeColor} 88%, transparent), color-mix(in srgb, ${awayColor} 88%, transparent))` に変更し、画像が薄く透けるようにする（specの「UIサーフェス」節に修正後のdiffを記載済み）
- 88%という数値は目安。チームカラー・白文字の可読性を保ちつつ画像のテクスチャが視認できるバランスであれば微調整してよいが、100%（透過なし）にはしないこと

入出力の例:
- 修正前: ヒーロー背景がフラットなチームカラーグラデーションのみに見える（画像のテクスチャが一切視認できない）
- 修正後: 同じチームカラーグラデーションの上に、`match-detail-bg.jpg` のピッチライン質感が薄く透けて見える

処理すべきエッジケース:
- 既存のチームカラーグラデーション・白文字の可読性（見出し・スコア・バッジ）が損なわれないこと
- 大会・チームカラーの組み合わせが変わっても破綻しないこと（数試合をランダムに確認する）
