# PR #98 — レビューのペイウォールが効かないバグを修正

## 背景

試合レビュー（recap）ページで、AI チャット以外のコンテンツが全文無料で表示される問題がある。

### 原因

`components/match-content.tsx` の `splitAtSecondHeading` は
`block.level <= 1`（H1 見出し）が 2 つ見つかったところで分割する。

しかし、生成されるレビュー記事は以下の構造になっている:

```
# 試合レビュー: Chiefs vs Highlanders  ← H1 タイトル（1つ目）
## 試合全体像                           ← H2（カウントされない）
...
## ターニングポイント                   ← H2（カウントされない）
...
```

H1 が 1 つしかなく、2 つ目が見つからないため全文が free 扱いになる。

プレビュー（preview）は `#` H1 でセクション分けされており正常に動作している。

### 修正方針

`lib/llm/prompts/generate-recap.ts` のプロンプトを修正し、
レビュー記事もプレビューと同様に `#`（H1）でセクションを開始するよう指示する。
タイトル行（`# 試合レビュー: ...` のような冒頭 H1）は不要なので省く。

## スコープ

対象:
- `lib/llm/prompts/generate-recap.ts`

対象外:
- `components/match-content.tsx` の変更なし
- 過去生成済みコンテンツの修正なし（既存レコードは影響なし）

---

## 変更仕様

`generate-recap.ts` の `structureInstruction` を、各セクションが `#` H1 で始まるよう明示する。

現状の指示（例）:
```
構成: 1)試合全体像(400-500字) 2)ターニングポイント(500-600字) 3)次戦への示唆(300-400字)
```

修正後の指示（例）:
```
構成: 1)試合全体像(400-500字) 2)ターニングポイント(500-600字) 3)次戦への示唆(300-400字)。
各セクションは # 見出し（H1）で開始すること。冒頭にタイトル行は不要。
```

具体的には:
- `structureInstruction` の 3 つのパターン（`hasLineups` / `isDataSparse` / それ以外）すべてに
  「各セクションは # 見出し（H1）で開始すること。冒頭にタイトル行は不要。」を追記する。
- 既存の「見出し(#)と箇条書き(-)のみ使用すること」はそのまま残す。
- `PROMPT_VERSION` を `"recap@2.2.0"` に更新する。
