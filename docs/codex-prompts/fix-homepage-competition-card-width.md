# 受け入れ条件の訂正（2026-08-31）

**指摘のとおりです。受け入れ条件2の `scrollHeight - clientHeight === 0` は spec 側の不備で、達成不可能な条件でした。**

`text-sm`(14px) × `leading-tight`(1.25) = **17.5px** と行高が小数になるため `scrollHeight` は必ず切り上げられます。行高の変更は同 spec で対象外にしているので、`=== 0` は原理的に満たせません。**自己矛盾でした。**

spec の受け入れ条件2・4 を更新済みです。

## 更新後の条件

**条件2**: 対象5件が **2行以内に収まっている**こと。判定は Range による行数カウントを推奨します。

```js
const range = document.createRange();
range.selectNodeContents(el);
range.getClientRects().length;   // <= 2 であること
```

許容差の形なら **`scrollHeight - clientHeight <= 1`**。

**条件4**: `scrollWidth - clientWidth <= 1`（同じ理由で `=== 0` にしない）。

**条件3**: `premiership` が1行に収まっているとのことなので満たしています。

**条件5**: `urc` が4行・19px で切り詰められたままなのは**想定どおり**です。
