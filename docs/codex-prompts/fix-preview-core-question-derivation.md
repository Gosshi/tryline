# Codex 指示: プレビューの「核心」をデータの3分岐でなく、その試合の材料から立てさせる

## 仕様書

`specs/fix-preview-core-question-derivation.md` を読んでから着手すること。以下は補足であり、仕様の置き換えではない。

## 何が問題か（一文）

`selectCorePattern` が**データの3分岐で冒頭の軸を機械的に決めている**ため、その試合で本当に重要な出来事があっても核心になれない。

## 実測（2026-08-21、同じ素材で4回生成）

**4回とも冒頭が「5連勝」で始まった。**

```
18:45  5連勝中で…南アフリカが初戦で土をつけられるか
22:06  5連勝で平均得点45.4点・平均失点12.4点の南アフリカに、同じく5連勝で…
23:30  直近5試合をともに5連勝し平均45点超を記録する…
23:44  5連勝で直近5試合の平均得失点差が南アフリカ+33点…
```

両チームが `result_streak: "winning"` なので `selectCorePattern` が **"form" を返し**、プロンプトがこう指示している。

```
【フォーム型で書くこと】連勝/連敗ストリークや直近の状態変化を軸にする
例: 「5連勝中のBullsに、プレーオフ圏ギリギリのMunsterが土をつけられるか——…」
```

**18:45 版は例文の「土をつけられるか」をそのまま使っている。例文が模倣されている。**

## 使われなかった材料

同じ試合の sourced_facts にこれらが入っていた。**1つも核心にならなかった。**

- 主将コリシが負傷欠場、デュ・トワが主将
- **その穴に入るデ・ヴィリアスは、オールブラックス戦が初のテスト出場**
- NZ はツアー中に4人を負傷で帰国させ、ベンチを3人入れ替え
- **引き分けならトロフィーが磁力で2つに分かれ、両国が半分ずつ持つ**
- ハンドレ・ポラードが23人から外れた

**3分岐に「チーム状況・ニュース型」が無い。構造上、核心になれない。**

## 過去2回の失敗を繰り返さないこと（最重要）

recap 側で同じ単調さに2度取り組んでいる。

| spec | 手法 | 結果 |
|---|---|---|
| `fix-recap-opening-variety.md` | 特定フレーズを `PROHIBITIONS_BLOCK` へ追加 | **別の紋切り型へ乗り換えて再発** |
| `fix-recap-opening-variety-v2.md` | 冒頭文の**構造**を禁止 | 実装済み |

**本件を「禁止句を足す」「構造を禁止する」で解こうとしないこと。** 問題は禁じ方ではなく、**プロンプトが積極的に指定している軸**にある。禁止をいくら足しても、指定された軸が変わらなければ冒頭は変わらない。

## やること

1. sourced_facts に試合固有の出来事があるとき、それを核心の候補として提示し**モデルに選ばせる**
2. sourced_facts が乏しいときだけ既存3分岐へフォールバック
3. 例文が模倣される問題に対処
4. `PROMPT_VERSION` を上げる

## 設計上の注意

**「ニュース型」という第4の分岐を機械的に選ばせる形にしないこと。** 分岐が3つから4つに増えるだけで同じ問題が起きる。**選択の主体をモデル側へ移すことが要件。**

**核心は入力に根拠を持つこと。** sourced_facts か DB 入力に裏付けのない問いを立てさせない。既存の捏造ガードと矛盾させないこと。

**プレーオフ分岐は妥当なので壊さない。** 決勝・準決勝で大会文脈を軸にするのは正しい。

## 絶対にやってはいけないこと

1. **`PROHIBITIONS_BLOCK` に禁止句を足して解こうとしない。** 2回失敗している方向
2. **第4の分岐を機械的に選ばせない**
3. **`generate-recap.ts` に触らない。** `fix-recap-opening-variety-v2.md` の結果を維持
4. **英語 preview の出力を変えない**
5. **セクション構成・字数配分を変えない**
6. **`lib/llm/content-length.ts` に触らない**
7. **QA の採点ルーブリックを変えない**
8. **既存記事を再生成しない。** コードとテストまで
9. **モデル ID を直書きしない。** `lib/llm/models.ts`

## テストで押さえる点

- **sourced_facts 0件 → 従来どおり3分岐のいずれかが出る**（修正前の挙動を固定）
- 両チーム `result_streak: "winning"` + 主将欠場の fact あり → **「フォーム型で書くこと」だけを指定する状態になっていない**
- 同条件で、sourced_facts 由来の材料を核心候補として参照する指示が出る
- 核心が入力に根拠を持つことを要求する指示が出る
- **現行の例文がそのままの形で出力に含まれない**
- `match_phase` がプレーオフ系 → 大会文脈の指示が引き続き出る
- `contentType: "recap"` の出力が前後で一致
- `preview` / `language: "en"` の出力が前後で一致
