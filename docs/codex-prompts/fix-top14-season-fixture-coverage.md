仕様書: `specs/fix-top14-season-fixture-coverage.md`

**先に spec を最後まで読んでから着手してください。特に「対象外」節を読み飛ばさないでください。**

## 最初に: これは「取り込み漏れを直す」作業ではありません

**Top 14 が1節先までしか入らないのは、Owner が意図的に設けた制限の結果です。**

> フランスには法律上 sui generis データベース権がある。CGU に主張が無くても「実質的な部分の抽出」は制限され得るため、Owner 判断で節単位に絞っている（1回3節上限・節間3秒待機）。**全26節の一括取得はしない。**（2026-08-29 決定）

**2026-09-01 に Owner が「取得窓を前方にずらす」ことを承認しました。**

- `getDefaultTop14LnrRoundSlugs()` を **「現在節-1・現在節・+1」から「現在節・+1・+2」へ**変えます
- **取る節数は3のまま。追加リクエストはゼロ**なので、上記の判断に抵触しません
- 上限クランプ（`1..26`）は維持してください。j25 なら2節、j26 なら1節を返します
- 直前節を取らなくなりますが `upsert` なので既存の確定スコアは残ります。**それを実際に確認して PR 本文に書いてください**

**次はすべて禁止です:**

- `MAX_TOP14_LNR_ROUNDS_PER_INGEST = 3` を増やす（**窓の位置は動かすが、節数は3のまま**）
- 1回の実行で4節以上を取る
- `scripts/backfill-top14-regular-season.ts` を `--confirm-owner-approved` で**実行する**
- `lib/scrapers/top14-lnr-results.ts` に手を入れる
- 節間の待機を短くする

「データが足りないなら取ってくればいい」は、この件では**却下済みの解法**です。

## 一文で言うと

`/calendar` は8週先まで移動できて「全大会横断」と書いてあるのに、**Top 14 は 2026-09-14 以降どの週にも出ません。** そしてそれが「試合が無い週」なのか「まだ取り込んでいない」のか、利用者には区別できません。

**本作業は、その区別がつくようにすることです。**

## やること（3つ）

### 1. 未取得であることを表示する（本体）

- `/calendar` で、**表示中の週より後にも開催があるが未取得の大会**があるとき、一覧の近くに注記を出す
- `/c/top-14/2026-27` にも同等の注記
- 文面は**事実だけ**。「Top 14 の日程は開催が近づいてから掲載されます」に相当する内容
- **該当する大会がある週にだけ出す。** 常時表示にしない

**制約:**

- **大会名・family をハードコードしない。** `top-14` という文字列で分岐しないこと。将来ほかの大会が同じ状態になっても機能させます
- **未取得の試合数や日程を推測して出さない。** 「あと168試合あります」のような数字は禁止です
- `/calendar` のクエリ本数を2本以上増やさない（現状: `getMatchesInRange` / `getStandingPositionLookupForCompetitions` / `getSpoilerGuardEnabledForUser`）

### 2. 取得窓を前方にずらす（2026-09-01 承認）

`lib/ingestion/sources/top14-lnr-live.ts` の `getDefaultTop14LnrRoundSlugs()` を「現在節-1・現在節・+1」から**「現在節・+1・+2」**へ。

- **返す節数は3のまま**
- 上限クランプ `1..26` を維持（j25 → 2節、j26 → 1節、j1 → j1・j2・j3）
- `MAX_TOP14_LNR_ROUNDS_PER_INGEST` と節間の待機は**変えない**
- 直前節を取らなくなるが `upsert` なので既存の確定スコアは残る。**確認して PR 本文に書く**

### 3. シーズン定数の腐りを直す（潜在バグ）

```

  const SUPPORTED_SEASONS = new Set(["2024-25", "2025-26"]);   ← 2026-27 が無い

lib/ingestion/sources/top14-lnr-live.ts:10

```

同じ「シーズン」を表す定数が2箇所にあり、片方だけ更新されました。`TOP14_LNR_SEASON` を単一の出所にしてください。

**`--dry-run` で許可されることの確認までです。本実行はしません。**

## 誤検知に注意（未解決の質問2）

「取り込み済みの最終キックオフより後の週か」で判定するのが素直ですが、**実際にシーズンが終了した大会**でも同じ条件が成立します。

例: URC は 2027-05-15 が最終戦です。2027年6月の週を表示したとき、「URC の日程が未取得」と誤って出しかねません。競技のシーズン終了日を持っていないため、単純な比較では区別できません。

**誤検知の具体例を PR 本文に列挙してください。** 多いようなら判定を緩める相談をします。
