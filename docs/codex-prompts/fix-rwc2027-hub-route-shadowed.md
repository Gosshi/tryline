# Codex 指示書: RWC 2027 専用ハブが本番で表示されない問題を直す

仕様書: `specs/fix-rwc2027-hub-route-shadowed.md`

**先に spec を最後まで読んでください。特に「根本原因」と「対照表」の節を飛ばさないでください。**

## 一文で言うと

`app/c/rwc/2027/page.tsx`（263行）が本番で一度も表示されていません。汎用の動的ルートが同じ URL を生成して覆っています。

## まず診断してください（実装より先）

```
pnpm build
```

ビルドが出力するルート一覧で `/c/rwc/2027` がどう扱われているかを確認し、**結果を PR 本文に貼ってください。**

spec に書いた根本原因は「`generateStaticParams` が `{competition:"rwc", season:"2027"}` を生成し、専用ページと同じ出力パスを作っている」です。**外形（レスポンスヘッダ）からは両ルートとも `x-matched-path: /c/rwc/2027` になるため、どちらのソースが生成したかを確定できませんでした。** ビルド出力が唯一の確実な証拠です。

**診断結果が spec の記述と食い違ったら、実装を止めて Owner に報告してください。** 誤った前提で直すより、そのほうが早く終わります。

## 症状の確認方法（`<title>` で判別する）

| | `<title>` |
|---|---|
| いま本番が返しているもの | `ラグビーワールドカップ 2027 日程・見どころ \| Tryline` |
| 専用ページが返すべきもの | `ラグビーワールドカップ2027 日程・出場国・日本語ガイド` |

前者は汎用ハブの書式です（`/c/top-14/2026-27` も `トップ14 2026-27 日程・見どころ | Tryline`）。

**本番検証では `curl -L` を必ず付けてください。** `trylinerugby.com` は `www.trylinerugby.com` へ 307 を返すため、付けないと15バイトの `Redirecting...` を測ることになります。

また React が `全<!-- -->26<!-- -->節` のようにコメントを挟むため、**HTML を grep する前に `sed 's/<!-- -->//g'` を通してください。**

## 1. 除外はハードコードしないでください

```ts

if (competition === "rwc" && season === "2027") return [];
```

**`app/c/` 配下に専用ルートが存在するパスを、一般的に除外してください。** 将来 `app/c/<family>/<season>/page.tsx` を足したときに自動で守られる形にします。

現時点で該当するのは `rwc/2027` の1件だけです。

**`rwc/2023` は引き続き生成してください。** 専用ページが無いので汎用ハブで正しく動いています。

修正前後の `generateStaticParams()` の件数と、減った要素の一覧を PR 本文に貼ってください。**減ってよいのは `rwc/2027` の1件だけです。**

## 2. revalidate の1行だけは中身に触れます

実測（2026-09-04）:

| ファイル | `revalidate` |
|---|---|
| 汎用ハブ `app/c/[competition]/[season]/page.tsx:59` | **3600** |
| `app/c/rwc/2027/bracket/page.tsx:9` | 60 |
| `app/c/rwc/2027/page.tsx` | **指定なし** |

いまは汎用ハブが応答しているので実質 3600 秒で再検証されています。**指定を足さずに切り替えると、再デプロイまで更新されないページになります。** 切り替え前後で挙動を一致させるため `3600` にしてください。

**bracket の `60` は変えないでください。**

## 3. サイトマップ

`app/sitemap.ts` は `/c/{family}/{season}` を一般ループで出しており、`/c/rwc/2027` は既に含まれています（総 URL 1663件）。**`bracket` は0件**です。

`/c/rwc/2027/bracket` を1件追加してください。**総件数が 1663 → 1664 以外になったらスコープ超過です。**

- `specs/fix-rwc2027-hub-page-gate.md`（「Coming Soon」誤表示の解消）
