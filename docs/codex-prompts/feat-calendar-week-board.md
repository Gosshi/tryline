仕様書: `specs/feat-calendar-week-board.md`
判断の根拠: `docs/decisions.md` の **D020**（2026-08-31、Owner 承認済み）
視覚の参照: `docs/design/mock-hub-direction-2026-08-31.html` の**候補B3**（**B でも B2 でもなく B3 が実装対象です**）

**先に spec と D020 を読み、モックをブラウザで開いてから着手してください。**

## 着手条件

**なし。単独で着手できます**（2026-09-01 に依存を外しました）。トークン spec が先にマージされていれば `--space-*` を使ってよい、という程度の関係です。

## 一文で言うと

`/calendar` はデスクトップ1336×759で **1画面目に試合が1件も入らず**、14試合の週が3.52画面になります。行の54〜69%が空白です。読者の63%はデスクトップです。

## セルの形（B3）

```
GLA – LIO                          ← 略称。Outfit + tabular-nums + 太字
グラスゴー・ウォリアーズ 対 ライオンズ   ← 正式名。小さく淡色
```

**正式名は絶対に省略記号で切らないでください。** `white-space: nowrap` と `text-overflow: ellipsis` を当てない。
**2行固定にもしないでください。** 実測で 648px・1画面目10/14 まで後退します。**必要なときだけ折り返す**形にすると 575px・12/14 で、14件中12件は1行のままです。

理由: **略称を知らない読者ほど、名前の長いチームで困ります。そこで保険の正式名が切れては意味がありません。**

## 文字量が最重要の制約です（2026-09-01 の指摘）

Owner が候補B を見て **「文字が多くて見るのがしんどい」** と言いました。実測して分解した結果:

| 内訳 | B | B2 |
|---|---|---|
| チーム名（削れない中身） | 186 | 186 |
| 列ヘッダ・時間帯ヘッダ | 95 | **49** |
| 凡例 | 34 | **29** |
| **会場** | **+258** | **出さない** |
| 合計 | 573 | **264（54%減）** |

**当初の spec は会場を足す設計で、それだけで +79% になるところでした。**

B2 でやっていること:
1. **会場を出さない**（デスクトップの週ボードのみ。**モバイルの縦積みには従来どおり出す**）
2. 「JST」は盤面の外に1回だけ
3. 試合数バッジ・「◯試合同時」の注記を削除
4. 「月」は最初の列だけ
5. 凡例は短縮形（「ユナイテッド・ラグビー・チャンピオンシップ」→「URC」）
6. **ホームを主（濃い・太い）、アウェイを従（淡い・小さい）**
7. 余白を広げる（高さは 500→559px と微増する。**詰めるより読みやすさを取る**）

**スコア・バッジ・視聴導線を足すときに、この削減を食い潰さないでください。** 受け入れ条件 5b で総文字数400字以下を機械判定します。

## 先にマイグレーションが必要です（順序を間違えないでください）

**`teams.short_code` に重複があり、そのまま略称を主にすると同じ週に「LEI」が2回出て別チームを指します。**

| slug で特定するチーム | 現在 | 変更後 | 根拠 |
|---|---|---|---|
| レスター・タイガース | `LEI` | **`TIG`** | レンスターと衝突。Tigers は当該クラブの通称 |
| チーフス | `CHI` | **`CHF`** | チリ（World Rugby の国コード）と衝突。国コードを優先 |
| ホンコンチャイナ | 未設定 | **`HKG`** | World Rugby / IOC の国コード |
| ジンバブエ | 未設定 | **`ZIM`** | 同上 |

**レンスター（`LEI`）とチリ（`CHI`）は変更しません。他の87件にも触らないでください。**

- **`slug` で対象行を特定してください。** `short_code` を条件にすると2チームまとめて書き換わります
- **`update` 4文だけ。** `insert` / `delete` / DDL を入れないでください
- **マイグレーションを本番適用してから UI をマージしてください。** 逆順にすると本番で `LEI` が2回出ます

`short_code` を変えて安全なことは確認済みです（一意制約なし・`eq()`/`in()`/`find()` 等の照合キーとして使っている箇所は**0件**・表示専用）。ただし `lib/llm/stages/assemble.ts:657-658` で **LLM の入力に含まれています**（チーム識別は `name`/`slug` があるので実害は無い見込みですが、認識しておいてください）。

## 実データで確認済みの前提（再調査不要）

- **1週の開催日数は最大4日。** 全86週（2025-08〜2027-07）で 1日16% / 2日38% / 3日38% / 4日7%、**5日以上は0週**。4列で足ります
- **チーム表示名は最大15文字**（`teams` 91件すべて `name_ja` 保有、中央値6文字 / p90 12文字）。1152pxを4列にすると1列277pxで収まります
- **2026-10-31 は7試合中6試合が 09:00 JST。** 現行は「09:00 JST」を6回繰り返しています。ここを1回にまとめるのが週ボードの効きどころです
- `WeekSchedule` の参照は `/calendar` の**1箇所だけ**。ホーム等への波及はありません
- **週ボードでは `TeamBadge` を出しません**（略称が文字として出るため重複します）。**モバイルの縦積みには従来どおり出してください**

## モックが描いていないもの（ここが本作業の設計課題）

モックは**予定試合しか描いていません**。実際には次を足す必要があります。**足した結果の見た目は Codex が設計してください。**

- **スコア**（終了済みの週）。`SpoilerScore` でラップし `spoilerGuardEnabled` を尊重する
- ステータスバッジ（`getStatusPresentation`）

**過去の週で列幅が破綻しないことを必ず確認してください。** spec の「保持しなければならない情報」表の11項目を1つも落とさないこと。

## サーバーレンダリングを壊さないこと

## 1日開催の週の扱い（あなたの質問への回答・2026-09-01）

**あなたの推奨どおり、週ボードを維持します。現行リストへのフォールバックは作りません。** spec の未解決の質問5は削除し、受け入れ条件20を確定させました。**矛盾していたのは spec の側で、指摘は正しかったです。**

**ただし「維持」を素直に `auto-fit` で実装しないでください。**

`repeat(auto-fit, minmax(240px, 1fr))` に日が1つだけ入ると、**カードが1078pxまで伸びて中に1試合だけが左端に乗ります**。これは D020 が直そうとしている「チーム名の右に800px空く」状態そのもので、**修正が自分の直した問題を再発させます**。

**その日の試合数から幅を決めてください**（実データ2週で検証済み）:

```
日カードのコンテナ:
  max-width: min(100%, calc(N * 288px + (N - 1) * 20px))   /* N = その日の試合数 */

日カード内の試合グリッド:
  grid-template-columns: repeat(auto-fill, minmax(240px, 1fr));
  gap: 0 20px;
```

| 週 | 試合数 | カード幅 | 内側の列数 | 高さ |
|---|---|---|---|---|
| 2026-12-07 | 1 | **288px** | 1 | 168px |
| 2027-05-28 | 5 | **1078px** | **4** | **252px** |

比較（5試合）: 全幅に伸ばす=396px / 288px固定で左寄せ=409px / **本ルール=252px**。

**`width: fit-content` は使わないでください。** 内側の `auto-fill` が幅を決められず1列に潰れます（実測: 1試合も5試合もカード幅324px）。試しましたが失敗した実装です。

**この幅計算は開催日が1日のときだけ。** 2日以上は日別列のままで構いません。

### 検証は本番 URL ではできません

`MAX_WEEK_OFFSET = 8`（`lib/format/week.ts`）により、**現在週から±8週を超える `?week=` はエラーにならず現在週を返します。**

- `?week=2026-12-07` を開いても1日開催の週は出ません
- **「URL を開いたら普通の週が出たので直っている」と誤判定しないでください**

**コンポーネントテストでフィクスチャを流して検証してください**（受け入れ条件 20b・20c）。目視は、実装時点で±8週以内にある1日開催の週を `matches` から探して使ってください（2026-09-01 時点では `?week=2026-08-17` が1日1試合）。
