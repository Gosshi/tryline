## ゴールは提案ではなくスキルの更新です

**成果物はレポートではありません。** 次の2ファイルに対する**具体的な差分**です。

```
.claude/skills/x-post/SKILL.md

```

レポートで終わらせないでください。**次に投稿を作るときに機械的に従える形の文言**まで落としてください。「エンゲージメントを高める」のような一般論は、スキルに書けないので成果物になりません。

## 調べてほしいこと

### 1. 小規模アカウントで実際にリーチが伸びる投稿の条件

フォロワー数千未満・ニッチ縦型の日本語アカウントで、**何がリーチを生んでいるのか**を実例から特定してください。

- 一般論の「有益な情報を出す」「継続する」ではなく、**投稿単位で観測できる特徴**（構造・長さ・冒頭の型・画像の有無・投稿時刻・引用RTか単独か）
- スポーツ以外の領域でも構いません。**日本語・ニッチ・小規模**という条件が一致していることが重要です
- 「バズった」だけでなく、**バズが定着（フォロー・再訪）につながった例**を優先してください。Tryline の問題は認知ではなく定着です

### 2. 読者層とプラットフォームのミスマッチをどう扱うか

**サイトの読者はデスクトップWindows・Bing中心（=Xの中心層と重ならない）です。**

- X 上に Tryline の読者に近い層は実在するのか
- いないなら、X は**新規獲得の場ではなく別の役割**（信頼の担保、記者・関係者への露出、検索面の補助）に位置づけるべきか
- 投稿時刻の最適解は「デスクトップで見る人」に合わせるべきか

**ここで「Xをやめるべき」という結論も許容します。** ただしその場合、代わりに何をするかまで示してください。

### 3. 現行スキルのルールのうち、根拠が弱い／古いものの特定

`x-post` スキルには実測日つきのルールが多数あります。**そのうち再検証が必要なものを洗い出してください。**

直近1件、実際に誤りが見つかっています。

> 「週次投稿は毎回新規クロールされるためリンクカードでも通常問題ない」（2026-07-14 追記）

2026-08-28 の実測で**誤りと確定**しました。`/calendar` は毎週同じURLなので X は再クロールせず、1週間前のOG画像が表示されていました。

**同種の「根拠が推測のまま固定化されたルール」が他にもあるはずです。** 削除・修正すべきものを挙げてください。**スキルは足すだけでなく減らしてください。**

### 4. note を続けるかどうか

週次B型は停止済みですが、**A型（試合直後の強い1本）とエバーグリーンは継続中**です。

- note 経由の流入は実質ゼロ（28セッションが全部 Owner 自身だった実例あり）
- それでも続ける理由があるとすれば何か（検索面？信頼？他媒体への転載元？）
- **やめる判断もありえます。** その場合、既存記事をどうするかまで示してください

### 5. 「番組化」は効いているか

固定シリーズ名（`【週末の海外ラグビー】`）で定期性を作る方針が 2026-07-13 に導入されています。

- 定期投稿は実際にフォロー動機になっているか
- なっていないなら、シリーズの設計（頻度・名前・内容）のどこが問題か

## 成果物の形

### 1. スキルの差分（本体）

2ファイルそれぞれについて、**節を特定した置換文**を出してください。

- 追加する文言は**そのまま貼れる形**にする
- **削除・修正すべき既存ルールも明示する**（何を消すかが同じくらい重要です）
- 各変更に **根拠（実測値＋日付、または参照した事例）** を1行添える
- 根拠が「一般論」「業界の常識」しかないものは**採用しない**

### 2. 判断の記録

方針が変わる提案（例: Xの位置づけ変更、note終了）が含まれる場合、`docs/decisions.md` に追記する D番号つきの決定文案も添えてください。

### 3. 検証方法

提案した各ルールについて、**それが効いたかを後から判定する方法**を書いてください。判定できないルールはスキルに入れません。

## やってはいけないこと

- **コード・DB・設定の変更**（変更するのはスキル2ファイルのみ）
- **X のクロール**
- **一般的なSNSノウハウの列挙。** フォロワー数万規模を前提にした施策は Tryline には適用できません
- **既に決定済みの方針の、新しい根拠のない再提案**
- **実測できていない数字の使用。** 「〜と言われている」「一般に〜」は根拠になりません
- **スキルを長くするだけの提案。** 削除も含めて提案してください
- 自動投稿の復活

## 品質の基準

提出物は次を満たしてください。

1. すべてのルールに**実測値または具体的な観測事例**が紐づいている
2. **削除・修正すべき既存ルールが最低1件**挙がっている
3. 各ルールに**後から効果を判定する方法**がある
4. 「Xをやめる」「noteをやめる」を含む**不都合な結論も候補として検討されている**
5. Tryline の規模（実ユーザー189/28日、フォロワー数千未満）に**現実的に実行できる**内容である
