# Codex 指示書: 時刻が決まっていない試合を「時刻未定」と表示する

仕様書: `specs/feat-kickoff-time-tbd.md`（受け入れ条件は仕様書を正とする）

`AGENTS.md` の規約に従う。**最新の `origin/main` からブランチを切る。**

## やること
- `matches.kickoff_time_tbd`（boolean, not null, default false）を足すマイグレーションを作る。**本番への適用は Owner がマージ前に行う**。PR 本文の冒頭に「マージ前にマイグレーションの適用が必要」と書く。
- 日付だけの試合を作る取り込み（URC・プレミアシップ・共通の Wikipedia の読み取り処理と、`rg` で見つけたほかのもの）で `kickoffTimeTbd` を返し、`upsert.ts` で挿入・更新とも書く。時刻が載ったときに同じ試合が二重に作られないようにする（プレミアシップの識別子に時刻を含めない場合を含む）。
- 時刻の表示・JSON-LD・iCal・アプリ向け API を仕様書のとおりに変える。
- 仕様書の受け入れ条件 1〜5 のテストを足す。

## 守ること
- 時刻のある試合の表示・並び順・iCal の `UID` を変えない。
- API は項目を足すだけ。
- 表示側で「00:00 UTC なら未定」のような推測をしない（必ず列を見る）。

## 検証
- `pnpm tsc --noEmit`・`pnpm lint`・`pnpm test`・`pnpm build`。**すべて必ず実行し、結果を完了報告に含める。**
- 受け入れ条件 6（壊して落ちる）の出力と 8（スクリーンショット）を PR 本文に貼る。時刻を表示している箇所の一覧と、日付だけを扱う取り込みの一覧も貼る。PR を出したらマージを待つ。
