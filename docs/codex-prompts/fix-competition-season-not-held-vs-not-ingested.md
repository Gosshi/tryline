## 何が問題か

大会シーズンページは試合が 0 件のとき、無条件にこう表示します（`app/c/[competition]/[season]/page.tsx:941-948`）。

```
試合データを準備中です
このシーズンの試合情報はまもなく公開予定です。
```

**「まもなく公開予定」は、その年度に開催されることを断定しています。** 本番の実データ（2026-09-09 実測）は次の 2 件です。

```
autumn-nations-2026       matches=0  total_rounds=null
rugby-championship-2026   matches=0  total_rounds=null
```

**`rugby-championship-2026` は開催されません。** Rugby Championship は Nations Championship に統合済みで、2026 年に独立大会として存在しません。それでも「まもなく公開予定」と出ています。事実に反します。

`autumn-nations-2026` は**未確認**です。断定しないでください。

## やること

`competitions` に「その年度に開催するか」を表す列を追加してください。既存 12 列にこれを表せるものはありません（確認済み: `id` / `slug` / `name` / `country` / `season` / `start_date` / `end_date` / `created_at` / `updated_at` / `family` / `champion` / `name_ja` / `total_rounds`）。

- **3 値**を表せること: 開催する / 開催しない / 未確認
- **既定は「未確認」。** 既存 38 行が「開催する」と断定されないこと
- **`start_date` / `end_date` の有無で代用しないでください。** 日程未発表と開催しないは別です

そのうえで `:941` の 0 件ブロックを分岐させてください。

| 状態 | 表示 |
|---|---|
| 開催しない | その年度は開催されない事実 + 対応する大会への導線 |
| 開催する（未取得） | 確認状況 + 公式日程への参照 |
| 未確認 | **断定しない文言。「まもなく公開予定」と書かない** |

既存の「他のシーズンを見る」導線（`:951-955`）は維持して構いません。
