やること:

- スタイル違反のみの場合のretryを、既存の事実違反retry予算（最大2回）とは別枠で最大1回に制限する

- hard gate（メタコメント、入力にない人名・数字、禁止引用、過去記事とほぼ同一の冒頭、明白な定型句過剰反復、日本語破綻）とsoft gate（接続詞の軽微な多用、段落長均一、見出し類似、`japanese_quality`3/4の際どいケース）を分離し、soft gateは合計点方式で判定する

処理すべきエッジケース:
- スタイル違反のみでretryが1回発生した後も違反が解消しない場合、draft化する（rejectでなく既存のfail-closedパターンに従う）
- hard gate項目は既存の挙動を変えず、即retry対象のまま維持する
