### 1. トップページの横スクロール

- 仕様: `specs/fix-home-sr-only-overflow-escape.md`
- 指示書: `docs/codex-prompts/fix-home-sr-only-overflow-escape.md`

トップページがページ全体として **862px 横スクロール**します（本番実測: `scrollWidth 2332` / `clientWidth 1470` / `scrollTo(10000,0)` 後の `scrollX = 862`）。

原因は `app/page.tsx:831` の `<span className="sr-only"> 最新シーズン</span>` です。Tailwind の `sr-only` が `position: absolute` を含むのに祖先に positioned 要素が無く、包含ブロックが初期包含ブロックになって `ul.overflow-x-auto` のクリップを逃れています。

**`html` / `body` に `overflow-x: hidden` を足さないでください。** `specs/fix-home-unwanted-horizontal-scroll.md` が同じ症状にまさにそれを指示し、PR #520 で実装され、**効きませんでした**。上の実測値はその `clip` が効いている状態のものです。同 spec には supersede 注記を追加済みです。

**jsdom にレイアウトエンジンが無いため、この spec の中心的な条件は vitest で検証できません。「`pnpm test` が green」を完了根拠にしないでください。** 実測値を PR 本文に貼ることが条件です。

### 2. 会場の現地時刻が全部 BST

- 仕様: `specs/fix-venue-local-time-timezone.md`
- 指示書: `docs/codex-prompts/fix-venue-local-time-timezone.md`

`components/match-header.tsx:26-36` の `TEAM_TIMEZONES` が欧州 6 か国分しかなく、それ以外を `Europe/London` にフォールバックしています。さらにキーが会場ではなく**ホームチーム**です。

```
現状: 現地 2026-08-15 (Sat) 06:00 BST   ← Townsville（豪 QLD）の試合
正:   現地 2026-08-15 (Sat) 15:00 AEST
```

**RWC 2027 は全 52 試合が中立会場**で、同一会場の `home_team` が spain / tonga / chile / georgia と変わります。ホームチーム推定はこの大会で原理的に機能しません。

`matches.venue` を権威にし、**未知の会場では現地時刻行そのものを出さない**設計にします。`venue` は既に `MatchListItem` に載っており props の配線追加は不要です。

**辞書を推測で埋めないでください。** 216 会場すべてを埋める必要はありません。未マッピングは安全側（現地行なし）に倒れます。間違った値を入れることが、この spec が直そうとしているバグそのものです。

**DB への `UPDATE` を差分に含めないでください。** 会場名の Wikipedia 脚注 `[17]`（本番に 53 行）は表示側で無視します。

### 3. 監査ツールの C5 誤検出

- 仕様: `specs/fix-external-identifier-key-policy.md`
- 指示書: `docs/codex-prompts/fix-external-identifier-key-policy.md`

PR #772 の監査ツールを本番で初回実行したところ、**C5 が 659 件**出ました。findings 677 行のうち **591 行が「C5 のみ」**で、実際に確認すべき 86 件（C1 / C3 / C4）が埋もれています。

`tools/audit-published-recap-event-integrity.ts:296-301` が `external_ids` のキー名を `/(?:id|url|fixture|event)/i` で拾っており、**`wikipedia_url`（1,148 行に対し distinct 43。シーズンページの URL）を fixture 識別子と誤認**しています。

許可リストは `match_url` / `league_one_match_id` / `world_rugby_match_id` / `top14_lnr_id` / `top14_lnr_match_path` の 5 種です。本番でいずれも出現行数と distinct 数が一致します。

**`wikipedia_event_id` を「大会で絞れば使える」と考えないでください。** 検算済みで、残る 9 件はすべて偽陽性です（`"mw-content-text"` というパーサのフォールバック、同一シーズン内の再対戦、ノックアウトの節見出し）。

この作業は `specs/fix-event-ingestion-identity-guard.md` の**未解決の質問 1 に答えるもの**でもあります。同 spec の質問 2・3 は未決のまま残してください。**取り込み時のガードは実装しないでください。**
