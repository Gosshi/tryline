## 何を直すか

`app/c/[competition]/[season]/page.tsx:611` に固定文があります。

```
answer: "日本ではDAZN・J SPORTS 等の配信サービスで視聴できます。",
```

これは `seasonFaqs` に入り、**全大会・全シーズンの FAQPage JSON-LD として出力されます。** 検索結果にも載りえます。

**同じページで、目に見える視聴ガイドは「確認中」と出しているのに、JSON-LD は「視聴できます」と断定しています。**

放送情報は `feat-broadcast-auto-ingest` / `feat-match-broadcasts` で試合単位に取り込む仕組みがあり、確認日も持っています。**検証済みデータがあるのに FAQ がそれを読んでいません。**

## 触るファイル

```
app/c/[competition]/[season]/page.tsx
```

**`lib/broadcasts/` には触らないでください。** 取り込み側は正しく動いています。読んでいない側を直します。

## 変えてはいけないもの

**FAQ の他の3項目（開催期間・次の試合・順位表）に差分を作らないでください。**

## 気をつけること

**「等」で断定を曖昧にしないでください。** 確認できたサービスだけを列挙し、確認できていないものは書きません。

**可視の視聴ガイドと JSON-LD は同じ関数から生成してください。** 片方だけ直すとまた乖離します。

**FAQ の文面を LLM で生成しないでください。** 決定論のテンプレートと検証済みデータの組み合わせです。

## 必ず入れるテスト

放送データが無い大会シーズンで、JSON-LD に **`DAZN` / `J SPORTS` / `WOWOW` / `NHK` のどれも現れないこと。**
