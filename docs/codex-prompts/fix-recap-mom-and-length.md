# Codex プロンプト: recap MOM 吸収 + 字数不足修正

仕様: `specs/fix-recap-mom-and-length.md` を参照（内容はインライン展開しない）。

## タスク

2 つの問題を同時に修正する。変更は `lib/llm/prompts/generate-recap.ts` のみ。

1. **`# MOM` が events+no-lineups ケースで出続ける** — 禁止ではなく吸収（`# ターニングポイント` 末尾に MOM 相当を統合）
2. **字数不足（目標 2,000字に対し約半分しか出ない）** — セクションごとに「何を書けば目標字数に達するか」を骨格として提示

## 変更ファイルと内容

### `lib/llm/prompts/generate-recap.ts`

**a) `PROMPT_VERSION` 更新**

```typescript
export const PROMPT_VERSION = "recap@4.4.0";
```

後続の改訂でバージョンがすでに上がっている場合は、現在のバージョンに +0.0.1 する。

**b) events あり・lineups なし ケースの `structureInstruction` を全面改訂**

## 受け入れ条件（完了の定義）

- `pnpm build` 相当のビルド・TypeScript エラーなし。
- `# MOM` という見出しが出力されない（構造で防ぐ。PROHIBITIONS_BLOCK への追加は不要）。
- `# ターニングポイント` の末尾に主要選手の分析を統合する指示が含まれている。
- 全体字数目標が `1,600字以上` と明記されている。
- 変更は events+no-lineups ケースのみ。他の分岐は一切変更しない。

## エッジケース・注意事項

- `structureInstruction` の分岐は 3 つある。events+no-lineups ケースのみ変更し、残り 2 つは触らない。
- `sectionHeadingInstruction` は既存の変数参照をそのまま使う。
- `PROHIBITIONS_BLOCK` への変更は不要。
