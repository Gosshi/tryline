## 処理すべきエッジケース

1. 今週の未来の試合が 0 件（日曜の夜など）。
2. 今週も今後も試合が無い（オフシーズン）: `getNextUpcomingMatch()` の 1 試合だけ。それも無ければボードを出さない。
3. 最近のレビューが 0 本・1 本・2 本。
4. 無料サンプル（`sampleMatch`）が無い: サンプルのリンクを出さない。
5. ネタバレ防止がオン: ボードの結果と最近のレビューのスコアが隠れる。
6. 390px の幅で、2 列が 1 列になる。
