`/specs/fix-home-unwanted-horizontal-scroll.md` の仕様を実装してください。

コンテキスト:
- プロジェクト規約は `CLAUDE.md` を読む
- 対象は `app/globals.css`。`html`・`body` セレクタに `overflow-x: hidden` を追加する
- 原因はホームページ（`app/page.tsx` 647行目付近）の「大会アーカイブ」セクションの横スクロールカード一覧 `<ul className="flex gap-3 overflow-x-auto ...">`。この要素自体は正しく描画・内部スクロールしているが、`document.documentElement.scrollWidth` がこの要素の内部スクロール分だけ膨張し、ページ全体が横スクロール可能になってしまう。本番ページのDevToolsで直接検証済みで、`html`/`body` に `overflow-x: hidden` を設定すると、この内部スクロール機能は維持されたままページ全体の横スクロールだけが無効化されることを確認している

入出力の例:
- 変更前: `document.documentElement.scrollWidth`（約1647px）が `clientWidth`（約1455px）より大きく、ページを横スワイプ/横スクロールできてしまう
- 変更後: 同じページで横スワイプ/横スクロールができなくなるが、「大会アーカイブ」のカード一覧は引き続き横スクロールで全項目を閲覧できる

処理すべきエッジケース:
- 他の主要ページ（試合ページ・大会ページ・カレンダーページ）に、意図的な横スクロールコンポーネント（カルーセル等）がある場合、`overflow-x: hidden` の全体適用によってそれらが機能しなくならないか確認する
- モバイル幅（320px・375px）でも同様に、意図しない横スクロールが起きないこと・意図したコンポーネントの横スクロールが機能することを確認する
