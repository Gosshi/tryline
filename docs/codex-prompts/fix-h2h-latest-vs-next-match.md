## 何を直すか

**H2H ページが未来の試合を「直近の対戦」として表示しています。**

`/h2h/japan-vs-usa` の実測:

```
収録対戦    4試合
直近の対戦  2027-10-16 (土) 05:00 JST   ← 未来（RWC 2027）
最新の対戦  日本 47 - 21 アメリカ        ← 終了済み
次回対戦    2026-09-12 (土) 19:05 JST
```

**同じページに3つの日付が並び、「直近の対戦」だけが 2027年**を指しています。終了済みの最新でも次回対戦でもなく、収録範囲の最終試合です。`/h2h/new-zealand-vs-south-africa` でも同様です。

原因は、収録試合の配列の先頭をキックオフ日時で絞らずに採用していることです。

## 気づいてほしいこと

**「直近の対戦」と「最新の対戦」は同じものを指しています。** 今は前者が未来・後者が過去を指すので別物に見えているだけで、正しく直すと重複します。**片方に統合してラベルを1つにしてください。**

## 境界条件

- 終了済みが0件のペア → 「直近の対戦」を出さない（「次回対戦」のみ）
- 未来が0件のペア → 「次回対戦」を出さない（「直近の対戦」のみ）

**キックオフ日時の比較は日時として行ってください。文字列比較にしないでください。**

## 変えてはいけないもの

**「Tryline 収録分、全通算ではない」の注記は正しいので維持してください。**

H2H ページの追加・削除・noindex 化はしないでください。収録価値の判断は GSC/BWT のデータを見てからです。

## デザイン

項目が1つ減るので、**余白の詰まりを 320 / 768 / 1440px で確認してください。** Owner の目視評価が受け入れ条件に入っています。
