# Codex 指示: 選手の日本語表記を DB に持たせ、記事ごとの揺れを止める

## 仕様書

`specs/fix-player-name-ja-coverage.md` を読んでから着手すること。以下は補足であり、仕様の置き換えではない。

## 何が問題か（一文）

**`players.name_ja` が 2,456人中 11人（0.4%）しか埋まっていない**ため、ほぼ全選手でモデルが毎回カタカナを作り直し、記事ごとに表記が変わる。

## 実測（2026-08-21、同一試合の再生成）

```
Malcolm Marx        マークス        → マルクス
Wilco Louw          ラウ            → ルー
Josh Moorby         ムーアビー      → ムービー
Fabian Holland      ファビアン      → フィジアン
Paul de Villiers    デ・ヴィリアーズ → デフィリアス
Cobus Reinach       ライナッハ      → レイナハ
```

**素材も試合も同じ。プロンプトのバージョンも同じ。** 変わったのは生成の揺らぎだけ。

## 本番実測（2026-08-23）

```
players 全体            2,456人中 11人  (0.4%)
ラインアップ登場選手    1,927人中 11人  (0.6%)
得点イベント登場選手      936人中  9人  (1.0%)
```

11人は日本代表選手（PR #600 でバックフィルした漢字表記）。**それ以外は全部空。**

## バグではない

`lib/llm/prompts/shared-prompt-blocks.ts:42-46` にこうある。

```
1. グロッサリにあれば指定の表記を必ず使う
2. 入力データに日本語表記があればそれを使う
3. どちらにも無ければカタカナで記載すること   ← 99.4% がここ
```

グロッサリは `buildJapanesePlayerNameGlossary`（`lib/llm/stages/assemble.ts:476`）が `players.name_ja` から作る。**空なので3行目に落ちる。設計どおり動いて、データが無い。**

## やること

1. 選手の日本語表記を生成して `players.name_ja` に固定する仕組み
2. 新規登録される選手に表記が入る経路
3. 20人程度の試し焼きができる形

## 設計上の注意（ここを外すと意味が無い）

**一度決めたら二度と変えないこと。** 記事ごとに変わるのが問題なので、**バックフィルのたびに変わるなら何も解決しない。** 既存値は上書きせず、べき等にすること。

**英語読みでカタカナ化しないこと。** ラグビーはアフリカーンス語・マオリ語・パシフィカ系の名前が多い。

```
Louw          → ルー（英語読み）ではなく ラウ
de Villiers   → デフィリアスではなく デ・ヴィリアーズ
Nortjé        → ノルチェ
```

**所属チームの国は `teams` から辿れる。** 言語背景をプロンプトに与えること。

**試し焼きは必須。** `content-regen` スキルの原則（少件数→検品→全件）に従う。**表記の誤りは記事に残り続ける**ので、コンテンツ再生成より慎重に。

## 絶対にやってはいけないこと

1. **日本代表11名の漢字表記を上書きしない。** テストで担保すること
2. **`shared-prompt-blocks.ts:42-46` の文面を変えない。** グロッサリが埋まれば1行目で解決する
3. **全件バックフィルを実行しない。** 試し焼き20人の提示まで。全件は Owner の承認後
4. **`players.slug` の正規化に手を出さない。** 別 spec（`ruan-nortj` の `é` 欠落）
5. **重複した選手行の統合をしない。** 別 spec（`cheslin-kolbe` と `-2` 等6組以上）
6. **チーム名・大会名の日本語表記に触らない。** 既に解決済み
7. **既存記事を再生成しない**
8. **モデル ID を直書きしない。** `MODELS.FAST`

## テストで押さえる点

- **既存 `name_ja` を上書きしない**（日本代表11名が変わらない）
- **べき等**（同じ選手に2回実行して値が変わらない）
- 件数を指定した試し焼きが動く
- `buildJapanesePlayerNameGlossary` が `name_ja` を拾い、プロンプトのグロッサリに載る
- LLM 呼び出しはモックする（**本番 API を叩くテストを書かない**）
