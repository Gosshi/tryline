コンテキスト:

- Ownerの提案（YouTube埋め込みの著作権面）をGPT-5.6が調査した結果、公式チャンネルの動画に限定した埋め込み基盤を安全に作れるとの整理になった
- 本specは埋め込みコンポーネントと許可リストの基盤のみを実装する。**実際にどのページに配置するかは対象外**

やること:
- `lib/` 配下に許可チャンネルIDリスト（`YOUTUBE_ALLOWED_CHANNEL_IDS` 等）を新設する。初期値は空配列でよい
- `components/youtube-embed.tsx`（または同等）を実装する: `youtube-nocookie.com` を使ったiframe埋め込み、クリック前はサムネイル表示のみで自動再生しない、Player純正UIを隠さない
- 動画IDのチャンネルIDが許可リストにない場合、または地域制限等で埋め込み不可の場合は、YouTubeへの通常リンクにフォールバックする
- 動画メタデータ（動画ID・チャンネルID・確認日時）を記録する仕組みを用意する（テーブル追加が必要な場合はマイグレーションを作成する）

処理すべきエッジケース:
- 許可リストが空の状態でも、コンポーネント自体はエラーなく動作し、常にリンクフォールバックになること
- チャンネルID照合に外部API（YouTube oEmbed等）を使う場合、レート制限・キャッシュを考慮すること

完了の定義:
- specs の受け入れ条件1〜5を満たす
