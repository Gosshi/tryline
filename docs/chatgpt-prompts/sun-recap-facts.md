**事実だけを書いてください。** 意見・予想・感想・評価は書かないでください。「面白い」「注目」「〜だろう」は不要です。

## URL の日付

**今日を含む週の月曜日**（6日前）の日付を入れてください。木〜日に終わった試合はすべてこの1ページに載ります。

**プレビュー側と違い、2ページは要りません。** 日曜夜の欧州キックオフは日本時間で月曜未明になり翌週のページに入りますが、**日曜20時の時点でまだ終わっていない**ので対象外です。

## 月曜未明の欧州戦をどうするか

日曜夜の欧州キックオフ（例: 2026-09-06 19:05 UTC = **JST 月曜 04:05** のラ・ロシェル×トゥールーズ）は、この枠では拾えません。

**その試合を厚くしたい週だけ、月曜 20:00 にもう一度実行してください。** URL は `week=<今週の月曜>` と `week=<翌週の月曜>` の2本にします。**締切は火曜 09:05**（`cron-post-match-recap-refresh` の火曜の回。手動で事実を入れた試合だけを再生成する）。

**毎週やる必要はありません。** 該当する試合が無い週、あってもニュース価値が低い週は飛ばしてください。

## 貼る前に必ず確認すること

**URL が生きていることはシステムが確認しますが、その記事がその事実を書いているかは確認できません**（`docs/decisions.md` の D026）。

**初回テスト（2026-09-04）で実際に食い違いが出ています。** 「リコ・イオアネが23人から外れる」の出典タイトルが `Dave Rennie drops Fabian Holland` で、別の選手名でした。

**数字・選手名・負傷の詳細は、貼る前に出典を開いて確認してください。**

**カタカナ表記は Claude に照合させてください。** 既存 DB と割れます（マルコム・マークス／マルクス、レノ／レン・イキタウ など実例あり）。ChatGPT は既存 DB を知らないので、プロンプトでは直りません。
