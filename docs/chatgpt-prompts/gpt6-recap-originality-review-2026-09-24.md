## 0. この依頼の趣旨

**Claude Code が出した「レビュー記事にオリジナリティを出す案」を、第三者の目で監査してほしい。**

Owner の不満は次の 2 つ:

1. 記事が**まだ事実の羅列に読める**
2. **過去の試合との比較や、分析**のような、ほかでは読めない内容がほしい

同時に、このサイトは過去に **LLM の捏造（存在しない統計・選手・発言）で記事を公開してしまった事故**を何度も起こしており、それを防ぐ仕組みを積み重ねてきた。**「分析を増やす」と「捏造を防ぐ」を両立できる案か**を見てほしい。

**案を褒める必要はない。** 間違っている・筋が悪い・もっと良い手がある、なら根拠を添えてそう書くこと。一般論ではなく、下のデータと実物の文章に即して書くこと。

## 1. プロダクト概要

**Tryline** — 海外ラグビーを日本語で追う Web メディア。

- 対象: 日本語で海外ラグビー（Six Nations / Premiership / URC / Top 14 / Super Rugby Pacific / Nations Championship / RWC 等）を追いたいファン
- 提供価値: 試合データの集約、LLM による日本語プレビュー/レビュー、試合ごとの AI チャット
- 収益: フリーミアム。**Premium ¥980/月で読めるのはレビュー全文**。有料購読者は実質ゼロ
- 体制: Owner 1 人。運用に割ける時間は 10 分/日・週 5 時間
- 方針: 「敵は AI ではなく間違い」。UI からは「AI 解説」という表示を外す方針（2026-06-07 決定）

### 設計上の不変条件（変えられない）

- コンテンツはすべて試合（match_id）単位。LLM 生成は試合単位でキャッシュし、ユーザー単位にしない
- **スクレイプした生テキストは再配信しない**。LLM で日本語に書き直してから出す
- **15 語を超える直接引用なし、同一ソースから複数引用なし**
- 生成パイプラインは 4 段: 集約 → 事実抽出 → ナラティブ生成 → 品質チェック（QA）

## 2. 今のレビュー生成の仕組み

### 2.1 本文を書く LLM に渡している材料（`lib/llm/stages/assemble.ts`）

| 材料 | 中身 | 状態 |
|---|---|---|
| `match_events` | 得点経過（分・種類・チーム・選手名）、カード | ほぼ全試合にある |
| `competition_standings` | 試合後の順位表 | 主要リーグにある |
| `recent_form` | 両チームの直近の成績 | ある。ただしシーズンをまたぐと QA が誤検出する既知の問題 |
| `h2h_last_5` | 過去 5 回の対戦 | 渡しているが、**QA が「対象外」扱い**（書いても評価されない） |
| `sourced_facts` | 出典付きの事実（Web 収集／Owner の手入力） | 試合によって 0〜12 件 |
| `projected_lineups` | メンバー | 取れた試合だけ |
| チームスタッツ（ボール支配・タックル・ラインアウト等） | — | **取得できていない（0 件）** |

### 2.2 捏造を防ぐための制約（プロンプト `lib/llm/prompts/generate-recap.ts` と QA）

- 入力に無い統計・選手名・発言・負傷・移籍などを推測して書かない
- 選手名は入力にある実名だけ
- 数値の因果関係は入力にある事実の範囲内で組み立てる
- QA は 4 項目（情報の密度・日本語の質・事実の裏付け・戦術の深さ）を 5 点満点で採点し、裏付けが 3 未満だと公開しない
- ほかに、固有名詞の照合と「捏造ゲート」がある

**結果として、LLM は得点経過をなぞることしかできず、羅列になりやすい**、というのが Claude Code の診断。

### 2.3 使っているモデル（`lib/llm/models.ts`）

| 段階 | モデル |
|---|---|
| 本文生成 | gpt-5.6-terra |
| 抽出・QA・固有名詞照合 | gpt-5.6-luna |

### 3.3 現行モデル（gpt-5.6-terra）の本文

#### この試合の核心

39分、ロマン・ンタマックのペナルティーゴールがヴァンヌ 16—トゥールーズ 17を刻み、最後のリード交代を生んだ。21分まで13点差を追ったトゥールーズは、前半終盤から48分まで17点を連取し、最終的に29—23で逆転勝ちした。ヴァンヌは50分に1点差へ迫ったが、69分のブレア・キングホーンのトライで届かなかった。4トライ対2トライという決定力の差が、6点差の結末を分けた。

#### 試合全体像

トップ14 2026-27シーズンのリーグ戦で、開幕から3試合を終えた時点で勝ち点10、3位のトゥールーズと、14位で勝ち点0のヴァンヌが向き合った。トゥールーズはこの勝利で2勝1敗を維持し、首位リヨンの勝ち点14、2位ボルドーの10点を追う位置にいる。ヴァンヌは3連敗となり、順位表の最下位から抜け出せなかった。

前半はヴァンヌの13点連取で始まった。3分にマキシム・ラファージがペナルティーゴールを決め、7分にはエリック・マークスのトライとコンバージョンで10—0。21分、アントニー・ブティエのドロップゴールで13—0まで差を広げた。25分にポール・グラウがトライを返すと、30分のシリル・バイユのイエローカード後、31分にラファージが追加点を挙げた。しかしトゥールーズは32分のサンティアゴ・チョコバレスのトライで反撃し、39分にンタマックが16—17へひっくり返した。

後半はトゥールーズが48分、テディ・トマのトライとコンバージョンで16—24とした。ヴァンヌも直後の50分、ベンジャミン・トーマス・スティーヴンソンのトライとコンバージョンで23—24まで迫る。だが以後は19分間スコアが動かず、58分にスティーヴンソンがイエローカードを受けた後、69分にキングホーンがトライ。トゥールーズが6点差を確保して80分を終えた。

ヴァンヌはペナルティーゴール2本、ドロップゴール1本、トライ2本で23点を組み立て、序盤には試合の速度を自ら選べていた。一方のトゥールーズは4人のトライスコアラーを出し、トライ4本で20点を獲得した。先行したヴァンヌがキックで盤面を積み上げたのに対し、トゥールーズはトライによって差を縮め、追い越し、終盤に再び広げた。直近5試合の平均得点が42.6のトゥールーズと16のヴァンヌという差は、試合終盤の得点手段の幅にも表れた。

#### ターニングポイント

3分、ラファージのペナルティーゴールでヴァンヌが3—0と先行した。7分にはマークスのトライとコンバージョンで10—0、21分のブティエのドロップゴールで13—0となり、ヴァンヌは最大13点差を作った。トゥールーズは25分、グラウのトライとコンバージョンで13—7へ詰め寄る。31分にはラファージが16—7としたが、32分にチョコバレスがトライを奪い、コンバージョンを加えて16—14。39分、ンタマックがペナルティーゴールを決め、16—17で初めてトゥールーズが前に出た。

ヴァンヌにとって崩れたのは、13—0から16—17へ転じた前半中盤以降の得点の連鎖を断てなかった点である。25分に7点を返されても、31分のペナルティーゴールで9点差を回復している。にもかかわらず、その直後の32分にチョコバレスのトライを許し、前半終了前には逆転を受けた。30分にトゥールーズのバイユがイエローカードとなり、ヴァンヌはその時間帯にラファージの3点を得た。それでも数的な局面を13点以上の安全圏へ結び付けられず、トゥールーズに次のトライを許したことが、前半の主導権を手放す分岐点だった。

トゥールーズは13点を追った25分以降、39分までに17点を連続で積み上げた。グラウ、チョコバレスと異なる選手がトライを記録し、ンタマックが逆転の3点を加えたことで、反撃は単発で終わらなかった。後半も48分にトマがトライを決め、16—24と差を広げる。50分に23—24まで迫られてからは、ヴァンヌに再逆転の得点を許さず、69分のキングホーンのトライまで耐えた。トライ4本を4人で分けた点は、得点局面を特定の1人に依存しなかったことを示している。

> 39分の逆転後、トゥールーズは一度もリードを渡さず、69分のトライで試合を閉じた。

この流れは、ヴァンヌが序盤の13点差を守る試合から、1点を追って終盤の得点を必要とする試合へ変えた。後半はトゥールーズが12点、ヴァンヌが7点。50分のスティーヴンソンのトライは会場の緊張を最大まで戻したが、そこから69分まで両軍無得点だった時間が、追う側には重くのしかかった。58分のスティーヴンソンのイエローカード中にヴァンヌは失点しなかったものの、得点も生めず、1点差を解消できないまま時間が進んだ。

試合を決定づけた選手はロマン・ンタマックである。39分、16—14という2点差の場面でペナルティーゴールを沈め、16—17と試合最後のリード交代を完成させた。この3点は最終スコア29—23の中では小さく見えるが、ヴァンヌに「守る側」から「追う側」への役割変更を強いた。トゥールーズは以降、48分と69分にトライを重ねられた。逆転の基準点を前半終了前に置いたンタマックの仕事が、後半の得点局面を生んだ。

#### 次戦への示唆

トゥールーズは勝ち点10でボルドーと並び、首位リヨンとは4点差にいる。次戦以降は、上位のリヨン、ボルドー、モンペリエが並ぶ先頭集団を追う対戦構図となる。今節の勝利は順位を支える一方、ヴァンヌ戦で21分まで13—0と先行を許した事実も残した。

トゥールーズの課題は、反撃を始めるまでに背負った13点差である。直近5試合の平均得点42.6、平均得失点差プラス20.2という数字を持ちながら、この試合では前半21分まで無得点だった。バイユのイエローカード中にはヴァンヌに3点を加えられ、相手にリードを広げる余地を与えた。トライ4本で勝ち切ったことは強みだが、上位争いでは追走する展開を常態化させない試合運びが必要になる。

ヴァンヌには、13—0の先行と50分の23—24という追い上げが残った。マークスとスティーヴンソンのトライ、ブティエのドロップゴール、ラファージのペナルティーゴール2本で、トゥールーズを69分まで射程に置いた。3試合で勝ち点0、14位という現状では、先行した局面を後半の得点へつなげることが次の課題となる。来季へ向けても、トライ2本に加えてキックで23点を作れた試合を、80分の結果へ結び直す経験が財産になる。

### 3.4 gpt-6-sol の本文

#### この試合の核心

> 39分、ロマン・ヌタマックのペナルティゴールでトゥールーズが初めて逆転し、そのリードを最後まで守った。

トップ14の2026-27シーズン、トゥールーズはヴァンヌを29―23で下した。21分には0―13と離されたが、32分から48分までに17点を連取。ヴァンヌが50分に１点差まで迫った後も、69分のブレア・キングホーンのトライで差を広げた。４トライを挙げた勝者に対し、敗者は２トライ。ヴァンヌは序盤に築いた13点の貯金を守れず、開幕３連敗となった。

#### 試合全体像

トップ14の2026-27シーズン、リーグ戦３試合目。前節にボルドーを48―12で破ったトゥールーズが、開幕から２敗していたヴァンヌと対戦した。試合後の順位表ではトゥールーズが２勝１敗の３位、ヴァンヌが３敗の14位。序盤の順位差だけでは捉えきれない逆転劇になった。

前半はヴァンヌが先行した。３分にマキシム・ラファージのペナルティゴール、７分にエリック・マークスのトライとコンバージョン。21分にはアントニー・ブティエのドロップゴールで13―０とした。トゥールーズは25分のポール・グラウのトライで反撃し、コンバージョンを加える。30分にシリル・バイユがイエローカードを受け、ヴァンヌは31分に16―７としたが、32分にサンティアゴ・チョコバレスがトライ。39分のヌタマックのペナルティゴールで16―17となり、前半を終えた。

後半も先に動いたのはトゥールーズだ。48分、テディ・トマのトライとコンバージョンで16―24。ヴァンヌは50分にベンジャミン・トーマス・スティーブンソンのトライとコンバージョンで23―24まで詰めた。58分には同選手がイエローカードを受ける。１点差が続いた後、69分にキングホーンがトライを奪い、23―29で決着した。後半の得点はヴァンヌが７点、トゥールーズが12点だった。

両者を分けたのは、得点手段と加点の持続性である。ヴァンヌは２トライに加え、ペナルティゴール２本とドロップゴール１本で序盤の差を築いた。一方のトゥールーズは４人が１トライずつを記録し、トライだけで20点を得た。ヴァンヌも50分のトライで応じたが、その後は得点できなかった。序盤には複数の手段で点を重ねた側が、後半には次の加点をつくれず、トゥールーズの終盤の１トライを受け止める形になった。

#### ターニングポイント

最後にリードが入れ替わったのは39分。ヌタマックのペナルティゴールで、ヴァンヌ16―トゥールーズ17となった場面である。そこへ至る推移が、この逆転の重みを物語る。３分のラファージのペナルティゴールでヴァンヌが３―０と先行し、７分のマークスのトライとコンバージョンで10―０、21分のブティエのドロップゴールで13―０。グラウの25分のトライとコンバージョンで13―７となり、ラファージが31分に16―７へ広げた直後、チョコバレスの32分のトライとコンバージョンで16―14まで迫られた。ヌタマックの一蹴は、この追い上げを初めてリードに変えた得点だった。

ヴァンヌの問題を、一つの守備対応の失敗に帰すべきではない。失点記録から読めるのは、13点差で先行した後、25分と32分にトライを許し、前半終了までにリードを失ったという連続性だ。とりわけ31分のペナルティゴールで９点差に戻した次の得点機会が相手に渡り、１分後にトライを許したことが痛い。得点しても相手の反撃を止められず、先行する側から追う側へと立場が変わった。後半には48分にもトライを許しており、39分の逆転を一時的なものにとどめられなかった。

トゥールーズは25分のグラウのトライで反撃の足場をつくり、32分から48分にかけて17点を連取した。そこにはチョコバレスとトマのトライ、ヌタマックのペナルティゴールが含まれる。30分にバイユがイエローカードを受け、31分に追加失点した後も、32分のトライで差を２点に縮めた。３度の得点機会をまたいで加点を続けたことが、前半の逆転を後半の８点リードへつなげた。個々のトライの起点までは得点経過だけから描けないが、異なる選手が得点を担った事実は明確である。

それでも50分、スティーブンソンのトライとコンバージョンでヴァンヌは23―24と迫った。ここで試合は再び１点差の攻防になる。しかし、次の得点は69分のキングホーンのトライだった。ヴァンヌにとっては、序盤の13点リードを失っただけでなく、追撃後にもう一度スコアを動かせなかったことが敗因となった。トゥールーズにとって39分は逆転点、69分はその優位を６点差に広げる一手である。前半終盤から後半序盤にかけて続けた加点が、50分の反撃を受けても崩れない土台になった。

この試合を決めた一人はヌタマックだ。39分のペナルティゴールはトゥールーズ唯一のペナルティゴールであり、同時に最後のリード変化を生んだ得点でもある。25分と32分のトライで縮めた差を、この３点で初めて覆した。後半にヴァンヌが１点差へ迫っても、トゥールーズは再逆転を許していない。彼の一蹴は単独で勝敗を説明するものではないが、追撃を「逆転」に変え、その後の試合展開の基準を定めた。

#### 次戦への示唆

次戦でトゥールーズが相手にするのは、今季３試合を終えて３位につけるチームを止めようとする側だ。２勝１敗、勝ち点10。ヴァンヌ戦の４トライは攻撃面の材料になる一方、13点差から追いかけた序盤と、50分に１点差へ詰められた後半は、次の相手にも突かれ得る時間帯だった。

トゥールーズの課題は、逆転できたことに満足せず、先行を許してから主導権を取り戻すまでの時間を縮めることだ。今回は25分に初得点を挙げ、39分に逆転したが、21分時点では13点を追っていた。48分に８点差へ広げても、２分後には１点差に戻された。４トライを挙げる攻撃と、得点直後に相手の加点を許す展開は、併せて検討すべきだろう。

ヴァンヌには、開幕３連敗でも収穫がある。マークスとスティーブンソンの２トライに、ラファージのペナルティゴール２本、ブティエのドロップゴールを組み合わせ、トゥールーズを50分に１点差まで追い詰めた。ただし勝ち点０の14位にとどまり、今季の最下位争いを抜け出すには、序盤の先行を80分の結果へ結びつけたい。今季の残り、そして来季へつながる課題は、追撃の１トライの後にも得点を重ねられるかにある。
