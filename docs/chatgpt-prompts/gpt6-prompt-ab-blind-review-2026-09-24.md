## 0. この依頼の趣旨

同じ試合・同じ入力・同じモデル（gpt-5.6-terra）で、2 種類の記事生成プロンプトから日本語の記事を 1 本ずつ作った。4 試合 × 2 本 = 8 本。

**どちらの本文が読者にとって良いかを、どちらのプロンプトから作られたかを知らないまま評価してほしい。** 同じ試合の 2 本は X と Y と呼ぶ。X と Y の割り当ては試合ごとに無作為に決めてある。

褒める必要はない。優劣がつかなければ「同等」と書いてよい。

## 3. 読者とプロダクト

- Tryline は、海外ラグビーを日本語で追うファン向けの Web メディア。Premium（月額 980 円）で読めるのはレビューの有料部分。
- 記事は試合ページに載る。**同じページに、得点経過の表（時刻・得点者・種別）と最終スコア、先発一覧の表が既にある**。
- レビューの有料部分は、本文の 3 つ目の見出し（`# `）から先。1〜2 つ目の見出しの節は無料で読める。
- 運営の方針は「敵は AI ではなく間違い」。入力にない事実・予想・根拠のない因果は、読みやすさより重く見る。

## 4. 評価の観点（各試合で X と Y を比べる）

1. **誤りと裏付けのない主張**: 入力（fixtures）と食い違う記述、入力にない予想スコア・原因・心理・選手の役割の断定。見つけたものは本文の該当箇所を引用して挙げる。
2. **繰り返し**: 得点経過を節をまたいで 2 回以上たどっていないか。核心の言い換えで字数を埋めていないか。試合ページの表と同じ内容を順に書き起こしていないか。
3. **問いへの回答**: 中心の問いを立て、入力の根拠を使って答えているか。
4. **読後の理解**: スコア表だけでは分からない理解が残るか（Owner の要望は「事実の羅列感」を減らし、分析としての独自性を出すこと）。
5. **有料部分の価値**（レビューのみ）: 無料部分から有料部分へ読み進めたくなるか。有料部分の量と中身は、月額 980 円の読者が満足する水準か。
6. **日本語**: 自然さ、ラグビー用語、人名表記（姓名の順、推測した漢字がないか）。

## 5. 答えてほしいこと

1. 試合ごとに、観点 1〜6 のそれぞれで X / Y / 同等のどれが良いかと、その根拠（本文の引用付き）。最後に総合でどちらを選ぶか。
2. 4 試合を通して、X / Y の区別を越えて見える**本文の型の違い**（構成、長さ、断定の強さ、数字の使い方など）。どちらの型が Tryline に向くかと、その理由。
3. どちらの型にも共通する弱点と、それを直すために本文生成の指示で変えるべきこと（指示文の案があれば添える）。
4. 採用の判断基準として、Owner は「新しい重大な事実誤りが 0 件」「4 組中 3 組以上で選ばれる」「残りの組でも重大な劣化がない」を置いている。あなたの評価でこの基準を満たす型はどちらか。

## 6. 自分の評価を書き終えたあとで

`fact-check.md` を読み、自分が見つけた誤りと食い違う点（相手が見落としたもの、自分が見落としたもの、判断が分かれるもの）を挙げる。
