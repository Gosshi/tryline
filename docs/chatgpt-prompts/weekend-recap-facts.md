# 土日月 18:00 — 終わった試合のレビュー素材

**ChatGPT のスケジュール実行に、このプロンプト全文をそのまま登録してください。**

**1つのスケジュールを土曜・日曜・月曜の3日に発火させます。** 締切はいずれも **20:30** です。

| 実行日 | 入力の締切 | 主な対象 |
|---|---|---|
| **土曜** | **20:30** | 金曜夜・土曜昼に終わった試合 |
| **日曜** | **20:30** | 土曜夜・日曜昼に終わった試合 |
| **月曜** | **20:30** | **月曜未明に終わった欧州戦**（2026-09-14 追加） |

**締切が20:30に揃っているのは、レビューの初回生成が「直近に過ぎた 20:30」を待つようになったためです**（`specs/fix-content-generation-timing-windows.md`）。締切を過ぎて入れた事実は、その日の 21:00 の生成には載らず、月曜 09:05 の再生成まで反映されません。

**月曜を足したのは、日曜夜の欧州キックオフ（JST 月曜未明）に自動の調査枠が無かったためです。** 2026-09-07 のラ・ロシェル×トゥールーズは、初回生成まで **53時間**かかっていました。

**前の回に入れた事実は残ります。** 同じ試合を次の回で重複して出しても、同一文面なら保存時にスキップされるので害はありません。

## 何が自動で取れていて、何が取れていないか（2026-09-06 実測）

**この切り分けが「欲しい情報」の優先順位の根拠です。**

| データ | 自動取得 | 実測 |
|---|---|---|
| トライ・コンバージョン・PG・DG と分数 | **入る** | `match_events` の type は `try` / `conversion` / `penalty_goal` / `drop_goal` の4種のみ。1試合13〜19件 |
| 最終スコア | 入る | `matches.home_score` / `away_score` |
| **カード（イエロー／レッド）** | **入らない** | `match_events` に該当 type が存在しない |
| **チームスタッツ** | **入らない** | `match_team_stats` は**全試合0行** |
| **公式 Player of the Match** | 入らない | LLM 推論で決めており、過去に実際の受賞者と食い違って手修正した |
| **監督・選手のコメント** | 入らない | 取得経路がない |
| **負傷の詳細・離脱期間** | 入らない | 同上 |

**2026-09-05 の収集は得点経過に偏り、自動データとほぼ重複した。** 得点経過を書かせないのは、この反省による。

## 回によっては空になる

**土曜の回は空になる週の方が多くなります。** JST の土曜18時までに終わる試合は多くありません。欧州の試合は日曜未明・月曜未明、南半球のテストも日曜未明が中心です。実測（9/5〜12/31）では JST 土曜14〜16時台のキックオフは3件でした。**土曜の回が実際に効くのは、日本代表戦や日本国内開催の試合がある週**です。

**月曜の回も、JST 月曜未明にキックオフした欧州戦が無ければ空になります。**

**空でも問題ありません。「対象なし」で終わってください。**

**試合当日の回は監督会見の記事がまだ出ていないことが多い**ので、コメントが取れなければ「コメント未発表」と書いて次の回に回してください。

## URL の日付

**今日を含む週の月曜日**の日付を入れてください。曜日によって「何日前か」が変わります。

| 実行日 | 今週の月曜 |
|---|---|
| 土曜 | 今日の**5日前** |
| 日曜 | 今日の**6日前** |
| 月曜 | **今日**（0日前） |

**どの回も1ページだけです。プレビュー側と違い、2ページは要りません。**

**日曜の回で月曜未明の試合が対象外なのは、その時点でまだ終わっていないからです。** その試合は翌日、**月曜の回が拾います**。JST 月曜未明の試合は**その月曜から始まる週**に属するため、月曜の回の `week=<今日>` の1ページに載ります。

## 月曜未明の欧州戦（2026-09-14 に自動化）

日曜夜の欧州キックオフ（例: 2026-09-06 19:05 UTC = **JST 月曜 04:05** のラ・ロシェル×トゥールーズ）は、**月曜の回が拾います。**

**月曜に読むページは1つだけです。** JST 月曜未明の試合は**その月曜から始まる週**に属するため、`week=<今日>` の1ページに載ります。プレビュー側の土曜のような2ページ読みは要りません。

**以前は「厚くしたい週だけ月曜 20:00 に手動で回す」運用でしたが、2週続けて実行されず**（2026-09-07 / 09-14 とも手動投入0件）、該当試合の初回生成が終了から53時間後になっていました。**発火日を1日増やすだけで ChatGPT のスケジュール枠は消費しない**ため、自動化しました。

**該当する試合が無い月曜は「対象なし」で終わって構いません。**

## 貼る前に必ず確認すること

**URL が生きていることはシステムが確認しますが、その記事がその事実を書いているかは確認できません**（`docs/decisions.md` の D026）。

**初回テスト（2026-09-04）で実際に食い違いが出ています。** 「リコ・イオアネが23人から外れる」の出典タイトルが `Dave Rennie drops Fabian Holland` で、別の選手名でした。

**数字・選手名・負傷の詳細は、貼る前に出典を開いて確認してください。**
