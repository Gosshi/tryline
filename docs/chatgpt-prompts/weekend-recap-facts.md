# 土日 18:00 — 終わった試合のレビュー素材

**ChatGPT のスケジュール実行に、このプロンプト全文をそのまま登録してください。**

**1つのスケジュールを土曜と日曜の両方に発火させます。** 締切と反映の仕組みは曜日で変わります。

| 実行日 | 入力の締切 | 反映 |
|---|---|---|
| **土曜** | **20:30** | `live-pipeline` 21:00 の**初回生成**。再生成が不要でコスト0 |
| **日曜** | **月 09:05** | `cron-post-match-recap-refresh` の月曜の回で再生成 |

**土曜が重要なのは、日本代表の国内戦がここに入るからです。** 試合当日にアクセスのピークが来る記事で、日曜まで待つと反映は月曜朝＝約40時間遅れになります。

**土曜に入れた事実は日曜以降も DB に残ります。** 日曜の回で同じ試合を重複して出しても、同一文面なら保存時にスキップされるので害はありません。

## 守ってほしいこと

**掲載されている試合をすべて扱ってください。** 情報量が少ない試合を勝手に省かないでください。調べても何も見つからない試合は「情報なし」と明記してください。**試合を落とすことが一番困ります。**

**事実だけを書いてください。** 意見・予想・感想・評価は書かないでください。「面白い」「注目」「〜だろう」は不要です。

**その出典が実際に書いていることだけを書いてください。** 複数の記事の内容を1つの出典にまとめないでください。

**関係者のコメントは引用せず、要旨を1文にしてください。** 原文をそのまま写さないでください。

## 出典について

**同じ記事を3試合以上の出典にしないでください。** 各試合について、その試合を扱った記事を探してください。

有料記事しか見つからない場合は、そのことを明記してください。

## 特に欲しい情報

**Tryline は試合中のイベントデータに欠けがあります。** 次を優先してください。

- **最終スコアと、前半・後半の得点経過**
- **得点者とその時間**（トライ・PG・DG の別）
- **カード**（イエロー／レッド、対象選手、時間、理由）
- 負傷による交代と、その後の見通し
- **公式の Player of the Match**（誰が選ばれたか）

## URL の日付

**今日を含む週の月曜日**（6日前）の日付を入れてください。木〜日に終わった試合はすべてこの1ページに載ります。

**プレビュー側と違い、2ページは要りません。** 日曜夜の欧州キックオフは日本時間で月曜未明になり翌週のページに入りますが、**日曜20時の時点でまだ終わっていない**ので対象外です。

## 月曜未明の欧州戦をどうするか

日曜夜の欧州キックオフ（例: 2026-09-06 19:05 UTC = **JST 月曜 04:05** のラ・ロシェル×トゥールーズ）は、この枠では拾えません。

**その試合を厚くしたい週だけ、月曜 20:00 にもう一度実行してください。** URL は `week=<今週の月曜>` と `week=<翌週の月曜>` の2本にします。**締切は火曜 09:05**（`cron-post-match-recap-refresh` の火曜の回。手動で事実を入れた試合だけを再生成する）。

**毎週やる必要はありません。** 該当する試合が無い週、あってもニュース価値が低い週は飛ばしてください。

## 貼る前に必ず確認すること

**URL が生きていることはシステムが確認しますが、その記事がその事実を書いているかは確認できません**（`docs/decisions.md` の D026）。

**初回テスト（2026-09-04）で実際に食い違いが出ています。** 「リコ・イオアネが23人から外れる」の出典タイトルが `Dave Rennie drops Fabian Holland` で、別の選手名でした。

**数字・選手名・負傷の詳細は、貼る前に出典を開いて確認してください。**

**カタカナ表記は Claude に照合させてください。** 既存 DB と割れます（マルコム・マークス／マルクス、レノ／レン・イキタウ など実例あり）。ChatGPT は既存 DB を知らないので、プロンプトでは直りません。
