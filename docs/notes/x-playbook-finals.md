# X 配信プレイブック（試合時間シーディング）

ゼロ〜小フォロワーのアカウントを動かす方法。**自分のTLに投稿して待つ**のではなく、**観客が集まっている大きいアカウントのライブ投稿に価値で割り込む**。

## 鉄則
1. **本文にリンクを入れない**（X がリーチを絞る）。リンクはリプ欄 or 固定ポスト or プロフィール
2. 本文は**画像ネイティブ**（カード・得点推移グラフ・スコア画像）でリーチを稼ぐ
3. **試合中**、大会公式・実況・解説者のライブ投稿に**日本語の解説/データでリプ** → 「こいつ詳しい」→ プロフィール流入
4. ハッシュタグは**3つまで**。試合中は大会の英語公式タグ（例 `#SuperRugbyPacific`）
5. ゴールは「バズ」でなく**最初の実フォロワー10〜30人＋プロフィール流入**。指標はクリック/プロフィール訪問/フォロー（スキ・いいね数で一喜一憂しない）

## リプの作法（価値先出し・リンクなし）
- 例（ハリケーンズがトライ）: 「ハリケーンズらしい速い連続攻撃からのトライ。準決勝も57点取った攻撃力、決勝でも止まりませんね🌀」
- 例（競った場面）: 「ここでPG選択は堅実。エクセターは接戦をこう拾って勝ち上がってきました」
- ポイント: **その試合を理解している一言**。宣伝臭を消す。リンクは貼らない（プロフィールに置いておけば見に来る）
