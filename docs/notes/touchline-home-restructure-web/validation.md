## ローカルの表示・長さ

実際のHomePage・HomeMatchdayBoard・FeaturedCompetitionCard・NewsletterSignup・SiteFooterを、クエリをテスト用データへ置き換えて描画。外側のヘッダーは同じ56pxの簡易表示。書体・CSS・画像は同リポジトリのビルド出力／公開画像をローカル配信し、書体のロード後にChromiumで測定。ブラウザでは静的DOMなので、Next.jsの初期表示・通信・hydration・実際の性能を検証したものではない。試合・日付・順位・記事はテスト用のfixtureであり本番値ではない。
