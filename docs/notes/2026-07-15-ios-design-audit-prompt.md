実行環境（公平性のため両者同条件）: **どちらも `~/Documents/src/tryline-mobile` ディレクトリで起動**する（Fable = Claude Code の新規セッション、GPT-5.6 = Codex CLI）。画像は撮影リストのファイルをディレクトリ内（例: `tmp-audit/`）に置いてパスで渡すか、添付する。

## 監査プロンプト（ここから下を画像と一緒に貼る）

あなたはモバイルアプリのデザイン監査人です。添付した iOS アプリのスクリーンショット一式を監査し、指定フォーマットで指摘を返してください。

### プロダクト文脈

- アプリ名: Tryline。海外ラグビー（Six Nations、URC、Top 14 等）を観戦する日本のファン向けの日本語観戦アプリ。試合日程・スコア・順位・日本語の試合解説（プレビュー/レビュー）・視聴方法を提供する
- Web 版（trylinerugby.com）が先行しており、アプリは同一ブランドであるべき。比較用に Web のスクリーンショット（14 番）を添付している
- ブランドの方向: **新聞・エディトリアル**。紙の質感＋インクの文字＋赤のアクセントを最小限に効かせる。派手なグラデーションや汎用 UI キット感は避けたい
- デザイントークン: アクセント `#c93a40` / 紙 `#f5f6f8` / インク `#1f2530` / 淡色 `#767d8b`。本文はシステムフォント（ヒラギノ）
- v1 はライトモードのみ・iPhone 縦持ちのみ

### 監査の観点（この順で重み付け）

1. **一貫性**: 画面間で余白・角丸・カード・ピル・見出し階層・バッジの扱いがバラついていないか。後から足された画面/部品（視聴方法リスト・ステータスラベル等）が浮いていないか
2. **Web とのブランド整合**: 14 番の Web と並べて、同じサービスに見えるか。色・密度・トーンの乖離
3. **タイポグラフィと階層**: サイズ/ウェイトの段が意図的か。日本語の行間・折返し。長いチーム名（例:「ハリケーンズ」より長い欧州クラブ名）での崩れの予兆
4. **情報設計**: 各画面で最重要情報が最初に目に入るか。カレンダーの走査しやすさ、試合詳細のセクション順
5. **状態デザイン**: 空状態（3 番）・エラー（13 番）・マスク状態（2・7 番）・ペイウォール（5 番）が「デザインされている」か、それとも素のテキストか
6. **タップターゲットとアクセシビリティ**: 44pt 未満に見える要素、コントラスト不足（特に `#767d8b` の淡色文字と白背景）、Dynamic Type 拡大時に壊れそうな固定レイアウト
7. **App Store 映え**: この画面群からストア用スクリーンショットを作れるか。「顔」になる画面はどれか

### コード参照の扱い（このリポジトリで実行する場合）

- リポジトリのコード（`src/theme/tokens.ts`・コンポーネント群）は読んでよい。ただし**用途は「修正案をファイル名・値の粒度で具体化すること」に限定**する
- **判定の根拠は必ずスクリーンショット（実際の描画）**。「コード上はトークンを正しく参照しているから問題ない」という理由で指摘を却下しない — コードの意図と実描画が食い違うケースこそ監査の対象
- コードだけから発見した問題（スクショに写っていない画面・状態）は、指摘一覧とは別に「G. コードのみで気づいた点」として分けて報告する

### やってはいけない提案（制約）

- **課金導線の追加提案は絶対にしない**（価格表示・購入ボタン・Web の購入ページへのリンク。App Store 審査規約上、既存契約者のログイン案内以外は置けない）
- ダークモード対応・新機能の追加・ナビゲーション構造の変更は提案しない（別フェーズで判断済み）。**今ある画面の見た目と状態の質**に限定する
- スコアやチーム名など事実情報の文言変更は提案しない

### 出力フォーマット（厳守）

**A. 総評**（3 行以内）

**B. 良い点 3 つ**（キャリブレーション用。画面番号つき）

**C. 指摘一覧**（最大 15 件。多く挙げるより優先順位に自信を持つこと）

| # | 重要度 | 画面 | 指摘 | なぜ問題か | 具体的な修正案 |
|---|---|---|---|---|---|

- 重要度: CRITICAL（公開前に必須）/ HIGH（公開前に推奨）/ MEDIUM / LOW
- 「指摘」は現象を、「修正案」は実装者がそのまま着手できる粒度で（例:「余白を広く」ではなく「カード内 padding を 12→16 に統一」）

**D. ストア用スクリーンショットに推す画面トップ 3**（理由つき）

**E. もし 1 つだけ直すなら**（1 件選んで理由）
