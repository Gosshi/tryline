# 【今週の海外ラグビーまとめ】新生「ネーションズチャンピオンシップ」開幕、日本はイタリアに快勝(2026.7.4)

今年から始まった新しい国際大会「ネーションズチャンピオンシップ」が開幕しました。シックスネイションズ6か国(イングランド・フランス・アイルランド・イタリア・スコットランド・ウェールズ)と、南半球・アジアの6か国(ニュージーランド・南アフリカ・オーストラリア・アルゼンチン・日本・フィジー)が対戦する新フォーマットで、7月と11月の2フェーズ制。11月末のファイナルズウィークエンドで初代王者が決まります。

まずは7月4日に行われた6試合を、事前プレビューの予想が当たったか外れたかも交えて振り返ります(各試合のプレビュー・レビューはリンク先で今も読めます)。

---

## ニュージーランド 34–32 フランス

プレビューでは直近5試合平均でフランスが42.2点、ニュージーランドが30点と、フランスの攻撃力がどこまでニュージーランドの守備を崩せるかが焦点とされていました。実際も開始2分にフランスが先制トライで主導権を握るシーソーゲームに。ニュージーランドが追いつき前半を17–13でリードすると、後半はフランスが再逆転するも、50分の決勝的なトライで応じたニュージーランドが振り切り、終盤の猛追をしのいで2点差で逃げ切りました。プレビュー通りの大接戦を制したのはニュージーランドでした。

→ [試合ページ(プレビュー・レビュー日本語)](https://www.trylinerugby.com/matches/e13e388d-f870-4a27-bea5-e4ba3ef08d28)

## 日本 27–10 イタリア

プレビューでは日本の平均得点16点・平均失点33.6点という守備の課題が指摘され、勝率でもイタリア0.4対日本0.2とイタリアがやや上と見られていました。しかし蓋を開けてみれば日本が終始試合をコントロール。開始早々にイタリアに先制を許したもののすぐに追いつき、16分にトライとコンバージョンを連続で決めてリードを奪取。前半のうちに17–7と広げると、後半も追加点を重ね、キッカーの正確さも光って27–10の快勝。数字上の劣勢を覆す結果となりました。

→ [試合ページ(プレビュー・レビュー日本語)](https://www.trylinerugby.com/matches/f56e9ee9-14be-49e3-b47d-c51a29c07593)

## オーストラリア 31–33 アイルランド

プレビューでは直近の勝率がアイルランド0.8・オーストラリア0.2、平均得点も29.2対19.4とアイルランドが大きく上回り、直接対決も前回46–19の圧勝だったことから順当な差がつくと見られていました。ところが実際は前半だけでオーストラリアが24–12とリード。後半アイルランドが猛反撃し、46分に一度逆転するも、オーストラリアが再びリードを奪い返す激しい展開に。最後は77分の決勝的なキックでアイルランドがようやく突き放し、33–31でかろうじて逃げ切り。「アイルランド有利」という下馬評は当たったものの、中身はリードが何度も入れ替わる大接戦でした。

→ [試合ページ(プレビュー・レビュー日本語)](https://www.trylinerugby.com/matches/59513a57-27aa-4cfa-95a5-7f8a11410b59)

## フィジー 24–39 ウェールズ

プレビューでは直近5試合平均得点でフィジーが35.2点(カナダ戦では63点)・ウェールズが18点、勝率もフィジー0.6対ウェールズ0.2と、フィジー優勢と見られていました。しかし結果は真逆に。フィジーが開始2分に先制したものの、ウェールズが前半のうちに連続トライで逆転し10–7でリード。後半に入るとさらにギアを上げ、立て続けにトライを重ねてフィジーの反撃を封じ込みました。大差をつけての勝利で、プレビューの予想を覆す一戦となりました。

→ [試合ページ(プレビュー・レビュー日本語)](https://www.trylinerugby.com/matches/8504834e-d258-4a7b-9b03-554db1b0f426)

## 南アフリカ 45–21 イングランド

プレビューでは南アフリカが6連勝中で平均失点10.2という堅守も誇り、平均得点も44.4対30.6とイングランドを大きく上回っていました。実際も開始わずか2分のトライで早々に主導権を握ると、前半だけで17–12とリード。イングランドも食い下がりましたが、後半に南アフリカが立て続けにトライを重ねて突き放し、キッカーはコンバージョンを全て成功させる安定ぶりで45–21の完勝。数字通りの実力差を見せつける結果となりました。

→ [試合ページ(プレビュー・レビュー日本語)](https://www.trylinerugby.com/matches/b5b2af27-4b42-4d58-8ea9-f13d1e2b1466)

## アルゼンチン 38–47 スコットランド

プレビューでは、スコットランドが直近5試合で3勝(3月のフランス戦は50得点)、アルゼンチンは南アフリカに大敗した直近戦績が触れられつつも、対戦成績自体はアルゼンチンが優位という材料も紹介されていました。実際の試合も前半から一進一退の接戦に。アルゼンチンが6分に先制するも、スコットランドがすぐ追いつき前半を19–10でリード。後半アルゼンチンが追い上げる場面もありましたが、スコットランドが連続トライで突き放すと、終盤にアルゼンチンも連続トライで追いすがり、最後はスコットランドが47–38で競り勝ちました。直近フォームの良さを見せつける形となりました。

→ [試合ページ(プレビュー・レビュー日本語)](https://www.trylinerugby.com/matches/42bebc1f-9225-452b-9786-9e0a1fbaa34a)
