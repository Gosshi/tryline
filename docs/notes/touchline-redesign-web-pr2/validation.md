## 実装

- トップ: 既存の写真を全幅の静止ポスターとして使用。今週の取得結果による静的ティッカー、2列の試合ボード、レビュー1本を大きく残りを小さく配置。0本・1本・3本をテスト。今週0試合ではティッカー・ボードを出さず、次戦のカウントダウン・チームリンク・通知設定をヒーロー内に維持。
- 大会: 低い写真帯と墨色のスクリーン、下線ナビ、デスクトップの日程／順位2列、要約・アプリ案内・ニュースレターをデータの後ろに配置。スマホは明示的な `grid-cols-1` とし、順位表の最低幅が日程を横にはみ出させない。
- 2b: `getSeasonGroupDisplayOrder` は元のインデックスの表示順だけを返す。開閉対象・`data-round-index`・自動スクロール対象は元のインデックスで維持。既定で開く節→以降の節→「これまでの節」と以前の節の逆順。折りたたみ対象外や単一グループの表示は維持。`getDefaultOpenGroupIndexes` と元のデータは変更なし。
- Premium 案内: `SeasonMatchGroups` と週カレンダーリンクの後ろへ移動。`hasAnyContent` と CTA の値は維持。
- 試合: 左右のチーム色の面＋墨色のスコア箱、本文／要点2列。イベント0件では空の右列を作らない。本文は最大40em／15px。得点推移の階段グラフと有料／無料の境目は維持。
- ネタバレ防止: 新設のティッカー・大きなレビュースコア・試合スコアは既存の `SpoilerScore` を通す。既定オフ、ログイン設定オンで隠す挙動を維持。PR 3 の動きは追加していない。
