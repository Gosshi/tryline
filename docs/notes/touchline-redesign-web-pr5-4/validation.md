## 配置と実データに合わせた判断

- 墨色の低いプロフィール帯に、既存のチーム色で斜めの面・下方向の暗いグラデーション・細い円を作る。明るいオーストラリアの黄色にも暗い面を重ね、名前とリンクは紙色で読む。写真や画像の追加、クライアント JS の追加はない。
- チームは次戦を先にする。1024px 以上では次戦／スタッツの 2 列、スマホでは次戦→スタッツ→直近の試合→選手。次戦がない場合はスタッツの従来の列数を維持する。試合の並び替え、取得条件・件数の変更はしていない。
- チームの試合一覧は既存 MatchCard の表示分岐をそのまま使い、CSS で日時／チーム名とスコア／会場とコンテンツの札を並べる。`layout="row"` への変更はせず、略称・正式名・勝敗・会場・プレビュー／レビューの札を残す。放送リンクは引き続き試合リンクの外に置く。
- 選手はプロフィール→通算成績→出場試合→次に見るの順を維持する。成績に紙色の面と真鍮の罫線を付け、数字は Outfit。チーム／選手の長い名前は切らず折り返す。
- 国名、ポジション、所属、スコア、スタッツがない場合の既存フォールバックと条件を維持する。位置不明の選手に推測で役割を追加しない。実在選手の写真を追加せず、既存のバッジと汎用アバターを使う。
- スコアの新しい表示場所や数え上げは追加していない。チームの既存 MatchCard と選手の既存 formatScore の挙動を維持し、SpoilerScore／設定を変更していない。ログインした状態でのネタバレ防止の実操作はこの検証では未確認。
