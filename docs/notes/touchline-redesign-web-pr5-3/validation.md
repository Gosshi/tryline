# Touchline PR 5-3: 順位表ページ

基点: 最新 `origin/main` の `5c465e9b`（#914 マージ後）。対象は `/c/[competition]/[season]/standings` のみ。権威ある文書は `specs/feat-touchline-redesign-web.md` の PR 5／「守ること」1〜9と `docs/codex-prompts/feat-touchline-redesign-web.md`。文書はmainに含まれるものを参照し、改訂していない。

## 変更と実データに合わせた判断

- 低い墨色の帯に、既存のパンくず・日本語のh1・更新日時をまとめた。A4の斜めの面と細い線、真鍮の下罫線を再利用。長い大会名は折り返し、固定高さで切らない。
- 大会・日程・カレンダーへの既存の導線を表の前に移動し、下線のタブにした。現在地「順位表」はリンクではない。既存のリンクの文言・行き先・`standings_calendar` の計測値は維持。3つの導線の高さは44px。
- 全順位表を紙色の誌面に載せ、二重罫線、大きな順位と勝点、細いチーム色で視線を揃えた。順位・勝点はOutfit。チーム色は既存の `getTeamStripe` をそのまま利用し、順位に応じた大会色の淡い背景も維持。
- 明るい色の線や濃淡に本文が影響されないよう、表の本文は墨色 `#20232a`。チーム色を文字の背景として使わない。チーム色から新しい順位の意味や勝ち抜け条件は付け加えない。
- デスクトップは従来の9列（#・チーム・試・勝・分・敗・得点・T・勝点）。スマホは従来の略称と6列（#・チーム・試・勝・敗・勝点）を維持し、このページ内だけ最小幅を解除して勝点まで表示。正式名と残りの数値もサーバーHTMLに残る。
- プール別の大会は同じ順序・同じ見出しで縦に並べる。プールの統合・並べ替え・新しい集計は行わない。
- `StandingsTable` のファイルは変更していない。スタイルは `.tl-standings-sheet` 内に限定し、トップ・大会ハブ・試合の表には及ばない。新しいclient部品・画像・動き・依存は追加しない。
- データ取得、順位表なしの404、h1の文言、メタデータ、パンくずJSON-LD、静的パラメータ、900秒のrevalidateは維持。更新日時は取得値をそのまま表示し、鮮度の推測や日付の補完は行わない。
