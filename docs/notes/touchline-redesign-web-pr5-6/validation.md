# Touchline PR 5-6: RWC 2027 専用ページ・ブラケット

2026-10-05。`origin/main` の `86794974`（#917 マージ済み）から `codex/feat-touchline-redesign-web-rwc` を作成。

## 対象と判断

- `/c/rwc/2027`: 既存の `tl-season-band` / `tl-band-art` で低い墨色の帯。h1の文言、メタデータ、FAQ JSON-LD、revalidate=3600を維持。
- 会場一覧を日程・プール分けの後ろへ移動。開幕前は日程→プール分け、開幕後は順位表→日程という分岐を維持。現在の36試合と大会全体の52試合を混同しない既存の案内も維持。
- 日程は既存のSeasonMatchGroupsをそのまま使用。プール順、試合順、フィルター、既定の開閉、SSR試合リンクを変更せず、専用ページ内だけ下線のタブ・大きめの明朝見出し・二重罫線を適用。
- プール分け・会場・ガイド・未公開案内は紙色と罫線。ガイドの本文、最終確認日、参照元、国内放送未発表の文言は変更なし。
- `/c/rwc/2027/bracket`: 同じ墨色の帯と紙色の案内。出場チーム未確定／ノックアウト日程未取得／大会情報取得不可の3状態と判断条件を維持。既存のh1の文言・個数（未確定画面では2個）、メタデータ、revalidate=60を維持。
- 対戦表の既存4ステージと枠数・roundの判定・日時順・TBDは変更なし。大きな05〜08は既存のround値から描く装飾（aria-hidden）で、実データに無い対戦やスコアは追加しない。
- チーム色は既存getTeamColor(slug)。斜めに切り分けた帯に限定し、文字とスコアは紙色の上の墨色。明るいチーム色でも文字に重ならない。未登録チームは既存のデフォルト色。
- 長い文字は折り返す。試合前は従来どおり日時と「予定」で、結果を作らない。既存のスコア出し分け、SpoilerScore、設定、数え上げは変更なし。日程の試合行も既存部品を保持。
- CSSはtl-scope内のRWC用クラスに限定。PoolTeamGrid等の他ページに使われる部品は変更なし。新しい依存、画像、JS、動き、データ取得は追加なし。

## スクリーンショットの条件

修正前は公開中の `https://www.trylinerugby.com/c/rwc/2027` と `/c/rwc/2027/bracket`。修正後は実装したページ・共有部品をrenderToStaticMarkupで描いたローカルの静的HTML。

公開ページのRSCにある36試合（日時、チーム、会場、状態）を使用。プール分け24チームの名前、ガイドの表示本文・参照元・確認日は公開HTMLから取得。未取得の順位数値は作らず、現在の開幕前画面では順位表を表示しない。DBやLLM APIは呼ばない。共通ヘッダー・フッター・フォントは公開HTMLを保持し、実装のTailwind CSSを追加。

静的SSRなので、Next.jsのhydration、ログイン、フィルター操作のE2Eやデプロイ後の性能を検証するものではない。Vercelは開いていない（Ownerが以後確認する方針）。
