# ハンドリングは直っていた。それでも後半0-35だった日本代表

17-56。リポビタンDツアー2026の第2戦、オーストラリア・タウンズビルでの一戦は、こういう数字で終わった。第1戦が32-35の3点差だったことを思えば、1週間でずいぶん遠いところまで来てしまった。

ただ、この39点差を「何もかもダメだった」とまとめると、見落とすものがある。**直っていたものは、確かにあった。**

## 前半だけを見れば、第1戦と同じ試合だった

先制したのはオーストラリアだった。7分にジョシュ・ナッサーが先に出る。日本は12分にハリー・ホッキングスが返すが、17分にタニエラ・トゥポウに突き放される。5-14、この時点では離されかけていた。

そこから日本が戻した。26分に齋藤直人、33分にディラン・ライリー。**17-14、日本が逆転していた。**

しかし39分にトゥポウがこの日2本目を挙げ、前半は17-21で折り返す。4点差である。

ボール保持率も前半は49%だった。**ほぼ互角に殴り合っていた。** 第1戦の前半が14-14だったことを思えば、数字の並びとしては同じ試合をしている。

問題はここから先だ。

## 後半に、すべてが出た

両試合の前後半を分けるとこうなる。

- 第1戦（8/8・大阪）　前半14-14 / 後半18-21
- 第2戦（8/15・タウンズビル）　前半17-21 / **後半0-35**

**第1戦は後半も競っていた。** 45分にトライを返し、53分と59分に松永拓朗がペナルティゴールを重ね、78分にはワーナー・ディアンズが取り切って3点差まで詰めている。最後まで試合の中にいた。

第2戦の後半、日本の得点は0である。オーストラリアは後半だけで5本のトライを重ね、コンバージョンはこの日8本すべてを決めた。

ボール保持率は後半33%まで落ちた。**そして最後の10分は7%。** 終盤の日本は、ほとんどボールを持てていない。

39点差という数字は、後半の40分だけで作られている。

## 直っていたもの

第1戦のあと、エディー・ジョーンズHCは敗因を「基礎的なスキル」と総括した。

その一点について言えば、答えは出ていた。**ハンドリングエラーは目に見えて減っていた。** 数字でも確認できる。この試合で日本が相手に与えたターンオーバーは6回。**オーストラリアの15回より少ない。**

ボールを持つ時間が短かったことを差し引いても、5-14から26分と33分に連取して逆転した流れは、手放して失う形が減っていたことの結果だろう。

だから「何も変わらなかった」ではない。**変えようとしたところは、変わっていた。**

## 直らなかったもの

**ミスタックル52本。**

オーストラリアは14本だった。この一行が、この試合のすべてを説明していると思う。

数字を並べるとこうなる。

- **ミスタックル　日本52 / オーストラリア14**
- **ディフェンダーを抜かれた回数　日本14 / オーストラリア52**
- **与えた反則　日本13 / オーストラリア5**

日本のタックル成功率は76.9%（173本成功・52本ミス）。オーストラリアは90.1%（128本成功・14本ミス）だった。抜かれた回数が14対52と、ちょうど裏返しになっているのも象徴的である。

**一人目が止まらない。止めてもペナルティになる。** 反則13という数字は、後者がどれだけ起きていたかを示している。止めたことにならないタックルが続くと、守備は前に出られなくなる。前に出られない守備は、次の一人目もまた止められない。

象徴的だったのがトゥポウだ。**前半だけで2トライ**。17分と39分、どちらも突進を受け止めきれなかった。

後半に入ってこの傾向は加速する。

終盤、自陣ゴール前の何でもないノックオンから、相手ボールのスクラムになった。押し込まれ、そこで日本の足が止まった。なぜ止まったのかは分からない。**ただ、プレーは続いていた。** オーストラリアはそのまま持ち出して、トライにしている。

その直後の失点は、性質がまるで違う。押し込まれたわけでも、判断を誤ったわけでもない。**ディフェンスが機能しないまま、簡単に運ばれた。**

片方は「止まってしまった」問題であり、もう片方は「止められなかった」問題である。**種類の違う2つが、わずかな間に続けて起きた。**

セットプレーも崩れていた。ラインアウトの成功率は62%。16本すべてを獲得したオーストラリアに対し、日本は3本を失っている。**自分たちのボールが確保できなければ、守る時間はさらに延びる。**

攻撃も同じ根から出ている。人数で上回っている場面でパスが出ず、トライにならない。取れた3本も、組織で崩したというより個人技によるものだった。

そして、**この56失点は最悪の数字ですらない。** オーストラリアがトライ直前にノックオンした場面が何度かあった。あれが続いていれば、点差はさらに開いていた。

ボールを持てば個で剥がされ、持たれれば個で止められない。80分を通して、**個の勝負でことごとく上回られていた。**

これは戦術より前の段階の話だと思う。どう並ぶか、どこへ動くかを詰める以前に、**一対一で立てるかどうか**が問われている。第1戦後にジョーンズHCが挙げた「基礎」とは、本来ここまで含む言葉だったはずだ。ハンドリングという分かりやすい一点は1週間で戻った。だが、より深いところにある課題は残ったままだった。

## 11月に向けて

日本代表は11月、ウェールズ（11/7）、イングランド（11/14）、スコットランド（11/21）と3週続けて戦う。いずれも欧州での試合だ。

80分を終えて残ったのは、**ディフェンスができないチーム**、という印象だった。厳しい言い方だが、ミスタックル52本と反則13という数字は、その印象を裏切らない。

ただ、今回の2試合が示したのは、**修正できる課題と、修正できていない課題が、はっきり分かれている**ということでもある。ハンドリングは1週間で変えられた。守備の一人目は変えられなかった。

3か月ある。前半だけなら第1戦も第2戦も競っていた、という事実は、悲観だけで終わらせる材料ではない。ただしミスタックル52本と反則13を抱えたまま欧州へ行けば、同じ40分がもう一度来る。
