## 実データへの判断

1. チーム色は A4 の固定色を採用せず、既存の `getTeamColor`。略称は `shortCode`、未設定時は実際のチーム名を折り返す。
2. 明るい色: レビューの略称・スコアは A4 と同じ墨色の札。面上のチーム名にも墨色の小さい背景を付け、色の組み合わせに依存せず読めるようにした。試合帯のチーム名と略称は既存の輝度判定による白／暗色と静的な色面を継続し、チーム面がスライドしている途中も読める。オーストラリアの黄色では暗色。
3. グラフはチーム色を保持し、明るい線の輪郭に墨色を重ねる。凡例の文字はチーム色で着色せず補助文字色にする。凡例はSVGの外に通常のHTMLで描画。
4. 長い名前: 試合帯のデスクトップ省略を外し、名前を折り返す。レビューのチーム名も折り返し、小カードの略称とスコアは必要なら次の行へ送る。
5. 試合前／スコアなし: 既存のVS・日程行の「—」を継続し、0–0を作らない。レビューの件数・選び方・抜粋は変更しない。
6. ネタバレ防止: レビュー大・小、ティッカー、試合帯のスコアは既存の `HomepageSpoilerScore` / `SpoilerScore` を継続。札や装飾に結果を複製しない。既定オフ、ログインした人の設定、表示操作、数え上げ禁止の条件は継続。
7. A4 の試合行は2段だが、Owner がPR #909で指定した日時｜チーム｜スコアの1行を継続。A4 の装飾だけを移して密度を保つ。
8. 国旗・放送・YouTube・H2H・大会の実データの集計は継続。固定データしかないモックに合わせて情報を削らないため、スコア帯と注目大会の高さは完全一致させない。
9. グラフはモックの3時点の補助線・固定の得点表を採用しない。実際の得点推移と試合経過、既存の配置を継続。
10. モックのGeorgiaの数字はOutfitで表現し、見出しはShippori Mincho B1の800を継続。ロゴ・ナビゲーションも実装のものを継続。
