# A2 — THE TOUCHLINE 改訂モック

2026-10-04。Aをベースにチーム色を残す方向で作成した、デザイン検討用の独立HTMLです。

[改訂モックを開く](mock-a2.html) / [元のA案](mock-a.html)

## 反映したこと

- 深緑・紙のような背景・明朝見出しを維持。見出しの基本ウェイトを700にし、本文・順位表はゴシック体のまま。
- 主要ボタンを深緑 `#203C30` ＋白文字へ変更。真鍮色 `#956137` は小見出し・区切り・ロゴの点に限定。テキストリンクには下線を追加。
- Web試合とiOS試合のスコア帯上端に、ホーム／アウェーのチーム色を同じ幅で配置。チーム名の横にも色を付けた。勝敗によって色や幅は変わらない。
- 大会の日程・順位、アプリの順位、ストーリーズ入口にもチーム色を反映。色は `lib/format/team-identity.ts` の既存定義を転記し、ロゴや試合写真は使っていない。
- 数字をAvenir Next／Bahnschrift系のゴシック体へ変更。ロゴと大見出しの誌面らしさを保ちながら、日程・結果・順位の一覧性を補う。
- アプリの得点グラフはトゥールーズの赤／モンペリエの青に変更し、実線／破線も維持。スコアを隠すとグラフ・得点経過も隠れる。
- トップの動画ポスターだけに、最大12pxの小さなスクロール連動を追加。画面の固定・スクロールの乗っ取りなし。スマホ幅とReduce Motionでは停止。動画は未収録で、配置枠の表現のみ。
- 上部の比較用ツールバーで、見出しを明朝／ゴシックに切替可能。製品の設定追加ではなく、Windowsで字形を比較するためのモック用操作。

## 使い方

単独HTMLをブラウザで開き、上部の6タブでWebトップ／大会／試合、Appホーム／試合／大会を切り替えます。アプリ試合の「スコアを表示」「試合データ」で両状態を確認できます。アプリの文字サイズは端末枠外で変更します。

試合・日程・順位・記事本文は元のA案から引き継ぎました。画像02の順位は確認できた上位3行のみ。元画像と転記範囲・集計時点の注意は [初回提案書](result.md) を参照してください。初回提案書の「Cをおすすめ」という評価は初回時点の記録であり、今回の検討方向はA2です。

## 確認結果

- 1440×900、390×844、768×1024で6画面を切り替え、ページ全体・端末内の横はみ出しなし。
- 大会の最初の試合行は、比較ツールバー込みで1440px時に下端623px、390px時に710px。最初の画面内に表示。
- アプリ3画面と表示中の得点経過で、文字200%でも横はみ出しなし。
- スコアの非表示→表示→非表示、プレビュー／試合データ、明朝／ゴシック、第5節／第4節の切替を確認。
- ブラウザで外部リソース取得なし。コンソールのerror/warnなし。
- Windows実機の明朝描画、iOS Dynamic Type／VoiceOver、本番LCP・CLS、動画再生は未確認。Reduce Motionは条件分岐とCSSを確認した段階で、OS設定での動作確認は未実施。
