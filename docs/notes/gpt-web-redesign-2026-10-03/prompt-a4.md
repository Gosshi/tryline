# GPT 依頼: A4（アイコン据え置き＋動き）（2026-10-04）

Owner の判断（2026-10-04）: アプリのアイコン（黒地・赤い線・白いボール）は変えない。サイトに動き（アニメーション）が欲しい。

## そのまま貼る文面

```
A3 をもとに A4 を作ってください。条件が 2 つ増えました。

### 1. 色: アプリのアイコンを変えないので、アイコンに合わせる
- アイコンは「黒に近い地・赤い線・白いボール」。サイトとアプリの主役の色をこれに揃えてください。
- 深緑はやめ、大きな面（トップ最上部・大会ページの帯・スコアの箱）は墨色（黒に近いインク色）にする。
- 押す場所・ロゴの点・強調は赤 #c93a40（今のブランドの赤）。赤は小さい面だけに使う。
- 紙色の背景、明朝の見出し、金色（真鍮）の小見出しは A3 のまま残してよい。
- 試合のスコア帯は A3 と同じくチーム色の面。墨色のスコアの箱なので、緑や赤のチームともぶつからないことを確認してください。

### 2. 動き: サイトとアプリに「動いている感じ」を足す
モックの中で実際に動かしてください。条件は、transform / opacity / clip-path / SVG の線だけを動かすこと、スクロールを乗っ取らないこと、prefers-reduced-motion では全部止まって最終状態で表示されること、ライブラリを使わず CSS と少量の JS（IntersectionObserver）で作ること。

Web:
a. トップ最上部: 紹介動画の代わりに、ポスターがゆっくり動く（ズーム・横移動。後で本物の動画に差し替える前提）。見出しは 1 行ずつ下から現れる。
b. 今週の試合のすぐ上に、試合と結果が横に流れる帯（ティッカー）。マウスを乗せると止まる。
c. スクロールで各セクションが下からふわっと現れる。試合の行は少しずつ時間差で。
d. 試合ページ: スコア帯のチーム色が左右からスライドして入り、スコアの数字が 0 から数え上がる。得点推移のグラフは線が左から描かれる。
e. 大会ページ: 順位表の行が上から順に現れ、勝点の数字が数え上がる。
f. カード・試合の行: マウスを乗せるとチーム色の線が伸び、少し浮く。押したときに少し沈む。

アプリ（React Native / Reanimated で実装できる範囲で）:
g. 「スコアを表示」を押すと、隠していた面がめくれるように開き、数字が数え上がる。
h. 試合データのグラフは線が描かれる。
i. 大会の順位表は行が順に現れる。

### 守ってほしいこと
- 大会ページで、最初の試合と順位表が 1 画面目に見えること（動きが終わる前でも読めること）。
- 動きは 1 回だけ。ループし続けるのはトップのポスターとティッカーだけ。
- 数え上げやスライドは 0.6 秒以内に終わること。
- 性能: LCP 2.5 秒未満・CLS 0.1 未満の前提を崩さない（レイアウトがずれる動きを入れない）。
- スコアを隠す操作（アプリ）は、動きを足しても結果が漏れないこと（数え上げの途中の数字も見えないこと）。
- 変更点と、動きの一覧（どこで・何が・何秒）を revision-a4.md にまとめてください。
```
