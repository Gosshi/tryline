# A3 — THE TOUCHLINE

[モックを開く](mock-a3.html) / [A2と比較](mock-a2.html)

Aの深緑・紙色・真鍮色、明朝見出しを維持し、情報の密度よりもビジュアルの面積と大小の差を大きくした案です。Web 3画面・iOS 3画面を上部のタブで切り替えられます。単独HTMLで動き、外部画像・フォント・ライブラリを取得しません。

## 検証

- 1440・390・768pxで6画面を切り替え、ページ全体とiPhone枠内に意図しない横はみ出しなし。
- 大会の初回表示、日程／結果、節番号、詳細表の展開、明朝／ゴシック切替を確認。
- アプリ3画面と得点データで文字200%時の横はみ出しなし。iPhone枠は430×932pxを維持。
- スコアの非表示→表示→非表示で、得点グラフ・経過も連動することを確認。
- 外部リソースのリクエストなし。コンソールerror/warnなし。動作中のアニメーションなし。

## 性能と未確認事項

**LCP 2.5秒未満・CLS 0.1未満は、本番実装で守る目標です。このモックで本番性能を保証するものではありません。**

全幅の動画は初回から領域を確保し、軽量な静止ポスターと見出しを先に表示する方針。完成動画は主要コンテンツの表示後に取得し、スマホ・Reduce Motionでは自動再生せず静止ポスターを表示します。デスクトップで動画を入れる段階では停止操作・画面外での停止を追加し、最終素材でLCP/CLSを計測します。モックには動画取得・連番画像・WebGL・スクロール演出用ライブラリを含めていません。

紙目は120×120の小さな静的タイルを使用し、全面に動的なフィルターを重ねていません。

Windows実機の明朝描画、iOS実機のDynamic Type／VoiceOver／戻るジェスチャー、動画再生・実際の読み込み速度は未確認。アプリ本体・仕様書・意思決定記録・A2には変更せず、独立したモックとこの記録のみを追加しています。
