# アプリアイコン方針 — Fable / GPT-5.6 並行レビュー用

使い方: 下の「状況」「レビュープロンプト」を Fable（Claude Code 新規セッション）と GPT-5.6（Codex CLI）両方に貼る。本リポジトリ（tryline）で実行可。画像添付は不要（アイコンはテキストで精緻に記述済み）。

## 状況

Tryline の iOS アプリ（tryline-mobile）は App Store 提出前だが、**専用のアプリアイコンがまだ無い**（Expo デフォルトのまま、`app.config.ts` に `icon:` 指定なし）。

調査の結果、以下が判明した:

1. **Web サイト自体に画像ロゴが存在しない**。サイトヘッダーの「● Tryline」は画像ではなく CSS で描画した円（`components/site-header.tsx`: `<span className="h-2.5 w-2.5 rounded-full bg-[var(--color-accent)]" />`、色は `--color-accent` = `#c93a40`（赤））
2. `public/icons/` に PWA 用アイコン（icon-192.png 等）はあるが、**緑背景に白い円**という内容で、ブランドと無関係な放置プレースホルダーと判断される
3. **X（@tryline_rugbyjp）・note（tryline_rugbyjp）のプロフィールアイコンは既に存在する**。実物を目視確認した結果:
   - 紺色（ネイビー）の円形バッジ
   - 白抜きのラグビーボール（縦置き、緑色の縫い目ライン入り）のイラスト
   - バッジ下部に白抜き文字で「TRYLINE」（全て大文字、サンセリフ）
   - 全体としてスポーツチームのエンブレム/バッジ風のデザイン

Owner から「このX/noteのアイコンをそのままApp Storeアイコンに使えないか」という提案があった。

## サイトの確立されたブランド言語（参考）

2026-07-15〜16 のデザイン監査（本ファイルと同じ Fable/GPT-5.6 並行レビュー手法で実施済み）で、Web・アプリ双方について以下が確定している:

- アクセントカラーは赤 `#c93a40` のみ、用途を3つに限定（大会名等のラベル語／ネタバレ関連／主要CTA）
- 紙 `#f5f6f8` ＋ インク `#1f2530` を基調とした新聞・エディトリアル方向
- 角丸は小さく（8pt基準）、影を使わず罫線で区切る
- 試合詳細のマストヘッドは「インク単色の帯＋赤の細い罫線」という記号で統一（グラデーション不使用）
- 国旗・チーム識別に絵文字を使う以外、装飾的なイラスト・アイコン類はほぼ使っていない

これに対し、X/note のアイコン（紺＋緑、ラグビーボールのイラスト、バッジ/エンブレム調）は色・モチーフ・トーンいずれも一致しない。

## Claude Code（このセッション）の暫定見解

X/note アイコンの流用には否定的。理由: (1) 色が確立ブランド（赤）と別系統（紺+緑）、(2) ラグビーボールの円形バッジは汎用的でTryline固有の差別化（日本語・大会横断・エディトリアル）を表現できない、(3) App Store の極小表示サイズでボールの縫い目等の細部が潰れる懸念。新規に赤ベースの専用アイコンを作るべきと考えている。ただしこれは一人の判断であり、Owner の意向で別の結論もあり得る。

## レビュープロンプト（ここから下を貼る）

あなたはモバイルアプリのブランド/アイコンデザインに詳しいアドバイザーです。上記の「状況」を読み、Tryline の App Store アイコンをどうすべきか、独立した意見を述べてください。Claude Code の暫定見解に引きずられず、あなた自身の判断を優先してください。

### 検討してほしい選択肢

1. X/note のアイコン（紺＋緑のラグビーボールバッジ）をそのまま流用する
2. X/note のアイコンをベースに、色だけ Tryline の赤系に変更して流用する
3. Web/アプリの確立されたブランド言語（赤・紙・インク・エディトリアル）を土台に、新規デザインを起こす
4. その他の折衷案があれば提案してよい

### 判断材料にしてほしい観点

- **ブランド一貫性**: X・note・Web・iOSアプリという複数チャネルでの見え方の統一。SNSプロフィールとApp Storeアイコンが必ずしも同一である必要があるか（例: 多くのアプリはSNSアイコンとアプリアイコンが異なる）
- **App Store 表示上の実用性**: 検索結果・ホーム画面での極小サイズ（60px前後）での視認性、複雑なイラストが潰れないか
- **差別化**: 「日本語×海外ラグビー横断×日本での視聴方法」というポジショニングをアイコン単体でどこまで表現すべきか、あるいは表現しなくてよいか
- **実務コスト**: 新規デザインを起こす場合の工数・Owner側の意思決定負荷 vs 既存アセット流用の速さ
