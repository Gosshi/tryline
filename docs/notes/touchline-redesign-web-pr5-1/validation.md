# Touchline PR 5-1: 対戦成績・大会トップ・節ページ

基点: `origin/main` の `6c273a2e`（#912 マージ後）。仕様: `specs/feat-touchline-redesign-web.md` 末尾の PR 5、既存の「守ること」1〜9。仕様書・指示書は基点に存在するものを使用し、改訂していない。

対象を仕様の順に分割した最初の PR。今回の対象は `/h2h/[pair]`・`/c/[competition]`・`/c/[competition]/[season]/round/[round]`。カレンダー以降は、この PR のマージ後に続ける。

## 見た目の判断

- 対戦成績: 実データのチーム色を斜めに切り分け、下に向かう墨色のグラデーションと円の線を重ねた表紙。チーム名・h1 は墨色の札に置き、明るい色でも白文字の背景を確保した。通算成績は紙色の下段に Outfit で並べた。
- 直近と次回の対戦は紙色の2列（モバイルは縦積み）。個別スコアを目立たせ、CTA は既存のリンク・計測を維持。
- 収録試合と全履歴は罫線の一覧。長いチーム名は省略せず折り返す。履歴の「残りの試合」の details と全履歴のサーバー出力を維持。
- 大会トップ: 既存の生成ビジュアルを残し、墨色のスクリム、真鍮色の罫線、明朝見出しを重ねる。現在シーズンの要約を先頭に維持。順位の抜粋は既存の compact 表で勝点まで収め、全順位表へのリンクを残す。
- 最近のレビューは既存の `MatchCard` の1行表示を使用。従来カードの会場と W/L 札はこの一覧では省略する。W/L による個別結果の漏れを避け、日付・チーム名・スコア・試合リンクを残す。
- 大会ガイドの本文・確認日・リンクは維持。本文はゴシック、見出しは明朝とし、紙の余白と真鍮の左罫線でまとめる。
- 節ページ: 墨色の帯と大きな日付、時間｜チーム 対 チーム｜スコアの一覧。普通の節だけ大きな節番号を付ける。PNC の `101` は内部のステージ識別子なので「第101節」にせず、従来の h1「準決勝」と日付「12」を使用。
- 試合前は既存の「試合前」または状態札を残す。終了扱いでスコアが欠けている場合は、以前の 0 補完を表示用の「—」に置き換える（DB・集計・選択条件は変更しない）。
- 新しく目立たせる個別スコアは既存の `UserStateProvider` / `HomepageSpoilerScore` / `SpoilerScore` を使用。既定オフ、設定取得・クリック/Enter/Space での開示は既存の仕組み。数え上げは追加しない。通算の勝敗集計は既存どおり。

## スクリーンショットの作成条件と限界

修正前は公開サイト `https://www.trylinerugby.com` の実画面。修正後は、その公開 HTML に表示されているデータを query fixture として渡し、変更後の **ページ関数・React コンポーネントを renderToStaticMarkup で実際に描画**したローカル静的画面。Tailwind は変更後の `app/globals.css` から生成した。共通ヘッダー・フッターと大会ガイド本文は公開 HTML を保持している。DB への接続や記事生成は行っていない。

viewport は 1440×900 / 390×844、DPR 1。全ページをキャプチャし、左に修正前、右に修正後を原寸で配置した。ブラウザの縦スクロールバー分は撮影画像に含まれない。比較以外の元画像も同じディレクトリに保存している。
