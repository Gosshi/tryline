## 2. 仮説

### H1: Google は「評価していない」のではなく「需要のない時期を見ている」

**根拠**: 大会ハブの順位は6〜15位で取れている。にもかかわらずインプレッションが極小。8月にシックスネイションズを検索する人はいない。

**含意**: SEO の作り直しは不要。**ピーク期に何が起きるかを見るまで判断できない。**

**検証**: 2026年11月（Nations Championship = 日本代表欧州遠征）と2027年2月（Six Nations）の GSC 実測。同じ順位でインプレッションが2桁増えるかどうか。

**これが正しければ**、いま最も価値があるのは「ピーク期に順位を保ち、CTR を上げておくこと」になる。

### H2: Bing が効いているのは鮮度優位

**根拠**: Bing 99ユーザー・75秒滞在に対し Google 23ユーザー。日本の検索シェアは Google 7割超、Bing 数%。**シェアと逆転している。**

Tryline は IndexNow を実装しており Bing は即座に反映する。Google は IndexNow を使わない。

**含意**: 試合直後など**情報の鮮度が価値になる瞬間に、Bing だけが Tryline を載せている**可能性がある。

**検証**: Bing Webmaster Tools でクエリ別データを取り、Google との差分を見る。**未実施。**

**これが正しければ**、鮮度が武器になるクエリ（結果・順位・日程）に集中投資する根拠になる。

### H3: 商品は記事ではなく大会ハブとカレンダー

**根拠**: 大会ハブ107秒・カレンダー120秒に対し、試合ページ3.6秒。8/8 の日本戦ページはわずか7セッション。

934本の記事は**集客にほぼ寄与していない**。人は「試合の解説」ではなく「日程・順位・結果の一覧」を見に来ている。

**含意**: コンテンツ生産の増強より、**ハブとカレンダーの完成度**が集客に効く。

**検証**: 既に実測で強く示唆されている。追加検証は不要。

### H4: リテンションは「壊れている」のではなく「試せていない」

**根拠**: iCal 購読は実装済み・最も見られるページに導線もある。それでも7日で1リクエスト。

ただし **71セッションでは転換率を評価できない**。優秀な CTA でも2〜4件で、ゼロとの差はノイズ。

**含意**: 母数が無い状態で受け皿を磨いても判定できない。**集客が先。**

### H5: 被リンクの不在が Google の権威評価を抑えている

**根拠**: 日本語で海外ラグビーを継続的に扱う個人媒体はほぼ存在せず、被リンク獲得の探索は凍結済み。

**含意**: 従来型の被リンク施策は使えない。**別の権威シグナル**（滞在時間・再訪・直接流入）で代替するしかない。

### H6: 日本代表戦は「4日間の集客イベント」である

**根拠**: 上昇はメンバー発表日から始まり、翌日まで続く。試合当日だけではない。

**含意**: 11月の3試合は**12日分の窓**になる。準備の単位を「試合日」ではなく「発表〜翌日」で設計すべき。

## 3. プラン

持続性で3段階に分ける。**S = 一度作れば効き続ける / M = 継続運用が要る / L = 単発**

### A. 検索を太らせる（持続性 S）

**A1. 大会ハブの完成度を上げる**
順位6〜15位は取れている。同じ順位でも**CTR とタイトルで流入は変わる**。ハブは32大会分あり、一度作れば毎シーズン効く。
- 効果: ピーク期に最大化。11月・2月で検証可能
- 工数: 中
- **今日の欧州クラブ2026-27対応（PR #675-677）はこの一部**

**A2. 順位表を独立ページにする**
GSC 最大のクエリは「シックス ネーションズ 順位」（53インプレッション）。「順位」は**季節を問わず立つクエリ**で、大会数だけ横展開できる。現状は大会ハブ内の1タブ。
- 効果: 中〜大（クエリの数だけ増える）
- 工数: 中
- 持続性: **S**（一度作れば全大会・全シーズンで効く）

**A3. 放送情報を全試合に入れる**
「どこで見られる」は確実に検索需要がある。現状、日本代表戦以外はほぼ空。自動取得は JRFU 経由の日本代表戦のみ。
- 効果: 大（購買意図に近いクエリ）
- 工数: 大（ソース確保が課題）
- 持続性: **S**

**A4. H2H ページの拡充**
`/h2h/argentina-vs-england` が17セッション。対戦カードのクエリは**試合前に必ず立つ**。組み合わせの数だけページが作れる。
- 効果: 中
- 工数: 中
- 持続性: **S**

**A5. カレンダーの内部露出を上げる**
滞在120秒で全ページ中最長なのに11セッション。**最も刺さるページに人が届いていない。** トップ・ハブからの導線を見直すだけ。
- 効果: 中
- 工数: **小**
- 持続性: **S**

### B. Bing を伸ばす（持続性 M、即効性 高）

**B1. Bing Webmaster Tools のデータを取る**
**未実施。** Bing が最大の流入源なのに、どのクエリで来ているか把握していない。GSC は見ているのに Bing は見ていない。
- 効果: 不明（まず測る）
- 工数: **小**
- **最優先の調査**

**B2. 鮮度で勝てるクエリに集中する**
H2 が正しければ、IndexNow の即時反映が効くのは「結果」「順位」「日程」。試合直後の更新速度を上げる。
- 効果: 中
- 工数: 中

### C. 再訪を作る（持続性 S、ただし母数が要る）

**C1. iCal 購読の露出改善**
実装済み・導線あり・購読ゼロ。**まず母数を作ってから判定する。**
- 11月に実施するのが正しい

**C2. メール捕捉**
未実装。`feat-weekly-digest-cron` は Discord 送信でメールではない。**新規 spec が要る。**
- 効果: 大（唯一の恒久的な再訪装置）
- 工数: 大
- 持続性: **S**
- **11月までに作るべき最有力**

**C3. PWA インストール導線**
モバイル PWA として配信済み。ホーム画面追加は最も摩擦の少ない再訪装置。
- 効果: 中
- 工数: 小

### D. SNS（持続性 M〜L）

**D1. X の reply 継続**
28日で13セッションと小さいが、**8月に日本のラグビーファンが集まる唯一の場所**。
- 工数: 10分/日
- 持続性: **M**（止めると消える）

**D2. メンバー発表日の投稿**
H6 より、上昇は発表日から始まる。**8/6 は何も投稿していなかった。** 8/13 の発表が次の機会。
- 工数: 小
- 即効性: 高

**D3. 試合中の実況タイムライン参加**
中継中に検索する視聴者が最も濃い。
- 工数: 小
- 持続性: L

### E. 外部媒体（持続性 M）

**E1. note の継続**
referral は小さいが、note 内の推薦経路は独自。
- 工数: 週75分

**E2. 英語圏（Reddit / Medium）**
年間を通じて需要がある。ただし**英語では Tryline の差別化（日本語で分かる）が消える**。LLM コストは月$8〜10の追加で軽いが、**運用時間が制約**。
- 効果: 不明
- 持続性: M

**E3. ディレクトリ登録**
被リンクプールが枯渇している中で残る数少ない選択肢。
- 工数: 小
- 持続性: S（一度で済む）

### F. 構造（持続性 S）

**F1. 内部リンクの回遊設計**
ハブ107秒 → カレンダー120秒 → 試合3.6秒。**滞在の長いページ同士を繋ぐ**。試合ページへ送るのは逆効果の可能性。
- 工数: 小〜中
- 持続性: **S**

**F2. 大会間の関連リンク**
11月に NC ハブへ来た人が、欧州クラブや RWC 2027 へ回遊する導線。**今日の欧州クラブ対応で回遊先は用意できた。**
- 工数: 小

## 5. 判断が要る点

1. **B1 は誰がやるか。** Bing Webmaster Tools は Owner のアカウント作業。GSC と違い `tools/` に取得スクリプトが無い。

2. **C2 メール配信の基盤をどうするか。** 送信サービス（Resend 等）の選定とコストが要る。Supabase に配信機能は無い。

3. **A3 の放送情報ソース。** 日本代表戦は JRFU から取れるが、欧州クラブ・SRP は取得元が未確定。規約の確認も要る（2026-08-07 の監査で大手は軒並み不可だった）。

4. **H1 が外れた場合の備え。** 11月にインプレッションが増えなければ、Google 経由の集客は構造的に難しいことになる。その場合は Bing と直接流入に賭けるか、別の入口を探すことになる。
