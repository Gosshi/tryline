# iOS アプリ ロードマップ（2026-07-14 起点）

D014 のタイムライン（9月公開 → 11月オータム → Six Nations 2027 → RWC 2027 刈り取り）に対し、v1 のコードは 2026-07-14 に完成済み（tryline PR #571-574、tryline-mobile PR #1-2）。以降は「公開準備」と「データで判断する追加機能」のフェーズに入る。

原則: **アプリはコンテンツの増幅器であって集客の代替ではない**。X・note・SEO の週次運用（D012/D013）はアプリ作業より常に優先する。

## Phase 2: 公開（9月中〜下旬）

- App Store 審査提出 → 公開（オータム開幕の 1 か月以上前）
- 初速の送客: X 固定ポスト・note 記事・**Web に Smart App Banner**（小 spec）
- D014 の KPI 計測開始: インストール転換率 / 通知許可率 / 7日・30日継続率 / Web+iOS 合計有料購読者数

## Phase 3: オータムインターナショナル（10〜11月）— 最初のスパイク

- 日本代表の欧州遠征で通知・視聴先リンクの価値を実証する
- **アプリ内レビュー依頼**（SKStoreReviewController、v1.1 の筆頭機能）で評価を貯め始める — RWC 検索スパイクへの布石
- 計測を見て v1.1 の中身を確定する

## Phase 4: v1.1（オータム後〜年内）— データで判断

| 候補 | 前提・判断材料 |
|---|---|
| **IAP（StoreKit 2 + ASSN v2）** | スマホソフトウェア競争促進法下の外部決済リンク可否を**先に調査**（可なら IAP 恒久スキップで手数料 15% 回避）。Free→Premium 転換の需要シグナルが出てから |
| Sign in with Apple ＋ Google OAuth | OTP の離脱率次第。両方セットで実装（片方だけは審査不可） |
| 通知のスコア出し分け | `spoiler_guard` カラムは保存済み。通知クリック率を見て |
| アプリ内レビュー依頼 | Phase 3 に前倒し可 |
| ウィジェット（今週の試合） | ホーム画面接触の増加。Live Activities より先 |
