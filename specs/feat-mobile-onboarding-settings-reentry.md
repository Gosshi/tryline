# feat-mobile-onboarding-settings-reentry: 設定タブからのオンボーディング再入場導線

対象リポジトリ: **tryline-mobile** のみ。既存の `app/onboarding.tsx`(Stage A の直接選択画面)への導線を設定タブに追加するだけで、オンボーディング画面自体のロジックは変更しない。

## 背景

Owner による Simulator 実機確認(2026-07-24)で、初回起動時に「あとで選ぶ」を選んだユーザーが、後からオンボーディング(チーム選択)をやり直す手段が無いことが判明した。現状、`app/(tabs)/settings.tsx` の「お気に入りチーム」カードは `FavoritesEditor` を表示するが、未ログイン時は「お気に入りチームの編集にはログインが必要です。」というメッセージのみで、`pendingFavoritesStore` ベースの選択(オンボーディングと同じ経路)にアクセスする手段がない。

Owner の意向により、**未ログインユーザーのみ**を対象に、設定タブから既存のオンボーディング画面(`/onboarding`)を再度開けるようにする。

## スコープ

対象:
1. `src/settings/FavoritesEditor.tsx` の `if (!me)` 分岐(37行目付近)に、既存の「お気に入りチームの編集にはログインが必要です。」メッセージに加えて「チームを選ぶ」ボタンを追加する。押下すると `router.push("/onboarding")` で既存のオンボーディング画面へ遷移する
2. 遷移先の `app/onboarding.tsx` 自体は変更しない。既存の「選んで続ける」「あとで選ぶ」→完了画面→「ホームを見る」(`router.replace("/(tabs)")`)の流れをそのまま再利用する

対象外:
- **ログイン済みユーザーへの対応**(Owner確定: 未ログインユーザーのみが対象)。ログイン済みユーザーが再度チームを選び直す導線は、既存の `FavoritesEditor` の通常編集フロー(ログイン時に表示される標準の編集UI)がその役割を担っており、本specでは変更しない
3. オンボーディングのチーム選択候補ロジック(Owner が設問/選択肢を検討中のため着手しない)。**既知の依存関係として明記**: `app/onboarding.tsx` と `FavoritesEditor.tsx` はともに `competitionsQuery.data?.competitions.slice(0, 8)` の standings からチーム候補を作っており、2026-07-24 時点の本番APIで確認したところ先頭8大会が軒並み standings 空(現在進行中の大会がその中に含まれていない)ため、チーム選択チップが実質0件で表示される状態。この導線を追加しても、根本のチーム候補が直るまでは「チームを選ぶ」を押しても選択肢が出ない体験になる。**この既知の制約はブロッカーではなく、そのまま実装を進めてよい**(候補ロジックの修正は別途 Owner が着手)
4. `app/onboarding.tsx` の完了画面文言修正(`fix-mobile-onboarding-completion-copy` spec、別途進行中)

## データモデル変更 / API サーフェス

なし。

## UI サーフェス

- `FavoritesEditor.tsx` の未ログイン時表示に、既存メッセージ+新規ボタン「チームを選ぶ」を縦に並べる。見た目は既存の `Button` コンポーネント(`variant="secondary"` 等、画面内の他ボタンと統一)を踏襲する

## 受け入れ条件

1. 未ログイン状態で設定タブの「お気に入りチーム」カードに「チームを選ぶ」ボタンが表示されることを確認するテスト
2. 「チームを選ぶ」ボタン押下で `/onboarding` へ遷移する(`router.push` が呼ばれる)ことを確認するテスト
3. ログイン済み状態では「チームを選ぶ」ボタンが表示されない(既存の編集UIのみが表示される)ことを確認する回帰テスト
4. `app/onboarding.tsx` 自体への変更が無いこと(diffで確認)
5. TypeScript strict・lint・test green
6. **Owner 目視**: 実機または iOS Simulator で、未ログイン状態から設定タブ→「チームを選ぶ」→オンボーディング画面が開くことを確認する。**チーム選択肢が実際に0件で表示される可能性が高いことは既知(上記スコープ外3番を参照)であり、この時点での確認対象外**
