# Discord 通知: ワンクリックコピー UX を改善する

## 背景

`app/api/cron/notify-discord/route.ts` が送る Discord 通知には
「X 投稿ドラフト（コピペ用）」と「X リプライ用（URL）」の 2 フィールドが
コードブロック（\`\`\`）で表示されている。

現状の UX 問題:
1. コードブロックは Discord モバイルアプリで **長押し → コピー** という操作が必要
2. 投稿ドラフトとリプライ URL を**別々のコードブロック**でコピーするため、
   間違ったブロックをコピーするミスが起きやすい
3. フィールド名が「X 投稿ドラフト（コピペ用）」と長く、手順が不明瞭

改善目標: コピー操作を削減し、投稿までの手数を減らす。

## スコープ

対象:
- `app/api/cron/notify-discord/route.ts` — embed フィールドのレイアウトと文言を改善

対象外:
- Discord webhook の追加・変更
- X への自動投稿（`fix-sns-auto-post.md` が対象）
- 通知頻度・対象コンテンツの変更

## UI サーフェス

### Discord embed フィールドの改善案

```typescript
fields: [
  {
    name: "① X に貼る（URLなし）",
    value: `\`\`\`\n${draftTweet}\n\`\`\``,
    inline: false,
  },
  {
    name: "② リプライに貼る",
    value: `\`\`\`\n${replyText}\n\`\`\``,
    inline: false,
  },
  {
    name: "③ 記事を開く",
    value: matchUrl,  // コードブロック外でクリッカブルリンクのまま
    inline: false,
  },
],
```

**変更点:**
- フィールド名に番号（①②③）を付けて手順を明確化
- 記事 URL を `\`\`\`` で囲まず **クリッカブルリンク** のまま残す
  （コードブロックに入れると Discord でクリックできなくなる）
- フィールド名を「X 投稿ドラフト（コピペ用）」→「① X に貼る（URLなし）」に簡略化
