# fix-competition-season-not-held-vs-not-ingested

> GPT-6 監査 A-4 6（P1）。「開催しない大会」と「まだ取り込んでいない大会」を区別せず、どちらにも「まもなく公開予定」と書いている。

## 背景

大会シーズンページは、試合が 0 件のとき無条件にこう表示する（`app/c/[competition]/[season]/page.tsx:941-948`）。

```
試合データを準備中です
このシーズンの試合情報はまもなく公開予定です。
```

**「まもなく公開予定」は、その年度に大会が開催されることを断定している。** 実データを確認した（2026-09-09）。試合 0 件の大会は本番に **2 件**ある。

| slug | season | matches | total_rounds |
|---|---|---|---|
| `autumn-nations-2026` | 2026 | 0 | null |
| `rugby-championship-2026` | 2026 | 0 | null |

**`rugby-championship-2026` は開催されない。** Rugby Championship は Nations Championship に統合されており、2026 年に独立大会として存在しない（`project_nations_championship_absorbs_rugby_championship`、2026-07-22 確定）。それでもページは「まもなく公開予定」と表示している。**事実に反する。**

`autumn-nations-2026` が開催されるかは**未確認**。Nations Championship 2026 が秋の窓を吸収している可能性があるが、本 spec では断定しない。

監査の指摘（原文）: 「開催しない大会と未取得を識別していない。」「P1: 実開催しない年度は事実説明＋対応大会へ。開催予定・未取得なら確認状況＋公式参照。検索価値のない空年度はnoindexを検討するが、一括404/301はしない。」

## スコープ

対象:

- 試合 0 件時の表示を、その列に従って分岐させる
- 開催しない年度に対する noindex の検討
- テスト

対象外:
- **どの大会が開催しないかの判定そのもの**。これは Owner のデータ入力であり、コードで推測しない。**LLM に「この大会は2026年に開催されますか」と尋ねない**（それ自体が捏造の経路になる）
- **一括 404 / 301**。監査も明記している。既存 URL は 200 のまま残す
- `autumn-nations-2026` の開催有無の確定（Owner 調査）
- 試合が 1 件以上ある大会の表示

`competitions` に列を 1 つ追加する。**既存 12 列に「開催の有無」を表せるものが無い**ことを確認済み（`id` / `slug` / `name` / `country` / `season` / `start_date` / `end_date` / `created_at` / `updated_at` / `family` / `champion` / `name_ja` / `total_rounds`）。

## 変更詳細

### noindex

**開催しない年度は noindex を検討する**（監査の推奨）。ただし **未確認の年度を noindex にしないこと**。判断材料が無い状態で検索から消すと、後で開催が判明したときに回復が遅れる。

`project_index_bloat` のとおり noindex 化は 2026-08-02 に実測で効果を確認しているが、**あれは「無意味な選手ページ」が対象**で、大会ハブは Bing 流入の 86% が着地する面である（`project_bing_dominates_google`）。**大会ハブを安易に noindex にしないこと。**

## 受け入れ条件

1. マイグレーションが `supabase/` 配下にあり、**3 値（開催する / 開催しない / 未確認）を表現できる**
2. **既定値が「未確認」**で、既存 38 行が「開催する」と断定されない
3. 「開催しない」の大会シーズンで、**「まもなく公開予定」が表示されない**ことを検証するテストがある
4. 「開催しない」の大会シーズンで、対応する大会への導線が出ることを検証するテストがある
5. 「未確認」の大会シーズンで、**開催を断定する文言が出ない**ことを検証するテストがある
6. 「開催する（未取得）」で、確認状況と公式参照が出ることを検証するテストがある
7. 試合が 1 件以上ある大会シーズンの表示に**差分が無い**ことを検証するテストがある
8. **既存 URL が 200 を返し続ける**。404 / 301 に変えていない
9. **「未確認」が noindex にならない**ことを検証するテストがある
10. LLM 呼び出しが差分に含まれない（ソース中に `getOpenAIClient` / `MODELS` が現れない）
11. **開催の有無をコードにハードコードしていない。** 判定は DB の列だけを見る
12. `pnpm lint` / `pnpm typecheck` / `pnpm test` が green

**テストの置き場所**: `tests/app/` 配下（`exclude` 非該当。確認済み）。既存の `tests/app/season-page-ia.test.ts` を壊していないこと。
