# ホーム「注目大会」セクションの余白解消と「次戦」表示バグ修正

## 背景

2026-07-11、Codexによる調査（`docs/codex-prompts/research-home-featured-competition-whitespace.md`）で2点判明した。

### 1. デスクトップでの余白問題

`app/page.tsx`の「注目大会」セクションは、左カラム（見出し・説明文・カレンダーCTA）と右カラム（FEATURED COMPETITIONカード）の2カラムグリッドだが、実機確認（1440px）で左カラムの約70%（約268px）が未使用の空白になっている。モバイル（375px、縦積み）ではこの問題は発生しない。

### 2. 「次戦」表示が実データと不一致

FEATURED COMPETITIONカードの「次戦」は「未定」と表示されるが、本番DB確認では実際にPNC 2026の次の試合（2026-09-12、フィジー vs カナダ 他）が存在する。原因は`app/page.tsx`の「次戦」計算が、全大会横断の今週最大6試合のプールからPNCの試合を抽出しているだけで、今週の6試合に該当PNC戦が無い場合は本来の次戦を探しに行かないため（`app/page.tsx:177`付近）。

Codexの調査では4案を比較し、**「コンテンツを追加せず、横長のコンパクトなティザーに再構成する」案（d）**を推奨している。理由: PNCの順位表・レビューは現状表示できるデータが無く（0本）、残り試合の表示はMatchday Boardの役割と分散するため。

## スコープ

対象:
- 「注目大会」セクションを、現在の2カラムグリッド（左テキスト+右カード）から、横長のコンパクトなバナー形式に再構成する（高さ目標: 約220〜260px）。大会画像・見出し・説明・統計（次戦/レビュー本数/今週の試合数）・大会ページCTAを1つの横長カードにまとめる
- 「カレンダーで全日程を見る」CTAは、セクション本体ではなく小さな副リンクとして扱う（配置はCodexの判断でよい）
- 「次戦」の計算ロジックを修正し、今週の6試合プールに限定せず、該当大会（Featured Competition）の本当の次の試合を取得するようにする

対象外:
- `HomeMatchdayBoard`（ヒーロー内の試合ボード）自体の変更
- PNC順位表・レビュー一覧をこのセクションに追加すること（Codexの調査で見送りと結論済み）
- 今週活発な大会を自動選択する仕組み（現状の`FEATURED_COMPETITION`定数によるハードコード運用を維持する）

## UI サーフェス

`app/page.tsx`の「注目大会」セクション（350行目付近）を横長バナー形式に再構成する。具体的なレイアウト（大会画像の配置比率等）はCodexの実装判断に委ねる。

## 受け入れ条件

1. デスクトップ（1440px相当）で「注目大会」セクションの高さが現状（約410px）より縮小されており、大きな未使用の空白が無い
2. モバイル（375px相当）の表示に回帰がない（現状問題ないため、大きく変える必要はない）
3. FEATURED COMPETITIONカードの「次戦」が、今週の6試合プールに限定されず、該当大会の実際の次の試合を正しく表示する（PNC 2026の場合、2026-09-12の試合が表示される）
4. 該当大会に今後の試合が1件も無い場合、「次戦」欄が不自然な表示（「未定」等）にならず、適切なフォールバック表示になる
5. `pnpm tsc --noEmit` / `pnpm lint` / `pnpm test` / `pnpm build` が通る
6. 本番デプロイ前に実際のブラウザで1440px・375px双方のスクリーンショットを確認する。本番デプロイ自体はOwner承認後に別途行う
