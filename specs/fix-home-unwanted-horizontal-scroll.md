# ホームページの意図しない横スクロールを修正

## 背景

ホームページ（`/`）全体が、コンテンツ幅を超えて横スクロールできてしまう（Owner指摘）。Chrome DevToolsで直接検証したところ:

- `document.documentElement.scrollWidth`（1647px）が `clientWidth`（1455px）より約192px大きく、ページ全体が横スクロール可能な状態になっている
- 二分探索で原因箇所を特定した結果、「大会アーカイブ」セクション（`app/page.tsx` 647行目付近）内の横スクロールカード一覧 `<ul className="flex gap-3 overflow-x-auto ...">` が原因と判明した
- この `<ul>` 自体の描画位置・幅は正しくビューポート内に収まっており（実測: left=184, right=1272, 幅1088px、ビューポート1455px以内）、`overflow-x-auto` によって内部スクロールも意図通り機能している。にもかかわらず、この要素が存在する状態だと `document.documentElement.scrollWidth` がその要素の内部スクロール分だけ大きくなり、ページ全体が横スクロール可能になってしまう
- 実機検証: `document.documentElement.style.overflowX = 'hidden'`（および `body` にも同様に設定）を適用すると、この「大会アーカイブ」の横スクロールカード一覧自体は内部スクロールが正常に機能したまま、ページ全体の横スクロールだけが正しく無効化されることを確認した

## スコープ

対象:
- `app/globals.css` の `html`/`body` セレクタに `overflow-x: hidden` を追加し、ページ全体の意図しない横スクロールを防ぐ（既存の意図的な内部横スクロール要素〈大会アーカイブのカード一覧等〉の動作には影響しない）

対象外:
- 「大会アーカイブ」の横スクロールカード一覧自体の実装変更（`overflow-x-auto` の挙動自体は正しく機能しているため変更不要）
- 他ページ（試合ページ・大会ページ等）での同種の横スクロール問題の調査（本specはホームページのみを対象とする。他ページで同様の事象が見つかった場合は別途報告する）

## データモデル変更

なし。

## API サーフェス

なし。

## UI サーフェス

`html`/`body` に `overflow-x: hidden` を追加することで、ページ全体の横スクロールバー・横スワイプによるページ送りが無効化される。既存の「大会アーカイブ」カード一覧など、意図的に横スクロール可能なコンポーネントの動作は変わらない。

## LLM 連携

なし。

## 受け入れ条件

1. `app/globals.css` の `html`・`body` に `overflow-x: hidden` が追加されている
2. ホームページで `document.documentElement.scrollWidth > document.documentElement.clientWidth` であっても、ページ全体を横スワイプ・横スクロールで動かせない
3. 「大会アーカイブ」セクションのカード一覧は、引き続き横スクロールで全項目を閲覧できる（内部スクロール機能が壊れていない）
4. 他の主要ページ（試合ページ・大会ページ・カレンダー）で新たな表示崩れ（意図した横スクロールコンポーネントが機能しなくなる等）が発生していないことを目視確認する
5. `pnpm tsc --noEmit` / `pnpm lint` / `pnpm test` / `pnpm build` が通る
