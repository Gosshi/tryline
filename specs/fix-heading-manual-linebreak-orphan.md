# fix-heading-manual-linebreak-orphan

## 背景

Ownerが本番サイト（`trylinerugby.com`、1920px幅）で実機確認し、Claude Codeがスクリーンショットで再現を確認した（2026-07-20）: トップページの「注目大会」カード（`components/featured-competition-card.tsx:47`）で、見出し `{FEATURED_COMPETITION.headline}`（`lib/featured-competition.ts` の `"ネーションズチャンピオンシップ 2026 を追う"`）が「ネーションズチャンピオンシップ 2026 を追」で改行され、「う」1文字だけが2行目に孤立して表示される。

原因は、`<h3>` タグ（47行目）が折り返し制御なしのプレーンテキストとして長い日本語文字列をレンダリングしており、コンテナ幅（画像と2カラムで分割されたカード内の残り幅）に対してテキストが長すぎるため、ブラウザのデフォルトの折り返しが任意の文字境界で発生していること。

同種の問題は、トップページのメインヒーロー見出し（`app/page.tsx:266-274`、「今週の海外ラグビーを、日本時間で追う。」）にも読点・`<wbr>`・手動`<br>`が多用されており、改行の見た目が不自然になりやすい構造になっている。

## スコープ

対象:
- `components/featured-competition-card.tsx:47` の見出し `<h3>` に、孤立文字（widow）を防ぐCSS（`text-wrap: balance` または `text-wrap: pretty`）を適用する。それでも特定の幅で「う」のような1〜2文字が孤立する場合は、見出し文言自体を短くする対応も検討する（例:「ネーションズチャンピオンシップ 2026」とし、「を追う」はCTAボタン側の文言に統合する）。文言変更を伴う場合はOwnerに確認してから実施する
- `app/page.tsx:266-274` のメインヒーロー見出しについて、手動の `<br>` ・多数の `<wbr>` を整理し、`text-wrap: balance` を基本に、意味の区切りとして本当に必要な箇所だけ改行制御を残す

対象外:
- 見出しの文言自体の大幅な変更（本specは折り返し制御が主目的。文言変更が必要な場合は最小限に留め、変更する場合はOwner確認を得る）
- `app/pricing/page.tsx` 等、他ページの見出し折り返し（本specは上記2箇所に限定。他に同様の孤立文字が見つかった場合は追加で報告してよいが、修正は本specのスコープ外としてよい）

## UI サーフェス

- 使用トークン: なし（CSSプロパティの追加のみ）
- **完了の定義にビジュアル確認を含める**: 実装後、Owner が実際に本番相当の幅（1920px・1440px・375px）で見出しの折り返しを確認し、孤立文字が解消されていることを承認すること

## 受け入れ条件

1. `components/featured-competition-card.tsx` の見出しに `text-wrap: balance`（または同等の孤立文字防止CSS）が適用されていること
2. 1920px幅で表示した際、「ネーションズチャンピオンシップ 2026 を追う」が1文字だけ孤立する形で折り返されないことを目視確認する
3. `app/page.tsx` のメインヒーロー見出しの手動改行制御が整理され、不要な `<wbr>` ・ `<br>` が削減されていること
4. モバイル幅（375px前後）で両見出しが適切に折り返されること
5. `pnpm test` / `pnpm tsc --noEmit` / `pnpm lint` / `pnpm build` が通る
6. Owner によるスクリーンショット目視確認（1920px・1440px・375px）で承認を得ること

## 未解決の質問

- `text-wrap: balance` はブラウザによっては未対応の場合がある。対応ブラウザ範囲を確認し、フォールバック（未対応ブラウザでは従来通りの折り返しになる）で許容できるか実装時に確認すること
