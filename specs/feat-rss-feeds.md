# 最新レビュー・週次ガイドのRSSフィードを追加する

## 背景

2026-07-10、Codex（新モデル）による集客分析で提案された施策。再訪・購読の導線として、Push通知・応援チームフォロー（`feat-favorite-team-follow-engagement.md`）とは別に、RSSリーダーを使う層への露出も低コストで確保できる。

Trylineには現状RSSフィードが存在しない。`app/sitemap.ts` に既にNext.js App RouterでのXML生成パターンがあるため、同じ手法でRSS（Atom/RSS 2.0形式）を実装できる。

## スコープ

対象:
- `app/rss.xml/route.ts`（または `app/feed.xml/route.ts`）に、直近公開されたレビュー（recap）の最新20〜30件を含むRSSフィードを追加する
- 各アイテムには試合ページへのリンク・タイトル（対戦カード）・概要（レビューの冒頭抜粋）・公開日時を含める
- サイトのフッターまたはヘッダーに、RSSフィードへのリンク（`<link rel="alternate" type="application/rss+xml">`）を追加する

対象外:
- 大会別・チーム別等の細分化されたRSSフィード（今回は全体で1本のフィードのみ）
- 「今週の試合・週次ガイド」用の別フィードは、実装コストとのバランスを見てCodexの判断で対象に含めるかどうか決めてよい（対応する場合は `app/calendar-rss.xml/route.ts` 等、対応しない場合は完了報告にその旨を明記する）

## API サーフェス

- `GET /rss.xml`: RSS 2.0またはAtom形式のXMLを返す

## 受け入れ条件

1. `/rss.xml` にアクセスすると、直近公開されたレビュー20〜30件を含む有効なRSS/Atomフィードが返る（RSSバリデーターやブラウザのRSSリーダーで読み込めることを確認する）
2. 各アイテムに試合ページへのリンク・タイトル・概要・公開日時が含まれている
3. サイト上（フッター等）にRSSフィードへのリンクがある
4. `pnpm tsc --noEmit` / `pnpm lint` / `pnpm test` / `pnpm build` が通る
5. 本番デプロイはOwner承認後に別途行う

## 未解決の質問

- 「今週の試合・週次ガイド」用の別フィードを追加するかはCodexの判断に委ねる。実装コストが高い場合は見送り、レビュー用フィードのみで完了としてよい
