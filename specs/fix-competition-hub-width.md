# fix-competition-hub-width

## 背景

大会ハブページ（`app/c/[competition]/page.tsx`）の主要コンテナは `max-w-4xl`（896px、`121行目`・`134行目`）で、1440px画面では左右合計約544px（各272px）の余白になる。GPT-5.6の調査で、この幅はカード一覧（順位表・試合一覧等）を表示するには狭すぎると指摘された。

## スコープ

対象:
- `app/c/[competition]/page.tsx` の主要コンテンツコンテナ（134行目 `max-w-4xl`）を `max-w-6xl`（1152px）に拡張する
- 拡張後、デスクトップ幅で「最新シーズン情報／大会ガイド」と「レビュー一覧／大会アーカイブ」等を2カラム構成にできないか検討する（GPT-5.6提案）。ただし2カラム化は見た目の判断を伴うため、まず幅拡張のみを実装し、2カラム化は目視確認の上でOwnerが追加指示する形でもよい
- ヒーロー部分のテキストオーバーレイ（121行目 `max-w-4xl`）は、大会名・説明文の可読性を保つため、そのまま `max-w-4xl` を維持してよい（本文コンテナとヒーローテキストは別の制約でよい）
- 長文になりうる大会ガイド本文がある場合は、そのブロックだけ内側で `max-w-3xl` 程度に制限し、可読性を維持する

対象外:
- `fix-home-width-expansion.md`（トップページの幅変更、別spec）
- 大会ハブページのカード自体のデザイン変更（幅拡張後の余白活用のみ）

## UI サーフェス

- 使用トークン: `design.md` のspacing定義に従う
- **完了の定義にビジュアル確認を含める**: 実装後、Owner がデスクトップ1440px幅でスクリーンショットを確認し、余白過多が解消されていることを承認すること

## 受け入れ条件

1. 大会ハブページの主要コンテンツコンテナが `max-w-6xl` になっていることをコードレビューで確認する
2. ヒーローのテキストオーバーレイの可読性が変更前と同等であること
3. モバイル幅（375px前後）の表示がこれまで通り正しく機能すること
4. `pnpm test` / `pnpm tsc --noEmit` / `pnpm lint` / `pnpm build` が通る
5. Owner によるスクリーンショット目視確認（デスクトップ1440px）で承認を得ること

## 未解決の質問

- 2カラム化（「最新／ガイド」と「レビュー／アーカイブ」）を本specに含めるか、幅拡張のみで一旦区切るかはOwnerが判断する
