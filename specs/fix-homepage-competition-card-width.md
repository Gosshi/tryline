# トップページの大会アーカイブカードで日本語名が切り詰められる

## 背景

PR #744（`fix-competition-hub-family-title-ctr`、2026-08-31 デプロイ）で大会ファミリー名を日本語化した結果、**トップページ「大会アーカイブ」行のカードで名前が切り詰められるようになった。**

日本語名は英語名より長い。

| family | 変更前 | 変更後 | 文字数 |
|---|---|---|---:|
| `urc` | URC | ユナイテッド・ラグビー・チャンピオンシップ | 3 → **21** |
| `pnc` | Pacific Nations Cup | パシフィック・ネーションズカップ | → 16 |
| `nations-championship` | Nations Championship | ネーションズチャンピオンシップ | → 15 |
| `lipovitan-challenge-cup` | （変更なし） | リポビタンDチャレンジカップ | 14 |

### 本番の実測（2026-08-31、デスクトップ 1324px 幅）

カード名の `<span>` は `line-clamp-2` で2行に制限されており、`scrollHeight` と `clientHeight` の差が実際の切り詰め量になる。

| 表示 | 幅 | clientHeight | scrollHeight | 溢れ |
|---|---:|---:|---:|---:|
| ユナイテッド・ラグビー・チャンピオンシップ | 96px | 35 | 71 | **36px（約2行分）** |
| ネーションズチャンピオンシップ | 96px | 35 | 54 | 19px |
| スーパーラグビー・パシフィック | 96px | 35 | 54 | 19px |
| ザ・ラグビーチャンピオンシップ | 96px | 35 | 54 | 19px |
| プレミアシップ | 96px | 35 | 36 | 1px |

**横方向のはみ出し（`scrollWidth - clientWidth`）はすべて 0。** レイアウト崩れではなく、`line-clamp-2` が設計どおり省略記号を出している状態である。

見え方の実例:

```
ユナイテッ      リポビタンDチ    ネーションズ     パシフィッ
ド・ラグビ…     ャレンジカッ…    チャンピオン…    ク・ネーショ…

プレミアシッ
プ                          ← 2行目に1文字だけ落ちる
```

**破綻ではないが、`ユナイテッ ド・ラグビ…` は識別しにくい。** 各カードにはロゴバッジがあるため識別は完全には失われていないが、英語名のときより見劣りする。

### なぜ今直すのか

PR #744 自体は差し戻さない。**検索結果に出る要素（`<title>`・パンくず JSON-LD・FAQ JSON-LD）が3つとも日本語化された価値の方が、アーカイブ行の見た目より大きい。** 本 spec はその副作用だけを後追いで解消する。

## 実装方針

`app/page.tsx:804` の幅指定を変える。

```tsx
<li
  className={isFeatured ? "w-44 shrink-0" : "w-32 shrink-0"}
  key={`${competition.family}-${competition.season}`}
>
```

- 通常カード: `w-32`（128px）→ **`w-40`（160px）**
- 先頭の注目カード: `w-44`（176px）→ **`w-52`（208px）**

**注目カードも一緒に広げること。** 通常カードだけ広げると、先頭が相対的に小さく見えて注目カードの意味が薄れる。比率（1.375倍）を維持する。

### この幅で足りるかの確認方法

内側の名前 `<span>` の実効幅は、カードの `px-4`（左右 16px ずつ）を引いた値になる。

- 現状: 128 − 32 = **96px** → 実測で `line-clamp-2` に収まらないものが4件
- 変更後: 160 − 32 = **128px**

`text-sm`（14px）の日本語は1文字あたり約14pxなので、128px なら**1行あたり約9文字・2行で約18文字**。21文字の `ユナイテッド・ラグビー・チャンピオンシップ` は**まだ収まらない**。

**したがって「全件が完全表示される」ことを受け入れ条件にしてはいけない。** 目標は次の2点に限る。

1. 最長の `urc` 以外（16文字以下）が2行に収まること
2. `プレミアシップ`（7文字）が2行目に1文字だけ落ちる不自然な折り返しが解消されること

**`urc` は引き続き省略記号で切り詰められる。** これは許容する。全件を収めるにはカードが倍近く必要になり、横スクロールが実用的でなくなるため。

### 実測での検証

実装後、ローカルまたはプレビューで次を確認すること。**目視だけで判断しない。**

**行高が 17.5px（`text-sm` × `leading-tight`）と小数のため、`scrollHeight` は常に切り上げられる。差が 0 になることは無い。** 受け入れ条件2の測定方法（Range による行数カウント）に従うこと。

## UI サーフェス

トップページ「大会アーカイブ」行のカードが横に広がる。カード枚数は変わらないため、**横スクロールの総幅が約25%増える**。

**モバイル（375px 幅）で、1画面に表示されるカード数が減りすぎないかを確認すること。** 現状 `w-32` で約2.5枚見えている。`w-40` では約2枚になる。**2枚を下回る場合は報告すること**（採用可否を Owner が判断する）。

## 受け入れ条件

1. 通常カードが `w-40`、注目カードが `w-52` になっている。
2. デスクトップ幅（1280px 以上）で、`nations-championship` / `super-rugby-pacific` / `rugby-championship` / `pacific-nations-cup` / `lipovitan-challenge-cup` の名前 `<span>` が **2行以内に収まっている**こと。

   **測定方法（`scrollHeight - clientHeight === 0` は使わない）**: `text-sm`(14px) × `leading-tight`(1.25) = **17.5px** と行高が小数になるため、`scrollHeight` は常に切り上げられる。**収まっていても差は 0 にならない。** 2026-08-31 に実測で確認済み（対象5件すべて差 1px、Range 計測では2行以内）。

   判定は次のいずれかで行う。

   ```js
   // 推奨: Range で実際の行数を数える
   const range = document.createRange();
   range.selectNodeContents(el);
   const lines = range.getClientRects().length;   // <= 2 であること

   // 代替: 行高から行数を算出する
   const lh = parseFloat(getComputedStyle(el).lineHeight);   // 17.5
   const lines = Math.round(el.scrollHeight / lh);           // <= 2 であること
   ```

   許容差の形で書くなら **`scrollHeight - clientHeight <= 1`**。**`=== 0` を条件にしてはいけない。**
3. `premiership` の名前が**2行目に1文字だけ落ちる状態**になっていない（変更後は1行に収まる想定）。
4. すべてのカードで `scrollWidth - clientWidth <= 1`（横方向のはみ出しなし）。**縦と同じ理由で、ここも `=== 0` を条件にしない。**
5. `urc` は切り詰められたままでよい（実測で4行・溢れ19px）。**これを理由に他の変更を加えない。**
6. モバイル幅（375px）で横スクロールが機能し、カードが重なったり画面外に固定されたりしない。
7. カードの高さ・角丸・グラデーション・ロゴバッジ・シーズン表記が変わっていない。
8. `formatFamilyName` および `lib/format/` 配下を変更していない。
9. `pnpm lint` / `pnpm tsc --noEmit` / `pnpm test` がすべて通る。
10. 既存のトップページのテスト（`tests/app/home-page.test.tsx`）が通る。幅のクラス名をアサートしているテストがあれば更新する。

## やってはいけないこと

- **`formatFamilyName` や表示名マップを変更しないこと。** PR #744 を巻き戻す方向の修正は不可。
- **短縮名マップを新設しないこと。** 同じ概念の名前マップが増えると、PR #744 で踏んだバグを再生産する。
- `line-clamp-2` を `line-clamp-3` 等に変えないこと。カード高さ（`h-24`）を超える。
- フォントサイズ（`text-sm`）を小さくしないこと。
- **「urc が収まらない」を理由にカードを大幅に広げないこと。** 横スクロールが実用的でなくなる。
- 「最近レビューのある大会」セクションに手を入れないこと。切り詰めは起きていない。
