# feat-mobile-editorial-polish: アプリのエディトリアル化（束2）

対象リポジトリ: **tryline-mobile**。前提: `fix-mobile-audit-bugs`（束1）のマージ後に着手（同じファイル群を触るため直列）。

## 背景

2026-07-15 の並行デザイン監査（Claude Fable 5 / GPT-5.6、指摘一覧は両モデルとも突合済み）で、**独立に同じブランド診断**が出た:「トークン（紙・インク・赤）は規律よく使われているが、22pt 角丸＋影の白カードの均質な羅列が汎用 UI キットに見え、Web の新聞的エディトリアルと同一ブランドに見えない」。続く方向性協議でも「毎週開きたくなるラグビー新聞」で収束した。Owner 承認（2026-07-15）のもと、アプリの見た目を Web の方向へ寄せる。

方針: **角丸と影を減らし、罫線と密度で紙面をつくる。試合だけをインクの濃い面にする。色・フォント・情報は変えない**（配分の目安: 紙 80% / インク 15% / 赤 5%）。

## スコープ

対象（原則見た目のみ。挙動追加は 6b・7・9b の 3 点だけで、いずれも明示）:

1. **トークン**: `radius.lg` 22→8（`md`/`sm` も比例縮小）。`Card` の影を廃止し hairline 罫線＋白地に。角丸・影のバリエーションを増やさない。**フォントサイズの直値をトークンへ回収**（`ScoreText` の 24、`Button`/`BroadcastLinks` の 15 → `typography.score` / `typography.button` を追加して参照）。トークン外の値（ペイウォールの `borderRadius: 18` 等）を一掃
2. **試合詳細のマストヘッド（アプリの「顔」）**: 大会名・日時・対戦・会場を画面固有のヘッダーとして統合し、**対戦部分をインク単色 `#1f2530` の帯＋白抜き文字**にする（Web のダークヒーローと同じ「試合＝濃い面」の記号。**グラデーションは使わない**）。帯の上端に赤 2pt 罫線。大会名の赤 eyebrow は帯の上の紙面に残す。スコア未確定時は帯内に `●–●` / KO 時刻。情報の順序: 大会・日時 → 対戦（帯）→ 会場 → 視聴方法 → プレビュー/レビュー → イベント・ラインナップ
3. **赤の用途を 3 つに限定**: (a) 大会名等の eyebrow **ラベル語**（「THIS WEEK」等。日付などのデータ文字列は muted に分離）、(b) ネタバレ関連、(c) 主要 CTA。順位表の順位番号は ink（順位帯の意味づけ配色は大会別定義が必要なため見送り）、設定の案内文は muted に
4. **数字の tabular 化**: スコア・順位・KO 時刻の数字に `fontVariant: ["tabular-nums"]`＋ウェイト 900。フォントの追加はしない
5. **罫線のシステム化と視聴方法の仕上げ**: セクション見出しの下罫・順位表の行罫として hairline を統一。カード内カード（`BroadcastLinks` の行・ペイウォール枠）は内側の枠・角丸を外し行区切りに。視聴行は `minHeight: 48`・**右端に外部リンクの手掛かり `↗`（muted）を追加**（Web と同じアフォーダンス）。`broadcasts` 空＋`broadcast_jp_url` 非 null の fallback 表示も同じ行スタイルに統一（ベタ赤ボタンをやめる）。ペイウォールは赤 3pt の左罫で新聞の「囲み記事」風に
6. **カレンダーの密度と階層**: 一画面 5〜7 試合を目安に縦密度を上げる（padding/gap は監査提案値を起点に調整可）。チーム名を主役（ink・800）、確定スコアは大きく、**未来の試合は時刻を主役にし「KO 前」プレースホルダを主役級（24pt/900）から降格**。**ネタバレマスク時もカードの高さを変えない**。日付見出しの罫線付きスタイルは維持。大会一覧はシーズン（年度）を左固定幅の主走査列とし 1 大会 1 行に圧縮。**（6b・挙動例外）0 試合のシーズンはリスト末尾へ送る**（非表示にはしない）
7. **状態デザインの統一（7 は action 追加の挙動例外を含む）**: `States.tsx`（空・エラー・ローディング）に幅 32pt×高さ 2pt の赤い上罫線、本文 `maxWidth: 320`、上余白 32pt。`EmptyState` に説明文と action を追加でき、カレンダーの空週では「翌週を見る」（secondary）を渡す
8. **詳細/モーダル画面の見出し重複解消**: ナビタイトルがある画面（試合詳細・サインイン）では本文側の大見出し（MATCH / SIGN IN 等）を削除し、ナビ下 16pt から内容を開始。タブ直下の画面（今週・大会・設定）の大見出し＋英語 eyebrow は Web と共通の型なので維持
9. **細部の統一**: (a) Pill（バッジ）実装が `MatchCard` と `BroadcastLinks` で二系統になっているため `src/components/Pill.tsx`（`tone: "neutral" | "accent"`）に集約。(b) **（9b・挙動例外）** マスク中の「レビュー本文はスコア開示後に表示されます。」を紙色の面＋`●–●`＋「スコアを表示すると読めます」に置き換え、**タップで既存の `revealMatch` に接続**。(c) イベント行は分数のみ muted、選手名・種別は ink。(d) Switch の ON トラックを `colors.accent`＋白 thumb に

対象外（やらないことを明示）:
- Web のえんじ→紺**グラデーションの移植**（単色インクで組む）
- **国旗・チームロゴの導入**（v1 は文字で組み切る）
- フォント追加、ダークモード、レイアウト構造（タブ・画面構成）の変更
- 6b・7・9b 以外の挙動・文言・データ表示の変更
- Web 側の変更

## 受け入れ条件

1. `src/theme/tokens.ts` の radius 変更が全カードに波及し、フォントサイズ・radius の直値（24 / 15 / 18 等）がコンポーネントに残らない
2. `Card` に影スタイルが存在せず、hairline 罫線が付く（コンポーネントテスト）
3. 試合詳細のマストヘッド: 対戦部分の背景が `colors.ink`・文字が白・上端に赤 2pt 罫線・グラデ実装が依存に追加されていない（テスト＋`package.json` diff）
4. スコア・順位の数字スタイルに `tabular-nums` が適用されている（テスト）
5. 視聴方法: 各行に `↗` が表示され、fallback（単一 URL）時も同じ行スタイルで描画される（テスト）。ペイウォールに赤 3pt の左罫があり、内側の `borderRadius` 付き枠が無い
6. スコア未確定の `ScoreText` が 24pt/900 でなく本文級サイズ・muted で描画される（テスト）
7. 大会一覧で 0 試合のシーズンが末尾に来る（テスト）。カレンダー空週の `EmptyState` に「翌週を見る」action が表示され、タップで翌週へ遷移する（テスト）
8. マスク中のレビュー案内をタップすると該当試合の開示状態になる（テスト）
9. 試合詳細・サインインで eyebrow（MATCH / SIGN IN）が表示されない。今週・大会・設定では従来どおり表示される
10. ネタバレマスクの ON/OFF で `MatchCard` の高さが変わらない（テスト）。密度圧縮でタップターゲットが 44pt を割らない
11. 挙動のリグレッションなし: 既存テストが全て pass（6b・7・9b に伴う正当な更新を除き、アサーション対象の文言を変えない）
12. TypeScript strict・CI green
13. **Owner 目視（最重要）**: 修正後に監査時と同じ 12 画面相当を再スクリーンショットし、Web と並べて「同一ブランドの別刷り（モバイル版）に見えるか」を Owner が判定する。PR に before/after を並べて添付する
