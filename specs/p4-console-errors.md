# コンソールエラー解消

## 背景

Playwright レビューで URC 等のページでコンソールエラーが1件以上検出された。
エラーの内容次第では SEO・ユーザー体験・監視アラートに影響する可能性があるため調査・修正する。

## スコープ

対象:
- ブラウザコンソールに出力されているエラー・警告の特定と修正

対象外:
- サーバーサイドのログ（別途 Vercel ダッシュボードで確認）
- パフォーマンス警告（別タスクで対応）

## 調査手順

Codex は以下の手順で調査すること:

1. `pnpm dev` でローカルサーバーを起動
2. Playwright または手動で以下のページを開き、コンソールエラーを記録する:
   - `/c/urc/2025-26`
   - `/c/premiership/2025-26`
   - `/c/super-rugby-pacific/2026`
   - 任意の試合詳細ページ
3. エラーの種類を分類:
   - **React Hydration エラー**: サーバー/クライアントの HTML 不一致 → SSR コードを確認
   - **Missing key prop**: リスト要素の key 漏れ → 対象コンポーネントを修正
   - **Failed to load resource**: 画像・スクリプト・フォント 404 → パスを修正
   - **TypeError / ReferenceError**: 未定義参照 → 発生箇所を特定して修正
   - **Supabase / Auth エラー**: セッション切れ・RLS 違反など → クエリを確認

## 対応方針

- エラーごとに最小限の修正を行う
- 修正後に該当ページを再確認し、エラーが消えたことを確認する
- 原因が複数ファイルにまたがる場合は最も根本的な箇所のみ修正し、
  他の場所のリファクタリングは行わない

## 受け入れ条件

- [ ] `/c/urc/2025-26` ページでコンソールエラーが0件になる
- [ ] その他の調査対象ページでも新規エラーが発生していない
- [ ] 修正内容が変更ファイルとエラー内容とともにコミットメッセージに記録されている
- [ ] `pnpm tsc --noEmit` と `pnpm build` が通る
