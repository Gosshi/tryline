# 料金ページ CTA テキスト統一

## 背景

料金ページ（`/pricing`）の「Premium を始める — ¥980/月」ボタンの下に
「続きを読む」という別の CTA テキストが並存している。
「Premium を始める」と「続きを読む」では訴求対象が異なり、
ユーザーがどちらをクリックすべきか迷う。

また試合詳細ページの paywall セクションでも「続きを読む」という CTA があり、
課金文脈なのか無料コンテンツの展開なのか曖昧である。

## スコープ

対象:
- 料金ページの CTA テキストおよびボタン構成
- 試合詳細 paywall の CTA テキスト

対象外:
- ボタンのスタイル・デザイン
- 認証・決済ロジック
- ログインモーダルの内容（`p6-login-modal-context.md` で対応）

## 変更内容

### CTA テキストの整理方針

| 箇所 | 現状 | 変更後 |
|------|------|--------|
| 料金ページ メイン CTA | 「Premium を始める — ¥980/月」 | 変更なし（主 CTA として維持） |
| 料金ページ サブ CTA | 「続きを読む」 | 削除または「無料で試す」に統一 |
| 試合詳細 paywall CTA | 「続きを読む」 | 「Premium で全文を読む」 |
| ヘッダーのログインリンク | 「ログイン」 | 変更なし |

### 試合詳細 paywall の変更

```tsx
// 変更前
<Button>続きを読む</Button>

// 変更後
<Button>Premium で全文を読む</Button>
```

### 料金ページのサブ CTA

「続きを読む」ボタンが独立して存在する場合は削除する。
「無料で試す」リンクが別途ある場合は `p6-free-trial-link.md` と合わせて整理する。

## 変更ファイル

- `app/pricing/page.tsx`（料金ページの CTA）
- `components/match-content.tsx`（試合詳細 paywall の CTA テキスト）

## 受け入れ条件

- [ ] 料金ページに「続きを読む」という曖昧な CTA が存在しない
- [ ] 試合詳細の paywall CTA が「Premium で全文を読む」になっている
- [ ] 各 CTA のクリック動作（モーダル表示・ページ遷移）は変更なし
- [ ] `pnpm tsc --noEmit` と `pnpm build` が通る

2. 「無料で試す」リンクとの重複整理方針（`p6-free-trial-link.md` と合わせて決定）
