# 試合ページ（モバイル）: 出場選手リストをタブ切り替えに変更

## 背景

`components/match-lineups-section.tsx` はホームチーム・アウェイチームの選手を
それぞれ縦一列で表示しており、2 チーム合計 40〜46 名が一度に並ぶ。

モバイル（375px）では全選手リストを表示するためにスクロール量が膨大になり、
試合のコアコンテンツ（プレビュー・レビュー・AI チャット）への到達を妨げている。

## スコープ

対象:
- `components/match-lineups-section.tsx` — モバイル向けタブ切り替え UI を追加

対象外:
- デスクトップレイアウトの変更（デスクトップでは左右 2 カラム表示を維持）
- 選手データの取得ロジック変更

## データモデル変更

なし

## API サーフェス

なし

## UI サーフェス

### モバイル（< `md` ブレークポイント / 768px 未満）

ホームチーム・アウェイチームを切り替える 2 タブを追加する:

```
┌─────────────────────┐
│  [Ireland] | France  │  ← タブ（ホームがデフォルト選択）
├─────────────────────┤
│  1. Hugo Keenan      │
│  2. James Lowe       │
│  ...                 │
└─────────────────────┘
```

- デフォルト: ホームチームタブを選択
- タブ切り替えは Client Component で実装（`"use client"` ディレクティブ）
- 現在 `MatchLineupsSection` がサーバーコンポーネントの場合は
  タブ切り替え部分のみを Client Component として切り出す

### デスクトップ（≥ `md` / 768px 以上）

既存の左右 2 カラム表示を維持（変更なし）。

### タブの実装方針

shadcn/ui の `Tabs` が既にプロジェクトで使われていればそれを使う。
なければシンプルな `<button>` + `useState` で自前実装する。
URL パラメータへの状態保存は不要（ローカル状態で OK）。
