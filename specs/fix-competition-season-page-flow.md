# 大会シーズンページで「次の試合」情報を先頭に出す

## 背景

2026-07-10、Codex（新モデル）によるデザイン評価（70/100）で指摘された課題。

`app/c/[competition]/[season]/page.tsx`（250行目付近）の現在の構成は `SeasonSwitcher` の後に `StandingsTable`（全順位表）が来る形になっている。以前の「ガイド全文が先頭」という問題（`fix-competition-descriptions.md` 等で対応済み）は解消されているが、今度は逆に**全順位表が最初に来るため、「次の試合を知りたい」訪問者が日程までスクロールする**構造になっている。

## スコープ

対象:
- ページヘッダー・シーズン切替（`SeasonSwitcher`）の直下に、「次戦」「首位チーム」「日本代表の次戦（出場している場合）」を簡潔にまとめた要約帯を追加する
- 「日程・結果」（`SeasonMatchGroups`）「順位」（`StandingsTable`）「大会ガイド」（`CompetitionViewingGuide`）をタブまたはページ内アンカーで切り替えられるようにし、初期表示は「日程・結果」にする
- 順位表は初期表示では上位数チーム＋該当チーム（日本が出場していれば日本を含む）に絞り、「全順位表を見る」で展開できるようにする

対象外:
- `SeasonMatchGroups`・`StandingsTable`・`CompetitionViewingGuide` 各コンポーネント自体のデータ取得ロジック変更（表示順序・初期表示範囲の変更のみ）
- SEOに影響する構造変更（SSR上では全情報を保持し、タブ切り替えはクライアントサイドの表示制御に留める）

## UI サーフェス

`app/c/[competition]/[season]/page.tsx` の該当セクション構成。タブ/アンカーの実装方法（`<details>`要素・タブUI・アンカーリンク等）はCodexの判断に委ねる。

## 受け入れ条件

1. シーズンページを開いた際、ヘッダー直下に次戦・首位チーム等の要約情報が表示される
2. 「日程・結果」「順位」「大会ガイド」を切り替えられる導線があり、初期表示は「日程・結果」になっている
3. 順位表の初期表示が全チームでなく上位＋該当チームに絞られており、「全順位表を見る」で展開できる
4. SSR時点（JavaScript無効時）でも全情報（順位表全件・大会ガイド全文）がHTMLに含まれている（SEOへの影響がないことを確認する）
5. `pnpm tsc --noEmit` / `pnpm lint` / `pnpm test` / `pnpm build` が通る
6. 本番デプロイ前に実際のブラウザで表示確認する。本番デプロイ自体はOwner承認後に別途行う

## 未解決の質問

- 「日本代表の次戦」表示は、日本が出場している大会（PNC・Nations Championship・RWC等）のみに限定してよい。出場していない大会（Premiership・Top14等）では該当項目を非表示にする
