# fix-h2h-latest-vs-next-match

## 背景

H2H ページが**未来の試合を「直近の対戦」として表示している**（2026-09-05 実測）。

`/h2h/japan-vs-usa` の表示:

| 項目 | 表示 |
|---|---|
| 収録対戦 | 4 試合 |
| **直近の対戦** | **2027-10-16 (土) 05:00 JST** ← 未来（RWC 2027） |
| 最新の対戦 | 日本 47 - 21 アメリカ（終了済み） |
| 次回対戦 | 2026-09-12 (土) 19:05 JST |

**同じページに3つの日付が並び、「直近の対戦」だけが 2027 年**を指している。これは「最新の終了済み試合」でも「次回対戦」でもない、収録範囲の最終試合である。

`/h2h/new-zealand-vs-south-africa` でも同様に 2026-09-13 が「直近の対戦」として出る。

原因は、収録試合を並べた配列の先頭（または末尾）をキックオフ日時で絞らずに採用していること。監査レポート A-5 は `data.matches[0]` をそのまま採用していると指摘している。

H2H は 200 ページあり sitemap の 12% を占める。**「直近の対戦」という語が最も基本的な意味で誤っているのは、データを扱う商品として重い。**

## スコープ

対象:
- `app/h2h/[pair]/page.tsx`: 「直近の対戦」を**終了済みの試合のうち最新のもの**に限定する
- 未来の試合は既存の「次回対戦」でのみ扱う

対象外:
- H2H ページの新規追加・削除・noindex 化（収録価値の判断は GSC/BWT のデータを見てから。別 spec）
- 「収録対戦リスト」の表示内容
- 「Tryline 収録分、全通算ではない」の注記（**現状の記述は正しい。維持する**）
- 他ページの「直近」表記

## UI サーフェス

| ラベル | 定義 |
|---|---|
| 直近の対戦 | **`status` が `finished` の試合のうち、キックオフが最も新しいもの** |
| 最新の対戦 | 上と同一。**重複しているため、どちらか一方に統合する** |
| 次回対戦 | status === 'scheduled'かつ有効なkickoffAt >= 固定した現在時刻のうち最も近いもの。cancelled/postponed/live/過去scheduledは除く。比較はDateのepoch値で行う。 |

最新の対戦カードを『直近の対戦』へ統合し、上部Metricの重複日付を除く。スコアと日時、hasRecapの場合のreview CTA、TrackedLinkのh2h_latest_review/h2h_next_matchとmatch_idを維持する。feat-h2h-latest-match-ctaの『既存Metric不変更』のみを本specで上書きする。

終了済みの試合が 1 件も無いペアでは、「直近の対戦」を表示しない（「次回対戦」のみ）。

デザイン: 既存のレイアウト・トークンを維持する。**項目が 1 つ減るため、余白の詰まりを Owner が目視で確認する。**

## 受け入れ条件

1. `/h2h/japan-vs-usa` の「直近の対戦」が **2027-10-16 ではなく、終了済みの最新試合（日本 47-21 アメリカ）の日付**になる
2. 同ページに「直近の対戦」と「最新の対戦」が**別項目として同時に存在しない**
3. `/h2h/new-zealand-vs-south-africa` で、未来の日付が「直近の対戦」として表示されない
4. 「次回対戦」が従来どおり未来の最も近い試合を指す
5. 終了済みの試合が 0 件のペアで「直近の対戦」が表示されないことを検証するテストがある
6. 未来の試合が 0 件のペアで「次回対戦」が表示されず、「直近の対戦」は表示されることを検証するテストがある
7. キックオフ日時の比較が**文字列比較ではなく日時として**行われている
8. 「Tryline 収録分、全通算ではない」の注記が維持されている
9. `pnpm test` と `pnpm typecheck` が green
10. **Owner の目視評価**: 項目が 1 つ減ったことによるレイアウトの崩れが無いこと。320 / 768 / 1440px で確認する

## 未解決の質問

なし。定義・統合方針・境界条件は本 spec で確定している。

**本 spec で解決しないと明示するもの**: 「収録対戦 4 試合」という件数は Tryline の収録分であり通算ではない。既存の注記は維持するが、**収録範囲の妥当性そのもの（200 ページの H2H を持つ価値があるか）は本 spec の対象外**で、GSC/BWT のデータを見てから別途判断する。
