# recap MOM 見出し → 注目選手

## 背景

`generate-recap.ts` の `hasLineups=true` ケースでは `# MOM` という見出しが出力され、LLM が得点・タックル等から選手を推論して記述する。しかし DB に公式MOMデータは存在しないため、記述が公式MOMと食い違うことがある（実例: 2026-06-07 リーグワン決勝、LLM 推論=李承信、公式=レタリック）。

`# MOM` という見出しは読者に「公式の最優秀選手」という印象を与えるが、実態は編集部の分析ピックである。見出しを `# 注目選手` に変えることで誤解を防ぐ。

## スコープ

対象:
- `lib/llm/prompts/generate-recap.ts`（`hasLineups=true` ケースの `structureInstruction` のみ）

対象外:
- 既存 recap DB レコードの遡及修正（次回再生成時に自然に更新される）
- `isDataSparse` ケース（MOM セクションなし）
- `!hasLineups && !isDataSparse` ケース（すでに MOM 吸収済み）

なし。

なし。

## 実装詳細

### バージョン更新

```typescript
export const PROMPT_VERSION = "recap@4.6.0";
```

### hasLineups ケースの変更箇所（3箇所）

1. セクション列挙行:
   ```
   "# MOM",
   ```
   →
   ```
   "# 注目選手",
   ```

2. 字数目標行:
   ```
   "- MOM: 300-400字。projected_lineups または match_events に存在する実名を使い、選出理由を具体化する",
   ```
   →
   ```
   "- 注目選手: 300-400字。projected_lineups または match_events に存在する実名を使い、この試合での貢献・プレー内容を具体的に記述する",
   ```

3. 禁止見出し列挙行:
   ```
   "**上記5つの見出し以外は絶対に追加してはならない。`# 試合概要`・`# 試合の流れ`・`# まとめ`・`# 総評` 等、リストに存在しない見出しの出力は禁止。**",
   ```
   →
   ```
   "**上記5つの見出し以外は絶対に追加してはならない。`# 試合概要`・`# 試合の流れ`・`# MOM`・`# マン・オブ・ザ・マッチ`・`# まとめ`・`# 総評` 等、リストに存在しない見出しの出力は禁止。**",
   ```

## 変更ファイルまとめ

| ファイル | 変更内容 |
|----------|---------|
| `lib/llm/prompts/generate-recap.ts` | バージョン `recap@4.6.0`、`hasLineups=true` ケースで `# MOM` → `# 注目選手` |

## 受け入れ条件

1. `hasLineups=true` ケースで生成された recap に `# MOM` 見出しが出力されない
2. 代わりに `# 注目選手` セクションが 300 字以上で出力される
3. `# 注目選手` の内容に選手名と具体的なプレー記述が含まれる
4. `pnpm tsc --noEmit` / `pnpm lint` clean
