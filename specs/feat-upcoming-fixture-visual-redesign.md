# feat-upcoming-fixture-visual-redesign

## 背景

GPT-5.6による調査（2026-07-20）とOwnerの実機確認で判明: トップページ「今後の試合」セクション（`app/page.tsx:366-421`）は、`TeamBadge` を `size={18}` という小さいサイズで表示しており、日付・チーム略称・大会タグがすべて同程度の視覚的重みで並んでいる。「次に見るべき試合」がひと目で判別しにくい。

`TeamBadge`（`components/team-badge.tsx`）は既に国旗SVG・チームカラーグラデーションを描画できる汎用コンポーネントであり、新規コンポーネントは不要。サイズと周辺レイアウトの調整で対応できる。

## スコープ

対象:
- `app/page.tsx` の「今後の試合」セクションを再設計する
- 直近1試合（リストの先頭、最も近いキックオフ）を「注目の次戦」として大きく扱う: `TeamBadge` を現行より大きいサイズ（目安 40〜48px）で表示し、キックオフ時刻を強調、チームカラーを左右の細いレール（stripe）として使う
- 2試合目以降はコンパクトな行として現状よりやや大きいバッジ（目安 28〜32px）で表示する
- `design.md` の既存方針「Team colors are limited to stripes, top bars, and low-opacity gradients」の範囲内で実装する（本文の文字色にチームカラーを使わない）

対象外:
- `TeamBadge` コンポーネント自体の内部実装変更（既存のflag/gradient描画ロジックは変更不要、サイズ調整のみで対応可能な想定）
- 大会ハブページ・カレンダーページの試合一覧デザイン変更（本specはトップページの「今後の試合」セクションに限定）
- 表示件数（現状5件）の変更

## UI サーフェス

- 参照: Owner・GPT-5.6のやり取りで出た構成イメージ（先頭1試合を大きく、以降はコンパクト行）
- 避けるべき表現: 実在ロゴ・公式ユニフォームへの寄せ（既存の `TeamBadge` の抽象的な旗/グラデーション表現を維持する）
- 使用トークン: `app/globals.css` のCSS変数（`--color-accent` 等）、`design.md` のspacing/radius定義に従う
- **完了の定義にビジュアル確認を含める**: 実装後、Owner がデスクトップ・モバイル双方でスクリーンショットを確認し、「次に見るべき試合」が視覚的に一段目立って見えることを承認すること（機械的なテストのみで完了としない）

## 受け入れ条件

1. 「今後の試合」リストの先頭1件が、2件目以降と視覚的に区別できるレイアウト（バッジサイズ・レイアウト構造のいずれかで差がある）になっていることをコードレビューで確認できる
2. `TeamBadge` の呼び出しにハードコードされた実在ロゴ画像・公式ユニフォーム画像が使われていないこと（既存の抽象表現を維持）
3. モバイル幅（375px前後）でレイアウト崩れ・横スクロールが発生しないことを確認する
4. `pnpm test` / `pnpm tsc --noEmit` / `pnpm lint` / `pnpm build` が通る
5. Owner によるスクリーンショット目視確認（デスクトップ1440px・モバイル375px）で承認を得ること
