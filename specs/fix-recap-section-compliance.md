# recap セクション構成コンプライアンス修正

## 背景

`recap@4.0.0` で生成した準々決勝（サントリー 40-35 リコー）のレビューに以下の問題が残った。

1. **`# 試合概要` が仕様外で出現** — events+no-lineups ケースの許可見出しは「試合全体像 / ターニングポイント / 次戦への示唆」の3つのみ。「試合概要」は禁止のはずだが `structureInstruction` に明示的なネガティブ制約がない
2. **`# MOM` がラインアップなし時に出現** — 現在は「MOM セクションは省略すること」という指示だが、モデルがイベントデータ内の選手名（チェスリン・コルビ）を使って MOM セクションを生成している
3. **字数不足（1,237字 < 2,000字目標）** — `# ターニングポイント` と `# 試合全体像` が指定字数の下限を下回っている

## スコープ

**対象:**
- `lib/llm/prompts/generate-recap.ts` のみ

**対象外:**
- 他のプロンプトファイル・パイプライン・型定義

## 実装詳細

### バージョン更新

```typescript
export const PROMPT_VERSION = "recap@4.1.0";
```

### 1. `structureInstruction` に「それ以外禁止」制約を追加

3ケースすべてで、見出しリストの**直後**（`全体で2,000字以上...` の行の前）に以下の行を追加する。

#### hasLineups=true の場合

```typescript
"**上記の見出し以外は絶対に追加してはならない。`# 試合概要`・`# 試合の流れ`・`# まとめ`・`# 総評` 等、リストに存在しない見出しの出力は禁止。**",
```

#### isDataSparse=true の場合

```typescript
"**上記の見出し以外は絶対に追加してはならない。`# 試合概要`・`# 試合の流れ`・`# まとめ`・`# 総評` 等、リストに存在しない見出しの出力は禁止。**",
```

#### events あり・lineups なし の場合

```typescript
"**上記の見出し以外は絶対に追加してはならない。`# 試合概要`・`# 試合の流れ`・`# まとめ`・`# 総評`・`# MOM`・`# マン・オブ・ザ・マッチ` 等、リストに存在しない見出しの出力は禁止。**",
```

### 2. MOM 禁止を強化（events あり・lineups なし ケースのみ）

events あり・lineups なし ケースの `structureInstruction` 配列の末尾（`sectionHeadingInstruction` の後）に追記:

```typescript
"**`# MOM`・`# マン・オブ・ザ・マッチ` セクションは絶対に出力してはならない。** イベントデータに選手名が含まれていても MOM セクションは生成禁止。MOM を記述したい場合は `# ターニングポイント` 内で選手名に言及すること。",
```

### 3. 字数下限の強制指示を強化

`return [...]` ブロック内の以下の既存行:

```typescript
"各セクションが指定範囲の下限を下回った場合は書き足すこと。",
```

を以下に変更:

```typescript
"各セクションが指定字数の**下限**を下回ってはならない。下限未満なら具体的な事実・戦術分析・選手描写を追加して下限まで書き足すこと。「字数確認済み」などのメタコメントは出力禁止。",
```

## 変更ファイルまとめ

| ファイル | 変更内容 |
|----------|---------|
| `lib/llm/prompts/generate-recap.ts` | バージョン `recap@4.1.0`、3ケースの `structureInstruction` に禁止リスト追加、MOM 強制禁止追加、字数下限指示を強化 |

## 受け入れ条件

1. events あり・lineups なし の recap を生成したとき、`# 試合概要` という見出しが出力されない
2. events あり・lineups なし の recap を生成したとき、`# MOM` という見出しが出力されない
3. 同ケースで全体字数が 1,600字以上（2,000字目標の許容下限）になる
4. `# 試合全体像`・`# ターニングポイント`・`# 次戦への示唆` の3セクションが正しく出力される
