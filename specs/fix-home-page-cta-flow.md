# ホームページのCTA導線を整理し、重複表示を解消する

## 背景

2026-07-10、Codex（新モデル）によるデザイン評価（74/100）で指摘された課題。

`app/page.tsx` の現在の構成（223行目付近から）を確認すると:
1. ヒーローセクション: 見出し「今週の海外ラグビーを、日本時間で追う」+ CTA（Premium無料体験→pricing / 今週の試合を見る→calendar）+ 右側に `HomeMatchdayBoard`（今週の注目試合ボード）
2. `FavoriteTeamsBanner`（未登録ユーザー向け、`feat-favorite-team-follow-engagement.md` で別途強化）
3. 無料サンプルレビュー（Premium未加入ユーザー向け）
4. （この後に「今週の試合」等の追加セクションがある想定）

見出しは「週末の実用性」を訴えているのに、第一CTAは料金ページ（Premium訴求）になっており、その直後にヒーロー右の試合ボードと、下部の「今週の試合」的なセクションで**同じ情報（今週の試合）をモバイルで二度見る**構造になっている。

## スコープ

対象:
- ヒーローのCTA順序を「今週の試合を見る（カレンダー）」を第一CTA、「Premium無料体験」を第二CTAに入れ替える
- ヒーロー右の `HomeMatchdayBoard`（試合ボード）と、ページ下部の「今週の試合」的なセクションが同じ試合情報を重複表示していないか確認し、重複があれば一本化する（`HomeMatchdayBoard` をヒーロー内に残し、下部は別の切り口—大会別レビュー一覧等—に絞る、または逆に下部に一本化してヒーローを軽量化する。どちらの構成にするかはCodexの実装判断に委ねる）
- 無料サンプルレビューセクションを、独立したセクションではなく「最近のレビュー」的な既存セクションの中の1件を開放する形に統合できるか検討し、可能であれば統合する

対象外:
- ヒーローのビジュアルデザイン自体（背景画像・タイポグラフィ等）の変更
- `HomeMatchdayBoard` コンポーネント自体のロジック変更（表示順序の入れ替え・配置のみ対象）

## UI サーフェス

`app/page.tsx` の該当箇所（ヒーローセクションのCTA配置、`HomeMatchdayBoard` とその後続セクションの構成）。

## 受け入れ条件

1. ヒーローの第一CTAが「今週の試合を見る」、第二CTAが「Premium無料体験」の順序になっている
2. モバイル幅（375px程度）でページを表示した際、同じ試合情報（対戦カード・日程）が2箇所以上で重複表示されていない
3. 無料サンプルレビューの表示方法について、統合した場合はその設計を、統合しなかった場合はその理由を完了報告に明記する
4. 既存のPremium会員向け表示分岐（`profile?.subscription_status !== "premium"` 等）に回帰がない
5. `pnpm tsc --noEmit` / `pnpm lint` / `pnpm test` / `pnpm build` が通る
6. 本番デプロイ前に、実際のブラウザ（Playwright等）でモバイル・デスクトップ双方のスクリーンショットを撮り、レイアウト崩れがないことを確認する。本番デプロイ自体はOwner承認後に別途行う
