# モバイルヘッダー タップ領域改善

## 背景

`site-header.tsx` のナビゲーション要素（「試合」「料金」リンクおよびログインボタン）が
モバイル 375px 幅でタップ領域が WCAG 推奨の 44×44px を下回っている可能性がある。
特にリンクの垂直 padding が `py-1.5`（12px）しかなく、ヘッダー高さ `h-14`（56px）に対して
要素が詰まって見える。

## スコープ

- 対象: `components/site-header.tsx`、`components/user-menu.tsx`
- 対象外: デスクトップレイアウト（sm: 以上は変更最小限）

## 変更内容

### ナビゲーションリンクのタップ領域拡大

現在の `px-3 py-1.5` を `px-3 py-3` に変更し、垂直タップ領域を 44px 相当に拡大する。
ヘッダー高さを維持したまま拡張するには `-my-1.5 py-3` を使う手法が有効
（ヘッダー外にはみ出さず、見た目のサイズ変化もない）。

```tsx
// 変更前
className="rounded px-3 py-1.5 text-sm font-medium ..."

// 変更後
className="rounded px-3 py-3 -my-1.5 text-sm font-medium ..."
```

### UserMenu のログインボタン

`UserMenu` コンポーネント内のログイン/サインアップ用ボタンが `min-h-[44px]` を
満たしているか確認し、不足していれば `py-3` などで調整する。

## 変更ファイル

- `components/site-header.tsx`
- `components/user-menu.tsx`（ログインボタンが 44px 未満の場合のみ）

## 受け入れ条件

- 375px 幅でナビゲーションの全インタラクティブ要素のタップ領域が高さ 44px 以上
- デスクトップ（sm: 以上）の見た目に変化なし
- ヘッダー全体の高さが著しく増加していない
