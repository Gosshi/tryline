# LLM プロンプト: カタカナ変換例を現役選手依存から汎用ルールに変更する

## 背景

プロンプトファイル（`generate-preview.ts` または `generate-recap.ts` 等）に
「Marcus Smith → マーカス・スミス」のような特定の現役選手名が例として記載されている。

この記載方法のリスク:
- 選手が引退・移籍・改名した場合に例が陳腐化する
- 例として挙げた選手を LLM が「必ず登場させる」と誤解するリスク
- 将来のプロンプト保守で「この選手は今も現役か？」を確認するコストが生じる

## スコープ

対象:
- 選手名を例示しているプロンプトファイル
  （Codex が `generate-preview.ts`・`generate-recap.ts`・`extract-tactical-points.ts` を確認して特定すること）

対象外:
- カタカナ変換のルール自体は変更しない

## LLM 連携

### 変更方針

具体的な現役選手名の例を**汎用ルール**に置き換える。

```typescript
// 変更前
"選手名のカタカナ表記例: Marcus Smith → マーカス・スミス、Antoine Dupont → アントワーヌ・デュポン"

// 変更後
"選手名のカタカナ表記: 英語の人名はカタカナに変換し、姓名の間に中点（・）を入れること。"
```

どうしても例が必要な場合は引退した伝説的選手（Jonah Lomu 等）を使うこと。

## 受け入れ条件

1. プロンプト中の現役選手名の例示が汎用ルールに置き換えられている
2. 出力テキストで選手名がカタカナ変換されることを手動確認
3. `tsc --noEmit` でビルドエラーなし
