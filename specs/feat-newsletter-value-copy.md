# ニュースレター登録導線の価値訴求

## 背景

大会ハブではニュースレター表示が多い一方、確認完了は少ない。登録前に受け取れる内容を具体的に示し、無料登録の意図を明確にする。

## スコープ

- `NewsletterSignup` の見出し、説明、送信ボタンを更新する。
- 既存の表示・送信・結果・確認イベントと API は変更しない。

## 受け入れ条件

1. 「今週の海外ラグビーを、見逃さず追う」と表示する。
2. 週1回、注目試合の日程と公開済み日本語レビューを送ることを説明する。
3. ボタンは「無料で今週のまとめを受け取る」と表示する。
4. 既存の送信処理とイベント計測が維持される。
