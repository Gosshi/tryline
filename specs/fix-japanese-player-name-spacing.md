# fix-japanese-player-name-spacing

> GPT-6 監査 A-3 6（P2）。日本語の選手名で姓名の間の空白が混在している。

## 背景

`players.name_ja` を持つ選手は **23 人**。うち**空白ありが 11 人、空白なしが 12 人**（2026-09-09 本番実測）。ほぼ半々で割れている。

```
空白あり: 齋藤 直人
空白なし: 木田晴斗
```

表示側は `name_ja` を**そのまま出している**（`components/match-events-section.tsx:281` / `components/match-lineups-section.tsx:183,186` / `components/team-stats-panel.tsx:187` ほか）。同じ画面に両方の書式が並ぶ。

監査の指摘（原文）: 「齋藤 直人/木田晴斗等で混在。」「P2: 日本語姓名の表示規則を定義し、DB原典表記と表示正規化を分離。**外国名の区切りを一律削除しない。**」

**最後の一文が本 spec で最も重要な制約である。** 空白を機械的に削除すると、`Seungsin Lee` のような外国人選手名や、カタカナ表記の姓名区切りが壊れる。

## スコープ

対象:
- 日本語の姓名に対する**表示規則の定義**（`docs/` または `design.md`）
- 表示用の正規化関数と、その適用
- テスト

対象外:
- **`players.name_ja` の DB 値の書き換え**。原典表記は保持し、表示側で揃える（監査の「DB原典表記と表示正規化を分離」）
- **外国人選手名の空白**。ラテン文字・カタカナの区切りは触らない
- `name_ja` の**カバレッジ拡大**（23/2456 人）。それは `fix-player-name-ja-coverage.md` の範囲
- 選手同一性（`Lee` / `Seungsin Lee` の重複）。同じく別 spec
- 英語名（`players.name`）の表示

## データモデル変更

なし。**読み取りと表示のみ。**

## API サーフェス

なし。

## UI サーフェス

選手名の表示。**空白の有無が揃うだけで、レイアウトは変わらない。**

## LLM 連携

なし。コスト $0。**表記の判定に LLM を使わない**（姓名の境界を推測させると捏造の経路になる）。

## 変更詳細

### 1. 規則を先に決めて文書化する

「漢字・ひらがなの姓名を空白で区切るか、詰めるか」を決め、**根拠とともに文書に残す**。実装だけ入れて規則が残らないと、次に別の人が逆向きに直す。

### 2. 適用範囲を判定できること

**漢字・ひらがなの姓名にだけ適用する。** 判定は決定論的に行う。

| 入力 | 扱い |
|---|---|
| `齋藤 直人` | 規則を適用 |
| `木田晴斗` | 規則を適用 |
| `Seungsin Lee` | **触らない**（ラテン文字） |
| `リーチ マイケル` | **触らない**（カタカナ） |
| `null` / 空文字 | **触らない** |

**カタカナを対象に含めないこと。** カタカナの姓名区切りは外国人選手で意味を持つ。

### 3. 置き場所

`lib/format/` 配下（`venue-timezone.ts` などの表示整形が集まっている場所）。**表示用であることが名前から分かる関数名にすること。** `fix-venue-footnote-display-leak` で `normalizeVenue`（照合キー用）と表示用を取り違えた前例がある。

## 受け入れ条件

1. 表示規則が `docs/` または `design.md` に文書化され、根拠が書かれている
2. `齋藤 直人` と `木田晴斗` が**同じ書式で表示される**ことを検証するテストがある
3. **`Seungsin Lee` の空白が保持される**ことを検証するテストがある
4. **カタカナ姓名（`リーチ マイケル`）の空白が保持される**ことを検証するテストがある
5. `null` と空文字で例外にならないことを検証するテストがある
6. 漢字とラテン文字が混在する名前で、ラテン側の区切りが壊れないことを検証するテストがある
7. `components/match-events-section.tsx` / `components/match-lineups-section.tsx` / `components/team-stats-panel.tsx` に適用されている
8. **`players.name_ja` への `UPDATE` が差分に含まれない**
9. LLM 呼び出しが差分に含まれない（ソース中に `getOpenAIClient` / `MODELS` が現れない）
10. **`players.name`（英語名）の表示に差分が無い**
11. `pnpm lint` / `pnpm typecheck` / `pnpm test` が green

**テストの置き場所**: `tests/format/` と `tests/components/` 配下（`exclude` 非該当。確認済み）。
