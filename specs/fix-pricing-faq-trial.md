# Pricing: FAQ に「無料トライアルはありますか？」を追加する

## 背景

`app/pricing/page.tsx`（または FAQ コンポーネント）の FAQ セクションに
「無料トライアルはありますか？」という最も基本的な購入前質問が含まれていない。

ユーザーが有料登録を検討する際に最初に湧く疑問であり、
これが FAQ になければ他のサイトで調べるか、離脱する可能性が高い。

## スコープ

対象:
- `app/pricing/page.tsx` または FAQ コンポーネント — FAQ アイテムを追加

対象外:
- 実際の無料トライアル機能の実装（Stripe の trial 設定は別タスク）
- 既存 FAQ アイテムの変更

## データモデル変更

なし

## API サーフェス

なし

## UI サーフェス

### FAQ に追加するアイテム（たたき台）

```tsx
{
  question: "無料トライアルはありますか？",
  answer:
    "現在、無料のプレビュー記事（試合前分析）をご登録なしでお読みいただけます。" +
    "レビュー記事（試合後分析）と AI チャット機能は Premium 会員限定ですが、" +
    "まずはプレビュー記事でコンテンツの質をお確かめください。",
}
```

追加位置: 既存 FAQ の**最初**に配置する（最も多く検索される質問のため）。

## 受け入れ条件

1. Pricing ページの FAQ に「無料トライアルはありますか？」が最初のアイテムとして表示される
2. 回答文が現在の無料範囲（プレビュー閲覧）を正しく説明している
3. `tsc --noEmit` でビルドエラーなし
