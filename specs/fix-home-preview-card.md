# ホームページ: ファーストビューに無料プレビューカードを追加

## 背景

`app/page.tsx` のヒーローセクションは動画背景 + キャッチコピー + CTA ボタンのみで構成され、
実際のコンテンツ（プレビュー記事）がファーストビューに存在しない。

初訪問ユーザーは「何が読めるのか」を体感できないまま離脱する。
`sampleReviews[0]`（最新の公開済み recap を持つ試合）はすでに取得済みで
Pricing ページのサンプルにも使われており、同一データをヒーロー内に
インライン表示することでコンテンツ品質を即座に体感させる。

## スコープ

対象:
- `app/page.tsx` — ヒーローセクション内に最新コンテンツカードを追加

対象外:
- データ取得ロジックの変更（既存の `sampleReviews[0]` を流用する）
- プレビュー全文の表示（冒頭 100〜150 字抜粋 + 「続きを読む」リンクのみ）
- 認証・ペイウォール制御（プレビューは無料なので不要）

## データモデル変更

なし

## API サーフェス

なし（既存クエリ `getRecentlyReviewedMatches(1, "ja")` を流用）

## UI サーフェス

### 配置

ヒーローセクションの CTA ボタン群（`mt-8 flex flex-wrap gap-3`）の下に記事カードを追加。

### カードデザイン

```
┌─────────────────────────────────────────┐
│ [大会名] Six Nations 2025               │
│ Ireland vs France  22–17                │
│ アイルランドは前半から…（100〜150字）    │
│                   プレビュー全文を読む → │
└─────────────────────────────────────────┘
```

- 背景: `bg-white/10 backdrop-blur-sm rounded-xl`（ヒーローの暗背景に馴染む半透明）
- テキスト色: `text-white/90`
- `sampleReviews[0]` が null の場合はカードを非表示（条件付きレンダリング）

### モバイル対応

375px でもカードが崩れないこと。テキストは折り返し OK。

## LLM 連携

なし

## 受け入れ条件

1. ヒーローセクション内に記事カードが表示される
2. カードには大会名・対戦カード（チーム名・スコア）・テキスト抜粋・試合ページリンクが含まれる
3. `sampleReviews[0]` が null のときカードが非表示になる
4. Playwright でデスクトップ（1440px）とモバイル（375px）のスクリーンショットを撮り、
   カードがヒーロー内に収まっていることを確認
5. `tsc --noEmit` でビルドエラーなし

## 未解決の質問

- `sampleReviews` が返す型に recap の冒頭テキスト（`recapExcerpt`）があることを確認し、
  プレビュー冒頭文として流用するか、別途 preview の excerpt フィールドを追加するか決める
- カードの具体的なビジュアルデザインは Owner が実装後に確認・調整すること
