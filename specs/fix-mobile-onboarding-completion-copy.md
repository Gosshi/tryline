# fix-mobile-onboarding-completion-copy: オンボーディング完了画面の文言修正

対象リポジトリ: **tryline-mobile** のみ。`app/onboarding.tsx` の1箇所のみを触る軽微な文言修正。

## 背景

Owner による Simulator 実機確認(2026-07-24)で、オンボーディング完了画面のタイトル「あなたの週ができました」が日本語として意味が伝わりにくいと指摘された。「週」が何を指すか(その週の試合日程なのか、パーソナライズされたホーム体験なのか)が不明瞭。Owner の選択により「準備ができました」に変更する。

## スコープ

対象:
1. `app/onboarding.tsx` の完了画面タイトルを「あなたの週ができました」→「準備ができました」に変更する(該当箇所: `<Text style={styles.title}>あなたの週ができました</Text>`)

対象外:
- 完了画面のその他の文言(「直近の試合はまだありません。ホームで最新情報を確認できます。」等の本文、試合サジェスト表示ロジック)
- オンボーディングのチーム選択候補ロジック(別途 Owner が選択肢/設問を検討中のため触らない)
- [[feat-mobile-onboarding-settings-reentry]] のスコープ(設定タブからの再入場導線は別spec)

## データモデル変更 / API サーフェス

なし。

## UI サーフェス

- `app/onboarding.tsx` の完了画面タイトルのみ変更。レイアウト・スタイルは変更しない

## 受け入れ条件

1. オンボーディング完了画面(`done === true` の分岐)のタイトルが「準備ができました」と表示されることを確認するテスト(既存のスナップショット/テキストアサーションがあれば更新、なければ追加)
2. 「あなたの週ができました」という文字列がコードベースに残っていないことを確認する(grep等)
3. TypeScript strict・lint・test green

## 未解決の質問

なし。
