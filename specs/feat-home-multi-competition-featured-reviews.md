# ホーム「最近のレビュー」を大会横断・レベル優先のヒーロー選定にする

## 背景

`fix-home-recent-reviews-round-grouping.md`（実装済み・PR #494）で、ホーム「最近のレビュー」を「直近の1件が属する大会+節をまとめて表示」に変更した。しかしヒーローカード（先頭の大きいカード）は依然として `generated_at`（レビュー生成パイプラインの処理順）が最新の1件という機械的な選定のままで、対戦カードの「レベル」とは無関係だった（例: 日本×イタリアがヒーローになり、NZ×フランスやSouth Africa×イングランドのような伝統国対決がコンパクト行に埋もれる）。

Owner との壁打ちで、以下の方針に決定（2026-07-08）:
- 対戦カードの「レベル」は、国代表戦は世界ランキング（`feat-world-rugby-rankings-ingestion.md`）、クラブ戦は順位表（`fix-top14-srp-standings-weekly.md`）で判定する
- 週内に**複数の大会**でレビューが公開された場合（例: Super Rugby PacificとLeague Oneが同じ週に完了）、大会ごとに1件ヒーローカードを出す（1大会1ブロック、各ブロックにヒーロー+コンパクト行）

本specは上記2つの前提spec（世界ランキング・順位表の週次自動化）の完了後に着手すること。

## スコープ

対象:
- `lib/db/queries/matches.ts` の `getRecentlyReviewedMatches` を、単一の大会+節グルーピングから「直近アクティブな複数大会、それぞれの最新節」を返す形に再設計する
- 大会ごとのヒーロー選定ロジック（対戦カードの合計レベルが最も高い試合を選ぶ）
- `app/page.tsx` の「最近のレビュー」セクションのレンダリングを、大会ごとに「ヒーロー1件+コンパクト行」のブロックを複数並べられる構造に変更する

対象外:
- `feat-world-rugby-rankings-ingestion.md` / `fix-top14-srp-standings-weekly.md` のデータ取り込み自体（前提specとして別途完了させる）
- ホームページの他セクション（大会アーカイブ、今週の試合等）
- 大会をまたいだ絶対的な優先順位付け（例: Super Rugby Pacificブロックを常にLeague Oneより上に出す、といった大会間の並び順の恣意的な優先度。並び順は「直近生成順」を維持する）

## データモデル変更

なし（前提spec側で追加済みの `teams.world_ranking` と `competition_standings` を読むのみ）

## 実装詳細

### 1. 「直近アクティブな大会」の判定

`generated_at` 降順で候補プール（目安40件）を取得するのは現状維持。候補プールを `competition.family + season + round` でグルーピングし、**各グループの最新 `generated_at` が直近7日以内**のグループだけを「アクティブな大会」として残す（7日という値は目安。Codexの裁量で調整可）。

### 2. 大会ごとのヒーロー選定（対戦カードのレベル判定）

各アクティブグループ内で、試合ごとに「レベルスコア」を計算する:

- **両チームに `teams.world_ranking` が設定されている場合**（国代表戦）: `home.world_ranking + away.world_ranking` が小さいほど高レベル
- **大会に `competition_standings` のデータがある場合**（クラブ戦）: 両チームの `position` の合計が小さいほど高レベル
- **どちらのデータも無い場合**: レベルスコアなし。フォールバックとして、そのグループ内で最も `generated_at` が新しい試合をヒーローにする（現状の挙動を維持）

各グループ内でレベルスコアが最小（＝最高レベル）の試合をヒーローにし、残りをコンパクト行にする。

### 3. UI構造の変更

`app/page.tsx` の「最近のレビュー」セクションを、大会グループの配列を受け取って **大会ごとに見出し（大会名）+ ヒーロー1件 + コンパクト行** を繰り返しレンダリングする構造に変更する。既存の単一ブロックのマークアップ（ヒーローカード・コンパクト行のスタイル）は流用し、大会ごとに繰り返す `.map()` でラップする形でよい。

## 受け入れ条件

1. 同じ週にSuper Rugby PacificとLeague One（またはその他2大会）が完了した場合、ホームに2つの独立したブロック（各々ヒーロー+コンパクト行）が表示される
2. 国代表戦のグループでは、世界ランキング合計が最小の試合がヒーローになる（例: NZ×フランスのような伝統国対決が、日本×イタリアより世界ランキング合計で優れていればヒーローになる）
3. クラブ戦のグループでは、順位表の合計順位が最小の試合がヒーローになる
4. ランキング・順位表データが無い試合しかない大会は、既存通り生成順で最新の試合がヒーローになる（クラッシュしない）
5. 7日を超えて更新のない大会グループは表示されなくなる
6. `pnpm test` で新規・既存のテストが通る
7. `pnpm tsc --noEmit` / `pnpm lint` / `pnpm build` clean
8. 320/768/1024/1440pxで複数ブロック表示時のレイアウト崩れがないことをスクリーンショットで確認する

## 未解決の質問

- 「直近7日以内」という活動判定のウィンドウ幅は仮の値。試合スケジュールの実態（週末開催が中心）を踏まえてCodexが調整してよい
- 大会ブロックの並び順（生成順以外の基準、例えば大会の知名度順）を将来つけたくなった場合は別specとする
