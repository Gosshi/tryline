# ホーム見出しの「を」だけが孤立する改行を修正

## 背景

`fix-home-hero-heading-overflow.md`（PR #501）で、320px幅でのオーバーフロー対策として `<wbr/>` を複数箇所に挿入した。しかし現在の本番表示（実機で確認、幅約1455px前後）では、見出し「今週の海外ラグビーを、日本時間で追う。」が以下のように折り返され、「を、」という2文字だけの行が孤立してしまっている:

```
今週の海外ラグビー
を、
日本時間で追う。
```

原因は `app/page.tsx:249-261` の `<wbr/>` 配置。「ラグビー」と「を、」の間に `<wbr/>` があるため、「今週の海外ラグビー」が1行に収まりきらない幅で「ラグビー」の直後に改行が起き、「を、」だけが次の行に取り残される。

本番ページ（Chrome DevTools経由）で実際に該当箇所の `<wbr/>` を1つ削除して検証したところ、以下のように自然な3行に改善されることを確認済み:

```
今週の海外
ラグビーを、
日本時間で追う。
```

## スコープ

対象:
- `app/page.tsx` の h1（249-261行目）から、「ラグビー」と「を、」の間の `<wbr/>`（3番目の `<wbr/>`）を削除する

対象外:
- 他の `<wbr/>`（「今週の」後、「海外」後、「日本時間」後）の変更（今回の孤立行問題には無関係と実機検証済み）
- `fix-home-hero-heading-overflow.md` で対応した320px幅でのオーバーフロー問題そのものの再修正（本specは見た目の改行位置のみが対象。オーバーフローを再発させないことは受け入れ条件で担保する）

3. `fix-home-hero-heading-overflow.md`（PR #501）で対応した320px幅でのオーバーフロー（左右にはみ出す・横スクロールが必要になる状態）が再発していないことを、320px・375px・768px・1024px・1440pxの各幅でスクリーンショットまたはDOM計測で確認する
