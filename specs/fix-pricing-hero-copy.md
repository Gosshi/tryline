# Pricing ページ: ヒーローコピーを具体的な便益訴求に変更

## 背景

`app/pricing/page.tsx` のヒーローコピーは「海外ラグビーを、もっと深く。」という
抽象的なメッセージで、ユーザーが得られる具体的な価値が伝わらない。

Pricing ページはコンバージョンの最終関門であり、
ここで「なぜ ¥980/月 を払うのか」が即座に理解できなければ離脱する。
数値や具体的行動を含むコピーに変更することで転換率の改善を図る。

## スコープ

対象:
- `app/pricing/page.tsx` — ヒーロー h1 とサブコピーのテキスト変更のみ

対象外:
- ページ構成・レイアウトの変更
- CTA ボタンのテキスト変更（「Premium を始める — ¥980/月」は維持）

## データモデル変更

なし

## API サーフェス

なし

## UI サーフェス

### 変更箇所

```tsx
// 変更前
<h1>海外ラグビーを、もっと深く。</h1>
<p>AI が生成した日本語プレビュー・レビューと試合チャットで観戦体験を格上げする。</p>

// 変更後（最終コピーは Owner が決定してから実装）
<h1>週 10 試合以上の AI 戦術分析を、日本語で読み放題。</h1>
<p>
  Six Nations・Premiership・URC ほか 8 大会対応。
  レビュー全文と試合 AI チャットが ¥980/月で使い放題。
</p>
```

コピーの要件:
- h1: 数値（試合数・大会数・価格）または具体的行動を含めること
- サブコピー: 対象大会名を列挙し価格を再掲すること
- h1 は全角 30 字以内（モバイル 375px で 3 行以内）

上記テキストはあくまで案。**Owner が最終コピーを確定させてから実装すること。**

## 受け入れ条件

1. h1 に数値または具体的便益が含まれている
2. サブコピーに対象大会名と価格が含まれている
3. モバイル（375px）で h1 が 3 行以内に収まっている
4. Playwright でデスクトップ・モバイル両方のスクリーンショットを撮り確認
5. `tsc --noEmit` でビルドエラーなし
