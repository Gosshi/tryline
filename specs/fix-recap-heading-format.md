# recap 見出しフォーマット修正

## 背景

`recap@4.2.0` で生成したレビューの見出しが `# この試合の核心（200字以内）` や `# 試合全体像（400-500字）` となっている。`structureInstruction` の各行が `# 見出し名（字数）: 説明` という形式なので、モデルが行全体を見出しとしてコピーしてしまっている。

## 根本原因

現在の `structureInstruction` のリスト形式:
```
# この試合の核心（200字以内）: 試合前の「何 対 何の争い」...
# 試合全体像（400-500字）
# ターニングポイント（600-700字）
...
```
→ モデルが `# ` で始まる行全体を見出しとして認識し、`（200字以内）` や `（400-500字）` まで見出し行に出力する。

## 解決策

「許可見出し一覧」と「字数・説明」を2つのブロックに分離する。

## スコープ

**対象:** `lib/llm/prompts/generate-recap.ts` のみ

## 実装詳細

### バージョン更新

```typescript
export const PROMPT_VERSION = "recap@4.3.0";
```

### `structureInstruction` を3ケースすべてで書き直す

各ケースを「見出し一覧ブロック」+「字数・説明ブロック」+「禁止ブロック」の3段構成にする。

#### hasLineups=true の場合

```typescript
[
  "出力するセクション（この順番・この見出し名のみ使用、変更・追加・省略は禁止）:",
  "# この試合の核心",
  "# 試合全体像",
  "# ターニングポイント",
  "# MOM",
  "# 次戦への示唆",
  "",
  "各セクションの字数目標と内容指示:",
  "- この試合の核心: 200字以内。試合前の「何 対 何の争い」に対し実際の結果がどう答えたかを1〜2文で述べる",
  "- 試合全体像: 400-500字",
  "- ターニングポイント: 500-600字",
  "- MOM: 300-400字",
  "- 次戦への示唆: 300-400字",
  "",
  "見出し行には「# セクション名」のみを書くこと。字数指示・説明文を見出し行に含めてはならない。",
  "**上記5つの見出し以外は絶対に追加してはならない。`# 試合概要`・`# 試合の流れ`・`# まとめ`・`# 総評` 等、リストに存在しない見出しの出力は禁止。**",
  `全体で2,000字以上を目標とすること。${sectionHeadingInstruction}`,
].join("\n")
```

## 受け入れ条件

1. 生成された見出しが `# この試合の核心`（括弧・説明なし）となっている
2. 生成された見出しが `# 試合全体像`（括弧・説明なし）となっている
3. `# 試合概要` が出力されない
4. `# MOM` が出力されない（events+no-lineups ケース）
5. 全体字数が 1,600字以上
