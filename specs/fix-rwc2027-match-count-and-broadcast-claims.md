# fix-rwc2027-match-count-and-broadcast-claims

## 背景

RWC 2027 ハブ `/c/rwc/2027` は North Star（RWC2027 までの有料購読者数）に直結する入口だが、**同一ページ内で矛盾した事実を出している**（2026-09-05 実測）。

| 箇所 | 表示 |
|---|---|
| `app/c/rwc/2027/page.tsx:84-90` `PreTournamentBanner` | 「2027年10〜11月、オーストラリア開催。**全36試合のスケジュールが確定しています**」 |
| 同ページの大会ガイド | 「大会は**24チーム・52試合**の形式で行われ」 |

`matchCount` は DB に登録済みの試合数をそのまま渡している。**36 はプール戦の数であり、大会全体は 52 試合。**「収録済み件数」を「大会全体の確定件数」に一般化している。

RWC 公式は **2027年10月1日〜11月13日・52試合**を発表済み（<https://www.rugbyworldcup.com/en/news/976797/about-mens-rugby-world-cup-2027>）。FAQ の開催期間は登録済み試合の最小/最大から算出しており 10/2〜10/18 になる。

同ページの視聴方法は **2027年の放送を断定している**。

> DAZN : ライブ中継とハイライトを視聴可能。／J SPORTS : **全試合を生中継**。／NHK : 日本代表の試合を中心に地上波でも放送予定。／WOWOW : …

**RWC 2027 の日本国内放送権は本 spec 作成時点で未発表。** 断定は誤った視聴行動を招き、「間違いを書かない」という商品の前提に反する。

## スコープ

対象:
- `app/c/rwc/2027/page.tsx`: 試合数表記を「大会全体 52 / 収録済み N」に分離
- 同ページ FAQ・JSON-LD の開催期間を公式値に接地
- 同ページの視聴方法から、未発表の放送を断定する記述を除去

対象外:
- 他大会のハブ（`fix-season-faq-broadcast-hardcoding.md` が扱う）
- `/c/rwc/2027/bracket`（別 spec）
- RWC 2027 の試合データ取り込み（`matchCount` を 52 にするためのバックフィルは行わない。**収録件数は収録件数のまま表示する**）
- 日本の進出条件・次戦・通知（P1 の別 spec）

## データモデル変更

なし。大会全体の試合数（52）と開催期間（2027-10-01〜2027-11-13）は**公式発表値の定数**として持つ。DB の登録件数から導出しない。

## API サーフェス

なし。

## UI サーフェス

`PreTournamentBanner` の文言を次の構造にする。

- 大会規模: 公式値（24チーム・52試合）
- 開催期間: 公式値（2027年10月1日〜11月13日）
- Tryline の収録状況: 「現在 N 試合の日程を掲載」（N は DB の登録件数）

**「全」「確定」を収録件数に対して使わない。** 収録件数と大会規模を同じ文に並べるときは、どちらがどちらか読者が誤読しない語順にする。

視聴方法は、放送が未発表であることを明示し、**サービス名を挙げて断定しない**。決定次第更新する旨と公式サイトへのリンクに置き換える。

デザイン: 既存トークン（`--color-rule` / `--color-ink-muted` / `bg-white`）と現行の `rounded-lg border px-6 py-4 text-sm` を維持する。**警告色を使わない**。**Owner の目視評価**を受け入れ条件に含める。

## LLM 連携

なし（コスト影響ゼロ）。**大会概要ガイドを LLM で再生成しない。** 定数と DB 値の表示ロジックの修正のみ。

## 受け入れ条件

1. `/c/rwc/2027` に「全36試合」という表記が存在しない
2. 大会総数52とTryline掲載件数Nは別ラベルで表示される。N=52のときは同じ数値になってよい。Nが0・36・52の各fixtureで検証する。
3. 同ページのガイド（52試合）とバナーの数字が矛盾しない
4. FAQ・JSON-LD の開催期間が 2027年10月1日〜11月13日である。**登録済み試合の最小/最大から算出していない**
5. 同ページに「J SPORTS : 全試合を生中継」等、未発表の放送を断定する記述が存在しない
6. 視聴方法の欄に、放送予定が未発表である旨と公式情報への参照がある
7. 収録件数が将来増えても、表示が「全 N 試合が確定」に戻らないことを検証するテストがある（`matchCount` を 52 に変えても「全52試合のスケジュールが確定しています」と出力しない）
8. `pnpm test` と `pnpm typecheck` が green
9. **Owner の目視評価**: 320 / 768 / 1440px で、収録件数と大会規模の区別が読者に誤解なく伝わること

## 追加の受け入れ条件
RWC2027の放送断定はguide.verified_atの有無に関係なく、2027年の当該放送権の出典が確認されるまで表示しない。DBのfamily共通guideは更新しない。旧大会の視聴案内・他ページには本変更の効果を外挿しない。

**放送情報が発表された場合**の反映は本 spec の対象外。`feat-broadcast-auto-ingest` 系の既存経路に載せるか手動更新するかは、発表時に Owner が判断する。
