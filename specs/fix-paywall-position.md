# 試合ページ: ペイウォール位置をあと 100〜200 字後ろにずらす

## 背景

`p3-paywall-teaser.md` によると現在のペイウォールは本文 300 字で切っている。
評価時点では冒頭直後に遮断されており、ユーザーが「深掘り感」を体感する前に
Premium 訴求が表示される状態。

「戦術分析の最初の段落が始まる直前」まで無料で読ませることで
「続きが読みたい」という購買動機を高める。
目標は 300 字 → **400〜500 字**（プロンプトで指定した文章構成上、
第1段落（導入）+ 第2段落冒頭（戦術分析の入り口）まで）。

関連仕様: `p3-paywall-teaser.md`（次の見出しをチラ見せする別アプローチ）と
組み合わせると更に効果的。

## スコープ

対象:
- `components/match-content.tsx` または `components/premium-recap-section.tsx` —
  非 Premium ユーザー向け表示文字数の制御箇所

対象外:
- プレビューの無料公開範囲（全文無料を維持）
- ペイウォールのデザイン・フェードアウト表現の変更

## データモデル変更

なし

## API サーフェス

なし

## UI サーフェス

### 変更箇所

`components/match-content.tsx`（または同等のコンポーネント）内の
非 Premium 向け文字数制限を 300 → **450** 字に変更する。

```typescript
// 変更前
const FREE_CHAR_LIMIT = 300;

// 変更後
const FREE_CHAR_LIMIT = 450;
```

定数が存在しない場合はマジックナンバーを定数化してから変更すること。

段落の途中で切れる場合は次の文末（`。`）まで延ばし、
文章が不自然に途切れないようにする。

## LLM 連携

なし

## 受け入れ条件

1. 試合ページの非 Premium 向けレビュー表示が 400〜500 字程度になっている
2. 文章が段落の途中ではなく文末（`。`）でカットされている
3. Premium 会員は全文を読める（変更なし）
4. Playwright で試合ページのスクリーンショットを撮り、無料表示量を確認
5. `tsc --noEmit` でビルドエラーなし
