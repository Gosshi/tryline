# recap MOM 吸収 + 字数不足修正

## 背景

`recap@4.3.0` で残る問題が2点。

### 問題1: `# MOM` が events+no-lineups ケースで出続ける

禁止ワードを増やしても `# MOM` が消えない。根本原因は「モデルがイベントデータにコルビの名前を見つけ、MOM を書きたいバイアスが禁止指示に勝つ」こと。

**解決策の転換:** 禁止ではなく吸収。`# ターニングポイント` の字数目標を引き上げ、末尾に MOM 相当の選手分析を含めるよう明示的に指示する。モデルが「MOM を書く場所」を見つければ独立セクションを追加しなくなる。

### 問題2: 字数不足（1,047字 / 目標 2,000字以上）

各セクションが指定字数の半分程度しか出力されない。「目標とすること」「下回ってはならない」という指示がモデルの簡潔化バイアスに負けている。

**解決策:** セクションごとに「何を書けば目標字数に達するか」を箇条書きで示す。モデルに構成の骨格を与えることで、埋めるべき内容が明確になり字数が増える。

## 受け入れ条件

1. `# MOM` という見出しが出力されない
2. `# ターニングポイント` の末尾に主要選手の分析が含まれている
3. `# 試合概要` が出力されない
4. 全体字数が 1,600字以上
5. `# 試合全体像` が 350字以上、`# ターニングポイント` が 500字以上
