# recap coreQuestionBlock を structureInstruction に統合

## 背景

`recap@4.1.0` で `# 試合概要` を禁止リストに明示したにもかかわらず、モデルが依然として出力し続けている。

**根本原因:** `coreQuestionBlock`（セクション0: `# この試合の核心`）と `structureInstruction`（セクション1〜）がプロンプト配列内で別ブロックとして分離されているため、モデルが「Section 0 と Section 1 の間を埋めるサマリーセクションが必要」と誤解して `# 試合概要` を補完している。

**解決策:** `coreQuestionBlock` を廃止し、`# この試合の核心` を `structureInstruction` の先頭に組み込む。モデルが参照する「許可見出し一覧」を一箇所に集約することで、補完の余地をなくす。

## スコープ

**対象:**
- `lib/llm/prompts/generate-recap.ts` のみ

**対象外:**
- 他のファイル

## 実装詳細

### バージョン更新

```typescript
export const PROMPT_VERSION = "recap@4.2.0";
```

### 1. `coreQuestionBlock` 定数を削除

以下のコードを削除する（現在 L58–L63）:

```typescript
const coreQuestionBlock = [
  "## セクション0（必須、200字以内）: # この試合の核心",
  "試合前の「何 対 何の争い」という問いに対し、実際の結果がどう答えたかを1〜2文で述べること。",
  "例: 「Leinsterの平均31得点アタックは今日も機能し、Saracensの堅守を41-12で打ち破った」",
  "このセクションを最初に必ず出力すること。",
].join("\n");
```

### 2. `structureInstruction` の3ケースを更新

**共通ルール:** 各ケースの先頭に `# この試合の核心` を追加し、その説明を同ブロック内に含める。禁止リストはそのまま維持。

#### hasLineups=true の場合

```typescript
[
  "以下のセクション見出しを、この順番で、必ずそのまま使用すること（変更・追加・省略はすべて禁止）:",
  "# この試合の核心（200字以内）: 試合前の「何 対 何の争い」に対し実際の結果がどう答えたかを1〜2文で述べる",
  "# 試合全体像（400-500字）",
  "# ターニングポイント（500-600字）",
  "# MOM（300-400字）",
  "# 次戦への示唆（300-400字）",
  "**上記5つの見出し以外は絶対に追加してはならない。`# 試合概要`・`# 試合の流れ`・`# まとめ`・`# 総評` 等、リストに存在しない見出しの出力は禁止。**",
  `全体で2,000字以上を目標とすること。${sectionHeadingInstruction}`,
].join("\n")
```

#### isDataSparse=true の場合

```typescript
[
  "以下のセクション見出しを、この順番で、必ずそのまま使用すること（変更・追加・省略はすべて禁止）:",

  "# 試合全体像（500-600字）",
  "# 大会文脈と順位への影響（400-500字）",
  "# 両チームの近況と戦術傾向（500-600字）",
  "# 次戦への示唆（300-400字）",
  "**上記5つの見出し以外は絶対に追加してはならない。`# 試合概要`・`# 試合の流れ`・`# まとめ`・`# 総評` 等、リストに存在しない見出しの出力は禁止。**",
  `全体で2,000字以上を目標とすること。MOM セクションは省略すること。${sectionHeadingInstruction}`,

```

#### events あり・lineups なし の場合

```typescript
[
  "以下のセクション見出しを、この順番で、必ずそのまま使用すること（変更・追加・省略はすべて禁止）:",
  "# この試合の核心（200字以内）: 試合前の「何 対 何の争い」に対し実際の結果がどう答えたかを1〜2文で述べる",
  "# 試合全体像（400-500字）",
  "# ターニングポイント（600-700字）",
  "# 次戦への示唆（300-400字）",
  "**上記4つの見出し以外は絶対に追加してはならない。`# 試合概要`・`# 試合の流れ`・`# まとめ`・`# 総評`・`# MOM`・`# マン・オブ・ザ・マッチ` 等、リストに存在しない見出しの出力は禁止。**",
  `全体で2,000字以上を目標とすること。MOM セクションは省略すること（ラインアップデータなし）。${sectionHeadingInstruction}`,
  "**`# MOM`・`# マン・オブ・ザ・マッチ` セクションは絶対に出力してはならない。** イベントデータに選手名が含まれていても MOM セクションは生成禁止。MOM を記述したい場合は `# ターニングポイント` 内で選手名に言及すること。",
].join("\n")
```

### 3. `return [...]` ブロックから `coreQuestionBlock` を除去

**変更前:**
```typescript

  persona,
  coreQuestionBlock,
  prohibitionsBlock,
  structureInstruction,
  ...
```

**変更後:**
```typescript
return [
  persona,
  prohibitionsBlock,
  structureInstruction,
  ...
```

## 受け入れ条件

1. events あり・lineups なし の recap を生成したとき、出力される見出しが `# この試合の核心`・`# 試合全体像`・`# ターニングポイント`・`# 次戦への示唆` の4つのみ
2. `# 試合概要` という見出しが出力されない
3. `# MOM` という見出しが出力されない
4. 全体字数が 1,600字以上
