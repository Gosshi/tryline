# 試合ページ・H2Hページのタイトル表記を「vs」から「対」に統一

## 背景

2026-07-08 の集客分析（Fable/Codex）で、GSC実測から「スコットランド 対 ポルトガル」という日本語クエリが82インプレッション・平均順位6.2位を記録しているのにクリックが0件であることが判明した。既に上位表示されている在庫のCTRが0%というのは、検索結果のタイトル・スニペットが検索意図と視覚的に一致していない可能性が高い。

コードを確認したところ、試合ページ（`app/matches/[id]/page.tsx:84`）・H2Hページ（`app/h2h/[pair]/page.tsx:68,126,139,211`）のタイトル・見出し・JSON-LDは、いずれもチーム名の連結に英語の **"vs"** を使っている（例:「スコットランド vs ポルトガル — Six Nations」）。一方、日本語ユーザーが実際に検索するクエリは「スコットランド **対** ポルトガル」のように日本語の「対」を使う。チーム名自体は既に日本語化されている試合でも、連結語だけが英語のままのため、検索結果のタイトルがユーザーの検索語と字面上一致せず、CTRを下げている可能性がある。

## スコープ

対象:
- `app/matches/[id]/page.tsx`: `generateMetadata` 内のタイトル生成（84行目付近）の連結語を "vs" → "対" に変更
- `app/h2h/[pair]/page.tsx`: タイトル（68行目）・見出し（126・139行目）・JSON-LD の `name`（211行目）の連結語を "vs" → "対" に変更
- 上記2ファイル以外にも同様の "vs" 連結パターンがないか横断検索し、見つかった箇所は同様に修正する（シーズンページの対戦カード一覧等）

対象外:
- チーム名自体の日本語化（`nameJa`/`homeDisplayName` の解決ロジック自体は既存のまま。本specは連結語のみが対象）
- OGP画像内のテキスト（`createMatchOgImage` 等、画像生成側で "vs" を使っている場合は別途判断。画像は視覚的なブランドスタイルとしての "VS" 表記が許容される可能性があるため、本specはHTML上のテキスト〈title/description/見出し/JSON-LD〉のみを対象とする）
- 英語版コンテンツ・英語UIの「vs」表記（本サイトは日本語ユーザー向けのため、英語ロケール分岐が存在する場合はそちらは対象外）

試合ページ・H2Hページの `<title>`・meta description・ページ内見出し・JSON-LD構造化データの表示テキストが変わる（例:「スコットランド vs ポルトガル」→「スコットランド 対 ポルトガル」）。

なし。

## 受け入れ条件

1. `app/matches/[id]/page.tsx` の `generateMetadata` が返す `title` が "対" を使う（"vs" を含まない）
2. `app/h2h/[pair]/page.tsx` の title・見出し・JSON-LD の `name` が全て "対" を使う
3. 横断検索で見つかった他の同様の "vs" 連結箇所（あれば）も修正されている。見つからなければ「無かった」と完了報告に明記する
4. 既存のOGP画像生成（`createMatchOgImage` 等）の見た目は変更されない（画像側は対象外）
5. `pnpm tsc --noEmit` / `pnpm lint` / `pnpm test` / `pnpm build` が通る

## 未解決の質問

- OGP画像内の "VS" 表記（テキストとしての表示ではなく画像内デザイン要素の場合）も合わせて「対」に統一すべきか、視覚的なブランドスタイルとして "VS" を残すべきかは、Owner のデザイン判断に委ねる。実装時にどちらか迷う場合は現状維持（画像は変更しない）を選び、完了報告で選択肢を提示する
