# OG画像のチーム名が文字境界で不自然に折り返される問題を修正

## 背景

X投稿時に表示されるOGP画像で、「ニュージーランド」（8文字）のような長いチーム名が「ニュージーラン」「ド」のように文字の途中で不自然に改行されている（Owner提供のスクリーンショットで確認）。

原因は `app/api/og/route.tsx` の試合結果画像（`type=result`）における home/away チーム名の描画（262-298行目付近）。`home`/`away` の各 `div` は `fontSize: "58px"` 固定・`flex: 1` で幅が可変だが、フォントサイズは名前の長さに関わらず一定のため、短い名前（例:「日本」）では問題ないが、長い名前（「ニュージーランド」等）では確保された幅に収まらず、`@vercel/og`（Satori）のレンダリング上、文字単位で折り返されてしまう。既存コードにはチーム名の長さに応じたフォントサイズ調整ロジックは存在しない（確認済み）。

## スコープ

対象:
- `app/api/og/route.tsx` の `type=result` 分岐における home/away チーム名描画に、名前の文字数に応じた動的フォントサイズ調整を追加する（長い名前は縮小し、1行に収まるようにする）

対象外:
- `type=competition` 等、他の画像タイプの文字表示（チーム名を表示しないため対象外）
- チーム名の日本語表記・略称化ロジック自体の変更（本specは表示崩れの修正のみ。名前を短縮する運用〈ショートコード表示への切り替え等〉は別の判断のため対象外）

## データモデル変更

なし。

## API サーフェス

なし（既存 `/api/og?type=result&...` のレスポンス画像の見た目のみ変更）。

## 実装詳細

チーム名の文字数（`home.length`/`away.length`）に応じて `fontSize` を段階的に縮小する。例えばのしきい値（Codexの裁量で調整可）:
- 4文字以下: 58px（現状維持）
- 5〜7文字: 46px程度
- 8文字以上: 38px程度

しきい値・具体的なpx値は、実際のチーム名一覧（日本語表記済みのチーム名で最長のもの、例:「ニュージーランド」「オーストラリア」「アルゼンチン」等）を使って `@vercel/og` のレンダリング結果を確認しながら調整すること。

## LLM 連携

なし。

## 受け入れ条件

1. 「ニュージーランド」「オーストラリア」を含むテスト用の画像生成で、いずれのチーム名も1行に収まり、文字の途中で折り返されない
2. 「日本」「NZ」のような短い名前は、従来通り大きなフォントサイズで表示される（縮小しすぎない）
3. 動的フォントサイズ調整のユニットテスト（文字数としきい値の対応関係）を追加する
4. `pnpm tsc --noEmit` / `pnpm lint` / `pnpm test` / `pnpm build` が通る
5. 実装後、`/api/og?type=result&home=ニュージーランド&away=イタリア&...`（既存のクエリパラメータ構造に倣う）に実際にアクセスし、画像を目視確認する

## 未解決の質問

- フォントサイズのしきい値・具体的なpx値はCodexの裁量で決めてよいが、極端に長いチーム名（10文字以上、現状のデータにあるか要確認）が今後追加された場合の下限フォントサイズも考慮すること
