# fix-site-copy-audit

## 背景

GPT-5.6による調査（2026-07-20）で、サイト内に機械翻訳調・内部用語が漏れた文言がいくつか見つかった。実コードで存在を確認済みのものと、未確認のものがある。

**確認済み**（grep実測）:
- `components/favorite-teams-banner.tsx:47` — 「応援チームを登録して、次の試合を逃さない」
- `app/page.tsx:195` — 「次日程待ち」
- `app/page.tsx:462` — 「Ask After Match」（英語のまま、日本語UIに混在）
- `app/pricing/page.tsx:280` — 「Premium ではこんな画面が読めます」
- `app/pricing/page.tsx:283` — 「詳細な日本語レビューと、試合について何でも聞ける AI チャット。」（「何でも聞ける」は sourced_facts / match_events に基づくgroundingの範囲を超える印象を与え、設計の不変条件「LLM生成コンテンツはデータに基づく」の趣旨とも齟齬がある）
- `components/match-chat.tsx:30` — サンプル質問「次節への示唆を踏まえて、この試合の意味を教えて」（硬い/不自然）
- `components/team-stats-panel.tsx:153` — 「match_events 取得済み {N} 試合」（内部テーブル名がユーザー向けUIに露出）
- `app/h2h/[pair]/page.tsx:143` 付近 — 「Tryline 収録分の対戦を表示しています。全history…」（「全history」は英語の混在）

**未確認**（GPTの報告にあったが本セッションでは実コード上の場所を特定できていない。実装時に検索して該当箇所があれば含める）:
- 「recap通知」に類する文言

## スコープ

対象:
- 上記「確認済み」の各文言を、以下の方向性で自然な日本語に修正する（最終文言はCodexの裁量とするが、意味を変えないこと）:
  - 「応援チームを登録して、次の試合を逃さない」→「応援チームの試合を、すぐ見つける」等
  - 「次日程待ち」→「次回日程を確認中」等
  - 「Ask After Match」→ 日本語に統一（例:「試合後に聞けること」）
  - 「Premium ではこんな画面が読めます」→「Premiumで使える機能」等
  - 「試合について何でも聞ける AI チャット」→ groundingの範囲を明示する表現（例:「試合データと公開レビューをもとに質問できるチャット」）に変更
  - `match-chat.tsx` のサンプル質問文言をより自然な話し言葉に変更（例:「この結果は次の試合にどうつながる？」）
  - 「match_events 取得済み {N} 試合」→ 内部用語を除いた表現（例:「得点イベントを確認できた試合から集計」）
  - 「全history」→「全対戦」等、英語混在を解消
- 実装時にサイト内（特に `app/` `components/` 配下）を横断検索し、同種の機械翻訳調・内部用語・英語混在文言が他に見つかれば、リストに追加して同様に修正してよい（ただし本specが明示した箇所の修正を優先する）

対象外:
- コピー全体のトーン統一やブランドボイスの再定義（本specは明確に不自然な箇所のピンポイント修正）
- LLM生成コンテンツ（recap/preview本文）のプロンプト・文体変更

## 受け入れ条件

1. 上記「確認済み」8箇所すべてが修正されていること（コードレビューで1件ずつ確認）
2. 修正後の文言が意味を変えていないこと（機能・遷移先・対象範囲が変わらない）
3. `app/pricing/page.tsx` の「何でも聞ける」表現がgroundingの範囲を超えない表現に修正されていること（この1点は特に確認する）
4. `pnpm test` / `pnpm tsc --noEmit` / `pnpm lint` / `pnpm build` が通る
5. 変更ファイル一覧と、各箇所の修正前後の文言をOwnerに報告すること

## 未解決の質問

- 「recap通知」相当の文言が実装時に見つからない場合は、対象外として報告してよい
