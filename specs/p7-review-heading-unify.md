# レビュー第1見出し（H3）の統一

## 背景

試合レビューの第1セクション見出しが競技によって異なる：
- Premiership: 「試合全体像とスコア分析」
- Six Nations: 「試合全体像」
- Top 14: 「試合レビュー: チーム名 vs チーム名」（LLMが自由生成）

原因は `lib/llm/prompts/generate-recap.ts` のプロンプトで
リーグ型試合に "とスコア分析" を付加する分岐があるため。

## スコープ

対象:
- `lib/llm/prompts/generate-recap.ts` — レビュー生成プロンプト

対象外:
- 既存の生成済みレビューコンテンツ（DB上のデータは変更しない）
- プレビューのプロンプト

## 変更内容

`lib/llm/prompts/generate-recap.ts` の構成指示文（L20-23付近）で、
リーグ型かどうかで分岐している「試合全体像とスコア分析」を
「試合全体像」に統一する。

変更前（L22付近の分岐）:
```ts
? "構成: 1)試合全体像とスコア分析(500-600字) 2)大会文脈・順位への影響..."
```

変更後:
```ts
? "構成: 1)試合全体像(500-600字) 2)大会文脈・順位への影響..."
```

「とスコア分析」の4文字のみ削除する。他の文字数指定・セクション構成は変えない。

## 受け入れ条件

- [ ] 新規生成されるリーグ型試合のレビューの第1見出しが「試合全体像」になる
- [ ] 字数指定・セクション構成は変わらない
- [ ] `pnpm tsc --noEmit` と `pnpm build` が通る

## 注意

既存コンテンツは変わらない。変更は新規生成分から適用される。
